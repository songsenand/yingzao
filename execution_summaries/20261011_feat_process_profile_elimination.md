# 执行摘要：工艺档案与"只否决"判定（含工作量预估）

> 本文件目前**只含方案与预估，未动任何业务代码**。
> 方向决策见 `docs/DECISION-LOG.md` 2026-10-11 条目「工艺判定只做"否决"，永不做"推荐"」。

## 动机

`check_printability` 的薄壁阈值是一个**固定常量**（`wallMinMm` 默认 1.2）。真实要求随材质与工艺改变，
而规则集本身也随工艺改变：SLS/MJF 没有悬垂问题，注塑的核心是拔模，CNC 的核心是刀具可达性。
更严重的是，这个默认值在**静默地塑造设计**——螺旋桨后缘"为了通过薄壁检测"被加厚，
用一个 FDM 规则的默认值越界改了气动几何；换 CNC/注塑则全是过度设计，而这个代价没有任何工具会告诉设计者。

用户拍板的方向：**判定只做两值（一定做不了 / 可能做得出来），永不做推荐最优，即使权重由用户给出。**
本文件给出落地阶段划分与工作量预估，供裁剪。

## 具体操作步骤（分阶段）

**S0 契约先行（无几何算法，1–2 人工日）**
1. 定 `profile` schema：`rules` 每条带 `value` / `applies` / `reason` / `source`（厂商规格 | 标准 | 用户实测 | 经验值）。
2. 定报告 schema：`excluded`（含规则名 + 位置 + 量）/ `notExcluded` / **`unevaluableRules[]`（披露，不是第三种判定）**。
3. 定措辞规范：`未排除（≠ 能做出）` 必须出现在人读的地方；写进 SKILL。
4. **加一条断言测试：schema 与输出里不存在推荐/排序/打分字段**（把"永不推荐"变成可执行的约束）。

**S1 档案 + 多档对照（横向复用现有测量，5–8 人工日 = 3–5 实现 + 2–3 验收）**
1. 把现有 5 个常量抽成 2–3 份示例档案（FDM-PLA-0.4 / SLA-标准树脂 / CNC-通用铣削）。
2. 工具加 `processProfiles[]`；输出回显档案 id；**未声明时不静默套默认**，报"按 FDM/PLA 默认档评估"。
3. 规则：壁厚 / 最小凸特征 / 最小缝隙 / 悬垂 / 桥接跨度——**全部复用**现有射线、体素、法线实现。
4. 运行记录写入档案 id + hash。
5. 立刻产出：回答"后缘是否为 FDM 过度加厚"。

**S2 封闭空腔与排粉/排液通道（7–9 人工日 = 4–6 + 3）**
1. 从已有的亏格 / 壳计数 / 连通体信息找封闭内腔（`check_connectivity` 已算这些）。
2. 对有开口的腔，判断通道是否够粗（连通路径 + 沿路径的最小间隙）。
3. 这是 SLS/SLA 档**唯一能否决**的规则，当前完全缺失。

**S3 拔模（注塑/铸造，8–12 人工日 = 5–8 + 3–4）**
1. 面法线 vs 脱模方向；脱模线/分型面搜索；**∀ 语义**（所有方向都存在违规面 → 排除）。
2. 分开报"无拔模面"与"分型线不闭合"（是两件事）。
3. 仅在确实做注塑时提前。

**S4 刀具可达性（CNC，10–14 人工日 = 6–10 + 4）**
1. 体素按方向集做形态学腐蚀；内圆角 vs 刀具半径；欠切区域。
2. 取向下限（3轴/4轴/5轴）写进档案。
3. **保守是安全的**：找不到可达路径 ⇒ "一定做不了"，该结论不会因算法不够精细而变错（本决策的直接收益）。

**S5 AI 辅助层（3–5 人工日）—— 分类错误，已改为 skill 章节（见 DECISION-LOG 同日条目）**
1. 档案起草模板：**强制 `source` 字段 + 需人签字**（生成的档案比没有档案更危险）。
2. 反例解释的措辞规范（工具给事实，模型给解释与修法）。
3. 实测 → 档案流水线（把台架/试件结果整理成带出处的档案）——这是"材料库"的正确形态：不是我们内置，是用户标定。

假设：一名熟悉本仓的工程师；单位为**人工日**；不含评审往返（那是日历时间）；每条新规则都含 fixture + **阴性对照**（本仓硬要求）；不确定度 **±50%**。

| S2 空腔 / 排粉排液通道 | 4–6 | 3 | **7–9** |

- **S0–S2（能立刻兑现"多档对照 + 空腔否决"）：13–19 人工日**
- **S3–S4（注塑 / CNC 深度）：18–26 人工日**

**横向成本（最容易被低估，单列）**
1. **阴性对照**：每条规则都要一个"必须不被排除"的对照件 + 一个"必须被排除"的对照件。
2. **双实现 parity**：若 worker(python) 与 TS oracle 都保留，每条规则 ×2。**建议新规则只做 worker 一份**——
   TS 那份的存在意义是防迁移回归，不是长期双维护；这一条能省掉接近一半的验收成本。
3. **文档重写**：SKILL 心智模型 + 陷阱（"未排除 ≠ 可做"）；TOOL-RUNTIME-MATRIX、HARNESS 同步。
4. **历史证据标注**：旧 runs 的 `verdict` 需追加"当时按 FDM/PLA 默认档"的标注，否则不可解释。

**最小止血版（若只想先止住"默认值掰弯设计"）**：S0 + S1 的第 2 项（档案回显 + 未声明就明说），
**3–4 人工日**。不算任何新规则，但从此"你看见的那一档就是你声明的那一档"。

**我能直接产出 / 必须人定**
- 我能直接做：S0 契约草案、S1 全部、S2/S4 的实现与 fixture、文档同步。
- **必须人定**：档案里的**数字及其出处**（权威问题，不是能力问题）；每条规则的保守程度是否可接受；
  S3 的分型面语义。关键路径上的人不是"审代码"，是**签数字**。

## 预期风险与验证

- **风险 1：术语定歪。** "未排除"被读成"可以做出"——这是本方案最危险的读法，S0 必须先把措辞钉死，
  否则后面全部返工。验证：把"未排除（≠ 能做出）"写成 SKILL 陷阱 + 报告排版断言。
- **风险 2：旧 verdict 语义漂移。** 历史 runs 的 `ok` 是"对着 FDM/PLA 默认档"的结论。
  验证：运行时回显档案 id + hash，历史 runs 追加标注，不修改历史条目。
- **风险 3：三角网格上的拓扑不稳。** 亏格/封闭腔判定会遇到退化面与共面片（本轮已实测到
  0.012mm² 的共面退化面污染过壁厚）。验证：S2 必须带一个"含封闭内腔"的阴性对照件 +
  一个"有排液通道"的对照件，两者结论必须相反。
- **风险 4：估算本身。** 这类从零设计的算法，±50% 是诚实的不确定度；S3/S4 尤其可能翻倍。
  验证：S0–S1 做完后回头校正 S2–S4 的估。

## 实际结果（S1 / S2 / S3 收尾）

**S1 已完成**（契约可执行 → 接入工具 → 两值判定 + 披露 + 永不推荐）。验收：`accept-process-profiles` 27/27、
`accept-p3` 71/71。**一处行为变更**：未声明档案时 `ok` 降级为 `check`（`ok` 会声称"通过了调用者从未指名的工艺"），
声明档案才是拿到通过的方式；档案 id + 内容 hash 随判定返回。

**S2-a 已完成**（封闭内腔 = 负体积壳）。判据：腔体的外法线（相对**材料**的外）指向腔内，散度定理给出负体积；
独立实体为正。实测空心球 R10/r9 → `voids=1`，体积 3027.3mm³（解析 3053.6，icosphere 离散误差 1%），
累加可还原材料体积 `+4188.8 − 3053.6 = +1135.2`。接入 `escapePassageMinMm` → 反例
`{rule, measured: 0, required, locationMm: 腔心}` → `excluded`。验收：`accept-p3` 75/75。
**明确不声称**：中途变细的通道无法从表面证明，报告用 finding 说明"通道内部的截面没有被测量"。

**S2-b（窄通道内部截面）推迟，不赶工。** 设计已定：只在腔体包围盒 + 余量内做体素化，
用 `scipy.ndimage.distance_transform_edt` 求腔区到壁的距离，再对阈值 r 二分并用 `ndimage.label`
检查"腔是否仍与外部连通"——最大的可行 r 即通道最小内切半径。**必须先解决的两点**：
① 分辨率与可测下限的关系（要测 2mm 通道至少要 ~0.5mm 体素，而 150mm 件全域体素是 10⁸ 量级 → 必须局部化）；
② "外部"的种子如何定义。这两点没想清楚就写，会得到一个"看起来对"的半径数字——正是本项目一直在消灭的东西。

**S3（拔模）已实现后被探针否决并撤回。** 原设计：对 26 个候选脱模方向取违规面积最小者，全都有违规则排除。
探针结果：**零拔模立方体报违规 0.00mm²**。原因不是 bug——沿体对角线抽芯时六个面各有 35.3° 拔模，
立方体确实可脱模。26 个方向里总存在一个让每个面都有正拔模的方向，于是**该规则对任何合理拔模角都不会否决**，
是同义反复。留着比没有更糟：它会对零拔模件给出"未排除"的**假安慰**。已完整撤回（无残留，parity 45/45）。

**由此暴露的 schema 问题（需要拍板）：** 脱模方向**不能自由搜索**。真实模具的抽芯方向由零件安装/压机决定，
选定之后才要求各处按该方向做够拔模。所以 `draftMinDeg` 必须配一个**声明的脱模方向**
（profile 里加 `drawDirectionsMm: [[0,0,1]]` 之类，或 `applies` 时必填），规则才是"对**声明方向**是否够拔模"，
而不是"是否存在某个魔法方向"。这是一个 schema 决定，不是实现细节——按"档案是契约"的既有原则，
我不擅自扩 schema。

## S3 的第三条路（消解 A/B 两难）：可行抽芯方向锥

用户否掉了 A（要求声明脱模方向——把难点推给用户，对没有相关知识的用户零增益）与
B（自由搜索后仅报告——理解门槛太陡，等于要求用户先学一遍）。两者共同的病是
**把"工具该自己算出来的东西"交给了用户的理解力**，而这个工具的使命恰恰是提升能力。

**提议（S3 重做方案）：球面盖交集。**

- 每个面 i 的可行抽芯方向 = 围绕 ±n_i、角半径 `90° − draftMin_i` 的**两个球面盖**
  （墙面可以落在分型线的任一侧）。
- 整个零件的可行方向集 = **所有面之盖的交集**（球面上的一个区域，可能为空、可能极窄）。
- **交集为空 ⇒ 一定做不了**，反例是**一对互相矛盾的面**：若对四种符号组合都有
  `angle(±n_i, ±n_j) > (90−draftMin_i) + (90−draftMin_j)`，则两面在任何方向下都无法同时满足
  —— **精确、成对、可指认**，不依赖方向集采样。
- **交集非空 ⇒ 报出这个锥**：中心方向、角宽度、以及**哪些面在收紧它**（去掉/补拔模后能放宽到多少）。
  这是"测量"不是"推荐"：它不选工艺，只把可行域和约束源说清楚。

**性质**：不需要用户声明（无 A 的门槛）；不是同义反复（无 B 的"魔法方向"问题，因为空集是**可证**的）；
并且天然给出**可执行的下一步**（"给这两个面补 1° 拔模，可行域从 3° 放宽到 20°"）。
采样只用于**非空**一侧的锥宽估计（并带免责声明）；**空集一侧用成对矛盾精确判定**——
与"证明用于否决、估计用于放行"的既有不对称完全一致。

**待做**：球面多边形求交（或用 Fibonacci 球面网格 + 成对矛盾精确兜底）。未实现，先记方案。

## S2-b / 非圆槽共用引擎：体素可达性 —— **算法已验证，整合未做**

**这是 S2-b（排粉/排液通道瓶颈）与 S4 非圆槽（刀具进不去的腔）共用的同一套引擎。**
探针脚本在已知答案的用例上验证通过；**尚未写进 worker，也尚未接入规则与验收**——停在这里
是因为整合需要一轮完整的验证，而本轮余量不足以再做一次"看着对"的交付。

**算法（已验证形态）：**

1. `trimesh` 体素化 → `fill()` 得实体掩膜；四周 padding 出远场（padding ≥ r + 4×pitch）。
2. `distance_transform_edt(~solid) * pitch` → 每个空隙体素到壁的距离（mm）。
3. **外部空隙** = t=0 时与栅格边界连通的空隙连通域（封闭内腔天然是另一个连通域，与 S2-a 的负体积判据一致）。
4. **球心可放位置** = `dt ≥ r` 且与远场连通的连通域。
5. **球能扫到的范围** = 用**球**结构元把球心集膨胀 r（⚠️ 不能用默认结构元——它是菱形/L1，会漏掉对角区域）。
6. `不可达 = 外部空隙 & ~扫到`；**再用球结构元腐蚀一次**：一 voxel 厚的界面壳是体素化误差，真实腔体会存活。

**两个被探针抓出来的错误（都不是小问题）：**

- 第一版把"dt < r 的空隙"当成不可达 → 整个贴壁空隙层都被算进去（报告 ~2700mm³ 的假腔）；
- 第二版膨胀用了 `ndimage.binary_dilation` 的默认结构元（菱形），对角方向覆盖不足，4mm 槽也报 66mm³。

**已知答案验证（pitch 0.2mm，r=1.5mm，槽 20×6mm 贯穿）：**

| 槽宽 | 原始不可达 | 腐蚀后（判据值） | 语义 |
| --- | --- | --- | --- |
| 0.8mm | 68.90 mm³ | **20.95 mm³** | 刀进不去 ⇒ 应排除 ✓ |
| 3.0mm | 25.22 mm³ | 0.00 mm³ | 与刀**恰好等宽**（零间隙）⇒ 几何上放得下，不排除 ✓ |
| 4.0mm | 25.22 mm³ | 0.00 mm³ | 放得下 ⇒ 不排除 ✓ |

**可辩护的语义（要写进工具描述）：** 当存在**至少约 2 voxel 厚**的、半径 r 的球到不了的区域时排除；
判据的分辨率下限是 pitch（要测 W 宽的特征，pitch 必须 ≲ W/3），**必须随报告一起给出**，
并且当要求的宽度低于 3×pitch 时要**拒绝**而不是悄悄粗化。

**接口已按新决策修改**（阈值类判定必须报余量，零/过小间隙记"困难"，见 DECISION-LOG 同日条目）：
引擎不再返回布尔，而是**每个区域的瓶颈半径**（对阈值二分）；规则层按三条带判定——
`< 要求 − pitch` 排除、`|测量 − 要求| ≤ pitch` **记为困难**、`> 要求 + pitch` 不报。
带宽来自测量分辨率，不自编工艺常数。

**待做（整合）：** ① 写成 worker op（输入 path/pitch/probePoints/要求半径，输出不可达簇 + 每簇的
瓶颈半径二分值）；② 接入 `toolRadiusMm`（非圆槽）与 `escapePassageMinMm`（通道瓶颈）；
③ 验收（0.8/3/4mm 三例 + 一个封闭内腔的瓶颈二分）；④ 网格上限（超过 ~4e6 体素就拒绝并说明）；
⑤ pitch 与可测下限写进报告与 skill。

### 整合进展：op 已写、排除半边已验证、**未接线**（第三个 bug 挡在"困难带"上）

`op_void_reach` 已写入 worker（未接线、未被任何工具调用，故不影响现状：tsc / parity 45/45 / p3 80/80 全绿）。

**已验证（排除半边）**：pitch 0.2、required 1.5 → 0.8mm 槽 = 不可达 20.952mm³、瓶颈 **0.400mm**（1 个区域）；
3.0 / 4.0 / 6.0mm 槽 = 0 个不可达区域 ✓。单次约 1.7–2.8s。

**探针抓出的三个 bug（前两个已修并写进 op 注释）：**

1. 把"`dt < r` 的空隙"当不可达 → 整个贴壁层被算成腔（**假 2700mm³**）；
2. 膨胀用 `binary_dilation` 默认结构元（**菱形/L1**，非球）→ 对角覆盖不足，4mm 槽也报 66mm³；
3. **`tightestPassageRadiusMm`（最紧通道半径）对宽槽出现虚假下限 ~1.600mm** —— 3.0/4.0/6.0mm 槽全部报 1.600。
   已排除的原因：padding 未按搜索上限定（已修，值未变）。**未定位的真因待查。**

## S3 可行抽芯方向锥：已实现并验证，**未接线**（发现成对证明不完备）

`op_check_printability` 已支持 `draftMinDeg` → 返回 `draft` 块（未接线到判定；只传参即计算）。

**已实现**：① 按法线方向合并面（网格有几千三角形但朝向很少，锥只取决于朝向）；
② **精确成对矛盾**：`acute_angle(line_i, line_j) > (90−δ_i) + (90−δ_j)` ⇒ 两面任何方向都无法同时满足；
③ 采样锥（Fibonacci 球面 20000 方向）：可行占比、最佳方向、最佳方向下的最差拔模与余量、
**收紧它的前 3 个面**（含"单独放宽它能到多少"）。

**探针验证（立方体 20³）**：

| δ | 采样可行占比 | 最佳方向最差拔模 | 余量 | 成对矛盾 |
| --- | --- | --- | --- | --- |
| 1° | 94.78% | 34.89° | **+33.89°** | 0 |
| 45° | **0.00%** | 34.89° | **−10.11°** | **0** ← 缺口 |
| 50° | 0.00% | 34.89° | −15.11° | 5（90.0° > 80.0°）✓ |

（δ=1° 可行 94.78% 是**正确**的：1° 的要求只排除坐标面附近 1° 的窄带，"只有体对角线可行"是我先前的直觉错误。
34.89° 对应体对角线的 35.3°，小差异来自采样最佳方向不是精确对角线。）

**发现的缺口（重要）：成对矛盾充分但不完备。** δ=45° 时立方体的锥**确实是空的**
（要求 `|d·x|,|d·y|,|d·z| ≥ sin45°`，三者平方和 ≥1.5 > 1，不可能），
但**任何一对面都不矛盾**——矛盾由**三个面联合**产生。所以：

- 成对矛盾 = **证明**（可下"一定做不了"）；
- 采样可行占比 = 0 且余量为负、但无成对矛盾 = **强证据，不是证明**。

**这也修掉了我自己写错的一个公式**：`bestWorstDraftDeg` 原写成 `90 − (margin + δ)`，
而 `margin = draft − δ`，所以应为 `margin + δ`；原式重复减了 90，把体对角线的 34.9° 报成 55.11°。

**接线前需要用户拍板的一件事**：立方体 δ=45° 这种"**采样为空但未被证明为空**"的情形怎么处理——
(a) 依采样证据排除并披露"无成对证明"；(b) 只在有证明时排除，其余记为**困难**并给出负余量与采样证据；
(c) 把证明补强为**最小不可行子集**（成对 + 三面，覆盖常见注塑情形），更大子集不查并披露。

## S3 修正：成对矛盾不够，改用**完备**的盖交判定（撤回我提的三个选项）

**用户的质疑**：余量为负，成对矛盾却是 0——这合逻辑吗？**合逻辑，但缺口在我的证明方法上，不在
"证明用于否决"这条原则上。** 立方体 δ=45°（每面要求 `|n·d| ≥ sin45° = 0.707`）：

| 组合 | 能否同时满足 | 见证方向 |
| --- | --- | --- |
| 面 +x 与 +y | **能**（零余量） | `(0.707, 0.707, 0)`，两面各恰好 45° |
| 面 +x 与 +z | **能** | `(0.707, 0, 0.707)` |
| 面 +y 与 +z | **能** | `(0, 0.707, 0.707)` |
| **+x、+y、+z 三者** | **不能** | 需 `|d·x|²+|d·y|²+|d·z|² ≥ 1.5 > 1` |

每对都能满足、三者一起不可能 ⇒ **只查两两的方法必然报 0**。余量 −10.11° 也是对的（体对角线是
最佳方向，最差面 34.89° < 45°）。两个数字都对，只是成对法看不见三面联合。

**因此撤回原先提的三个选项**（"依采样排除 / 只记困难 / 成对+三面"）——那是个**假两难**：
问题不该用政策绕过，该把方法补完备。

**完备判定（已验证）**：球面盖交集非空 ⟺ 要么某个**盖心**可行，要么某两个盖的**边界圆交点**可行。
（交集若非空，它要么含盖心，要么有极点，而极点必落在至少两个盖的边界上。）
故只需检查 **2k 个盖心 + O(k²) 个两两交点**即可**精确**判定空/非空。代价 O(k³)；
朝向数取上限（如面积最大的 100 个朝向）并披露。

**探针验证（立方体 20³，k=6，候选 108 个）**：

| δ | 判定 | 与真值 |
| --- | --- | --- |
| 1° | 锥**非空** | ✓ |
| 45° | 锥**为空（已证明）** | ✓ |
| 50° | 锥**为空（已证明）** | ✓ |

**分工**：**判定**用候选枚举（精确，覆盖所有空锥）；**报告余量/锥宽**用 Fibonacci 采样
（候选集只含盖心与交点，其"最佳余量"是**下界**——δ=45° 时候选给 −45.000°，采样给真值 −10.11°）。
于是"采样为空但未证明"这种情形**不再存在**，"一定做不了"始终有精确证明。

**待做**：把该判定写进 `op_check_printability`（替换现有成对测试），再接线到判定与验收。

## S2-b 完成：通道判定 = A（精确测量）+ 深度判据 + 通路条件（贯通/盲），含阴性对照
