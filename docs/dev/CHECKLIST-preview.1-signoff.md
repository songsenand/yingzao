## 1. U20 — 剖切目视签收（约 2 分钟）

> **2026-11-27 改版**：剖切不再有「任意平面 + 角度滑块」。现在是**沿视角**（切面与你当前屏幕平行，
> 按下时冻结，之后只调深度）和**轴切 X/Y/Z** 两种，界面上的滑块只有**深度**一个。

**要确认的一件事**：切进去看到的是**实心断面**（材料被切开、截面有填充、孔仍然是孔），不是空壳。

**已验（机器）**：`accept-ui section-free` 13 项
- 默认就是「沿视角」，且切面有真实几何（835.59 mm²）；
- **角度滑块确实不存在**（只剩深度滑块）；
- 拖深度，切面真的移动（cap 3962.2 → 1319.0 mm²）；
- 切面里**没有退化三角形**（0 / 113 个）；
- 切面有孔（cap 835.6 < 凸包 1963.8，比值 0.43）；
- 翻转后**切面不动**；
- 4 个真实零件 × 3 个方向 × 5 个深度扫描：退化三角形 0，最差只有极细三角形（<1e-4 mm²）。

**你来做的步骤**：

1. 面板里选 **镜筒 · v045**（或你自己的「照明座」），点 **◐剖切**。
2. 默认已按当前视角切好：**拖下面的深度滑块**，看切面在零件里推进/后退。
3. 转一个角度，点 **沿视角剖**：切面会重新对齐到新视角（深度不变）。
4. 看切面：应**实心**；孔仍是**通孔**（不是被面糊死）。
5. 点一次 **翻转**：切面应停在原处，只换保留的一半。

**判定**：① 界面只有深度滑块、没有角度滑块 ② 断面实心 ③ 孔是孔 ④ 翻转切面不跳 → 通过。
若仍有伪影，**把截图时左上那行「剖视」说明一起发我**（里面有 mode / 深度 / 法向），我按那组参数复现。

## 2. U21 — 真机切标签页（约 3 分钟）

**要确认的一件事**：切走再切回来，视口**不会白屏**；如果浏览器真的丢了 WebGL 上下文，
面板会自己重建（而不是留一块白）。

**已验（机器）**：`accept-ui webgl-recover`（注入上下文丢失 → 自动重建，模型像素占比 16.5% 恢复）、
`accept-ui big-mesh`（999,698 tri / 47.7 MB：传输 188 ms、解析 82 ms、首帧 74 ms、
稳态 63.9 ms/帧）、`accept-stream-progress` 16 项。

**你来做的步骤**：

1. 面板里打开 **整机预览**（16 个节点），等它画完。
2. 切到别的浏览器标签页，**停 10 秒**。
3. 切回来：模型应仍在（可能先看到一次重绘）。
4. 再打开一个**大一点的零件**（如 `p011` 的最新版本），在下载/加载过程中看左上**进度条**是否会动。
5. 顺手拖一下旋转/缩放，确认没有卡死。

**判定**：切回不白屏、进度条会动、能继续操作 → 通过。

## 3. Q1 — 三个任务的 A/B（约 10 分钟）

**要确认的一件事**：在**同样的任务**下，9 面工具面的**端到端 token** 比 45 个旧工具低 ≥20%，
且任务通过情况不变。

**已验（机器）**：`accept-token-budget`（固定前缀 5,930 chars ≈ 1,483 tok；45 个旧工具 104,675 chars；
降 94.3%）。**端到端**必须真会话，这就是这一项要你跑的原因。

### 3.1 两组配置怎么切

| 组 | 配置 | 怎么开 |
|---|---|---|
| **B 组（生产，9 面）** | `cordis.patch.yml` 现状：`toolScope: preset` + `toolSurfaces: [9 面]` + `hideLegacy: all` | 不用改 |
| **A 组（基线，45 工具）** | 把 `dsh-cad-harness/cordis.patch.yml` 里 `hideLegacy: all` 改成注释掉（或整段 `toolSurfaces` 注掉），再 `npx dsh-cad-setup` + 重启 dsh | 见下 |

```bash
cd /home/songsenand/Project/ToyMarker/dsh-cad-harness

node scripts/token-ab-toggle.mjs --status     # 现在在哪一组
node scripts/token-ab-toggle.mjs --legacy     # 切到 A 组（45 个 legacy 工具）+ 重新生成预设
# 重启 dsh，然后【新开一个空白会话】——toolScope 是会话创建时的事实

node scripts/token-ab-toggle.mjs --surfaces   # 跑完切回 B 组（从备份逐字节恢复）
```

脚本会：改 `cordis.patch.yml` 前先存备份到 `.tmp-ab/`、改完调用 `sync-cad-preset`（只重写预设，
不装 OpenSCAD），并**核对生成的预设确实变了**——"说切了但预设没变"会直接报错，不会静默。
`--surfaces` 从备份恢复，切换后 `cordis.patch.yml` 的 md5 与切换前一致。

> **注意**：`toolScope` 是会话创建时的事实，**已存在的会话不会变**；A/B 都要**新开会话**。

### 3.2 三个任务（A/B 用同一段话，逐字复制）

1. `做一块 120×80×6 的支架，四角 M4 沉头孔，中间加一条 40mm 长的加强筋；出一版并做打印性检查。`
2. `三件装配：底座 + 立板 + 横臂，立板用两个 M3 紧固到底座，横臂用转动副连到立板；检查接口契约再跑一次运动，报干涉和行程。`
3. `做一段 Ø20 外径、Ø14 内腔、60mm 长的直管；用流体预设跑一次，报到率、穿透和到达时间。`

### 3.3 记什么

每个任务、每组记三样：

| 任务 | 组 | 通过？ | 端到端 token | 备注 |
|---|---|---|---|---|
| 1 支架 | A / B | | | |
| 2 三件装配 | A / B | | | |
| 3 直管流体 | A / B | | | |

- **token 在哪看**：DSH Web GUI 里该会话的用量面板（宿主计费口径）；跑任务前记一次、结束后记一次，取差值。
- **通过标准**：任务产出可交付（版本 + 证据），A/B 都通过。
- **验收线**：三个任务里**至少两个** B 组 token 比 A 组低 **≥20%**；若达不到，Q1 记为"前缀已降、端到端未达标"，
  不硬凑数字。

把六个数丢给脚本，判定和记录它来做（不靠记忆）：

```bash
cd dsh-cad-harness
cat > /tmp/ab.json <<'JSON'
{ "date": "2026-11-28", "configA": "legacy 45 tools", "configB": "9 surfaces",
  "tasks": [
    { "name": "bracket",  "passA": true, "passB": true, "tokensA": 0, "tokensB": 0 },
    { "name": "assembly", "passA": true, "passB": true, "tokensA": 0, "tokensB": 0 },
    { "name": "fluid",    "passA": true, "passB": true, "tokensA": 0, "tokensB": 0 }
  ] }
JSON
# 把 0 换成你记到的 token 数，然后：
node scripts/token-ab-report.mjs --input /tmp/ab.json \
  --append ../experiments/20261127_0.2.0_token.md
```

- 判定规则写死在脚本里：**两臂任务都通过**，且 **≥2/3 任务降幅 ≥20%**（比较用表格显示的精度，
  避免"显示 20.0% 却判否"）。
- `--append` 会把表格追加到实验报告，**append-only**，不改历史。
