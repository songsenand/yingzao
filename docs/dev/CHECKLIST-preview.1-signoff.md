## 1. U20 — 斜切管道目视签收（约 3 分钟）

**要确认的一件事**：斜切之后看到的**是实心断面**（材料被切开、截面有填充、孔仍然是孔），
不是一层空壳。

**已验（机器）**：`accept-ui section-free` 8 项
- 斜切封盖三角形总面积 3,385.66 mm²（轴切 832.60 mm²）；
- 封盖面积 3,385.7 < 凸包 11,084.0（比值 0.305）→ **孔真的是孔**，没有被填平；
- 保留/切除翻转后**切面不动**（同一平面换边）；
- 帧确有变化（模型像素占比 7.0% → 10.1%）。

**你来做的步骤**：

1. 在 DSH Web GUI 里打开 CAD 面板（右栏 Tab），选 **镜筒 · v045**（零件 `p010`）。
2. 左上看板点 **◐剖切**。
3. 剖切条里把模式从「轴切」切到 **自由平面**，方位角拖到 ~40°、仰角 ~25°。
4. 看斜切面：应是**实心断面**；中间那个孔应仍是**通孔**（能看到内壁，不是被面糊死）。
5. 点一次 **翻转**（保留/切除互换）：切面应停在原处，只是半边材料消失。

**判定**：① 断面是实心 ② 孔是孔 ③ 翻转后切面没跳 → 通过；否则截个图告诉我。

## 2. U21 — 真机切标签页（约 3 分钟）

**要确认的一件事**：切走再切回来，视口**不会白屏**；如果浏览器真的丢了 WebGL 上下文，
面板会自己重建（而不是留一块白）。

**已验（机器）**：`accept-ui webgl-recover`（注入上下文丢失 → 自动重建，模型像素占比 16.5% 恢复）、
`accept-ui big-mesh`（999,698 tri / 47.7 MB：传输 188 ms、解析 82 ms、首帧 74 ms、
稳态 63.9 ms/帧）、`accept-stream-progress` 16 项。

**你来做的步骤**：

1. 面板里打开 **整机预览**（16 个节点），等它画完。
2. 切到别的浏览器标签页，**停 10 秒**。
3. 切回来：模型应仍在（可能先看到一次重绘）。
4. 再打开一个**大一点的零件**（如 `p011` 的最新版本），在下载/加载过程中看左上**进度条**是否会动。
5. 顺手拖一下旋转/缩放，确认没有卡死。

**判定**：切回不白屏、进度条会动、能继续操作 → 通过。

## 3. Q1 — 三个任务的 A/B（约 10 分钟）

**要确认的一件事**：在**同样的任务**下，9 面工具面的**端到端 token** 比 45 个旧工具低 ≥20%，
且任务通过情况不变。

**已验（机器）**：`accept-token-budget`（固定前缀 5,930 chars ≈ 1,483 tok；45 个旧工具 104,675 chars；
降 94.3%）。**端到端**必须真会话，这就是这一项要你跑的原因。

### 3.1 两组配置怎么切

| 组 | 配置 | 怎么开 |
|---|---|---|
| **B 组（生产，9 面）** | `cordis.patch.yml` 现状：`toolScope: preset` + `toolSurfaces: [9 面]` + `hideLegacy: all` | 不用改 |
| **A 组（基线，45 工具）** | 把 `dsh-cad-harness/cordis.patch.yml` 里 `hideLegacy: all` 改成注释掉（或整段 `toolSurfaces` 注掉），再 `npx dsh-cad-setup` + 重启 dsh | 见下 |

```bash
# 切到 A 组
cd /home/songsenand/Project/ToyMarker/dsh-cad-harness
cp cordis.patch.yml /tmp/cordis.patch.yml.bak
python3 - <<'PY'
import re,io
p='cordis.patch.yml'; s=open(p).read()
s=s.replace('        hideLegacy: all', '        # hideLegacy: all   # A/B: legacy 45 tools')
open(p,'w').write(s)
PY
npx dsh-cad-setup      # 重新生成预设
# 重启 dsh 后，新开一个空白会话（toolScope 是会话创建时决定的）

# 跑完 A 组后切回 B 组
cp /tmp/cordis.patch.yml.bak cordis.patch.yml && npx dsh-cad-setup
```

> **注意**：`toolScope` 是会话创建时的事实，**已存在的会话不会变**；A/B 都要**新开会话**。
