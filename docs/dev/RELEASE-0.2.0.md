# 0.2.0 版本目标：准生产基线

> **状态**：实施中。**preview.1 的 13 项：11 项已收口**（Q2、U12、U11、U22、U19、U15、F2、N15、U20、F1、U14），
> **2 项「已实现 · 未签收」**（Q1 差真会话 A/B、U21 差真机切标签页）；维护者 2026-11-28 决定本版不做这两项签收，按 11/13 发布。
> 本文只写**目标、范围、验收、顺序**；逐项状态与排序以 [TODO.md](TODO.md) §0.1 为准。
>
> **基线**：`0.1.2-preview.1`（2026-11-26 发布）。
> **发布形态**：先 `0.2.0-preview.1`，再 `0.2.0`；是否加 `preview.2` 由 Q6 按风险决定。
> **非目标**：第三引擎、社区/用户自行接入、插件市场、云/多用户。

---

## 0. 一句话

0.2.0 不是“再多几个功能”，而是把已经能跑的主流程收成一条**可交付的准生产基线**：
两个内核的「作者 → 验证 → 装配 → 查看/测量 → 导出/交付」闭环基本可用；
9 个工具面冻结，0.2.x 起只增不删；干净机器能装能升；用户文档中英全覆盖。

## 1. 完成定义（五条，每条都能指名一个观察）

### 1.1 主要功能基本可用

- OpenSCAD 与 CadQuery 各跑一个 bracket（孔 + 圆角 + datum）和一个 ≥3 件装配：
  `generate → check → assembly → motion/fluid → deliver audit` 全链路有 run、有证据；
  `npm run accept:preview` 全绿。
- 视口能完成：任意剖切 + 封盖、逐件显隐/隔离/高亮、正交/七命名视图/复原、
  角度/间隙/剖面面积/孔测量、审计视图点行跳到对应 run。
- 流体不再有已知“管外粒子”：F1/F2 的出口数字成立；161s 量级的跑有进度、能取消。
- 五项检查（制造/应力/装配/运动/物理）任一可从面板重跑；BOM CSV 可直接给加工/报价。

> **现状（2026-11-27）**：BOM CSV 已收口（U22）；重跑 **2/5**——制造与装配可一键（钉当前版本），
> 应力/运动/物理在旧运行上被**如实拒绝**并列出缺失输入（`needs`）；**2026-11-27 起新运行会记 `request`**，
> 于是它们可以 replay（版本重新钉住、joints 原样）。
> 要满足本条原文，需要把请求参数持久化进 run.json（additive，0.2.0）。
> 同理"流体不再有已知管外粒子"：F2 已修流轴、薄壁政策已立，但细网格仍可能外泄（F1b 未做）。

### 1.2 工具编组基本稳定

- 模型面**恰好 9 个 surface**，surface 名与 action 名冻结；不再同时存在 39/45 两套名字。
- 每个 action 有 catalog 条目、help、输出契约和一条可粘贴的 `example`；旧名迁移表在
  `dsh-cad-harness/docs/TOOL-SURFACE-MAP.md`，机器副本是 `TOOL-SURFACE-V1.json`。
- token 预算脚本进 CI：9 面 schema ≤ 6 KB；CAD 请求固定前缀有基线、不回归。

### 1.3 后面的版本基本可以向前兼容

- `docs/dev/COMPATIBILITY.md` 生效：0.2.0 起 surface/action **只增不删**；
  删除或改语义必须跨 1 个 minor，并先标 deprecated。
- 项目 schema **读旧、拒新**；0.1.2 golden 项目在 0.2.0 能打开、`doctor` pass、`verify --advisory` 能跑。
- 工具契约快照只允许新增；未知 `schemaVersion` 明确拒绝，不猜。
- 0.2.0 的 project / assembly / claims / evidence 格式在 0.2.x 内不再 breaking。

### 1.4 安装容易，问题少

- Linux / macOS / Windows 干净机器只按 README 完成安装并开启「营造模式」；首跑耗时记录在案。
- 0.1.2 → 0.2.0 升级有步骤、有回滚；`doctor` 对 preset drift / runtime 缺失 / OpenSCAD 缺失
  给出可执行的 fix，而不是只报错。
- 发布前 open P0/P1 = 0；已知问题全部进“已知边界”，不藏在 issue 里。
- R3/R6：13 个 in-range DSH 版本矩阵回填 `DSH-MATRIX.md`。

### 1.5 用户文档基本完整，中英对照

- 覆盖矩阵的 11 类常用任务无空缺；0.2.0 新功能都写“你会看到什么、你要决定什么”。
- 中英**同文件集、同标题、同版本号**；`accept-docs-parity` 进 CI。
- 安装/升级/排障/边界各有一页能独立读完的入口，不要求先读完全部文档。

## 4. 明确不做（0.2.0 不碰）

- **第三引擎、社区接入、插件市场、云/多用户**：沿用 2026-11-19 引擎纪律与 PROJECT-SCOPE 触发条件。
- **为省 token 削减验证/检查**：README 的立场不变；Q1 只削重复、长表、图片和无效上下文。

1. **版本号**：`dsh-cad-harness/package.json`、根 `package.json` shim、`presets/cad/preset.patch.yml` 同步。
2. **发布说明**：`docs/dev/RELEASE-NOTES-0.2.0.md`，含升级须知、工具名迁移、已知边界、证据表。
3. **迁移指南**：0.1.2 → 0.2.0 的 doctor/setup/项目备份步骤；旧项目不需要迁移时明确写“无需动作”。
4. **发布顺序**：CI 全绿 → tag → `npm stage publish` →（必要时手机 npmjs.com 批准）→ 发布后
   `npx dsh-cad-doctor` + `npx dsh-cad-verify <example> --advisory` + 干净安装冒烟。
5. **回滚**：保留上一版 tarball；若 latest 出问题，先 `npm dist-tag` 回退，再修。
