# 能力评估：玩具 → 准生产工具（2026-10-28）

> **合并对象**：2026-10-28 果糖球棍模型交付 + 10-27/28 的真实 run；10-18/19 bench 只作历史基线。
> **证据等级**：`[实测]` 本次亲自读/算出的数字；`[静态]` 读文件可核；`[推断]` 未单独验证；`[未测]`。
> **口径**：只认能指名观察的证据；"完成/通过"必须能说出哪个观察会证伪它（HARNESS §11.9）。

## 0. 三句话

1. **方向对**：瓶颈在验证，不在生成。
2. **总账约 55%**（判断值，不是测量值）：能力 ~75–80%，可验证性 ~55%，**可靠性未测**。
3. **缺的不是仿真器**，是"判据从哪来、准不准、实物对不对"。果糖证明第一问有解；后两问是准生产的后半段。

## 1. bench 为什么不能当现状

## 3. 自然实验：判据供给是"作者路径"问题

同一天、同一套工具，两个装配给出相反结果：

| | 玩具天平2（r104） | 果糖（r007） |
|---|---|---|
| 接口 | 25 | 122 |
| 有 tolerance | **0** | **122** |
| 结果 | 0 pass / 25 skipped | **122/122 pass** |
| 契约来源 | 手写 `assembly.json` | `spec/build_spec.py`（515 行）→ `assembly_plan.json` → `emit_manifest.py` |
| 真实错位 | I3/I4 量到 **116mm**（=2×58 左右互换），因无判据被 `skipped` | 同类错位 >0.25mm 会 `hard-violation` |

**结论**：G1 不是"agent 不会写 tolerance"，而是**手写契约会漏判据，生成的契约按构造完整**。产品化要做的不是教模型写 122 个数字，而是让 `assembly.json` 成为构建产物。

### 4.2 三个限定

1. **122/122 是名义一致性，不是功能验证。** 122 条的 `measured` 是 0 或 0.2（名义值），对 0–0.25 / 0.05–0.35 的带宽。它证明"零件按设计就位"，不证明"卡扣能保持、花键能抗扭"——后者靠负样本 + 打印筛查 + 待做的拉脱试验。
2. **判据有，但判据质量未标定。** 重接口凸台 Ø11.0 / 杯孔 Ø11.2 → 径向间隙 0.1mm，而同轴带是 0–0.25mm：**判据比配合本身还松**，0.1–0.25mm 的偏心能同时通过同轴与孔径两条检查。当前实测为 0，不影响这次结论；但它说明"有判据 ≠ 判据能分辨"。0.25 / 0.2 / 0.75 都是**声明常量**（`build_spec.py` 自述 "declared constants, not fitted numbers"）。
3. **39/39 水密没有 run。** `check_parts` 的 measure 半不写 run（BUILD B3 自述），所以这条主张可复算、但不能被 `delivery_audit` 引用。可被引用的只有 122/122（r007）与 motion（r004/r005）。这是"主张→证据"链上的一个真实缺口。

## 6. 路线图

### P0（最近两周）

1. **入库**（已完成，`4576124`）：果糖交付已按 AGENTS.md 提交；`cad-data/` 保持忽略。它是"规格→契约→验证"的参考案例。
2. **标定 coupon**：打一块测试片——间隙 0.2/0.25/0.3、壁厚 0.6/0.75/0.9、卡扣过盈 0.075/0.125；用卡尺+拉脱试验量出来，回填 `process-profile` 与 tolerance 带。**把声明值变成实测值。**
3. **产品化 spec→contract**：把 `build_spec.py` 的模式抽象成模板/工具；`check_assembly` 输出 `coverage: {hard, evaluated, skipped}`；生成式 manifest 成为 examples 的默认路径。

### P1

4. **闸门严格度**：`deliver` 模式下 `no-claims` → `blocked`；`check` run 只有 `evaluated>0` 才算证据；`skipped` 的 hard 接口 → `blocked`（除非 waiver）；加 `deliveryId`。
5. **重跑 bench 子集**（`00-smoke + 01b + 05 + 06`）并更新 4 份 rubric 的旧词汇；记录新 SUT 指纹。
6. **变异测试**：50 个已知缺陷（含 116mm 左右互换、单采样、缺 tolerance），测每个检查的检出率/误报率。

### P2

7. **物理验证回路**：拉脱试验 + 卡尺测量 → 回填语料；把"试打→测量→回填"做成文档化步骤，而不是一次性动作。
8. 装配 v2 / 版本图 / 批准当前版本（12.2 / 12.3）。

### 不建议现在做

装配视觉表达、STEP 导出、弹性 MPM、再加仿真器——都不产生否决权，也不解决标定。
