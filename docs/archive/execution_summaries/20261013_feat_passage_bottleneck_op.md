# 执行摘要：`op_passage_bottleneck` —— 锚定到开口的通道瓶颈测量（骨架）

## 动机
> 「先拓扑 → 再两端 → 才量宽度」的顺序与「测量必须锚定到一个具体开口」两条已定案
> （DECISION-LOG 2026-10-13 两条）。数据表明全零件盲扫会把窄通路盖住（Ø6+Ø1 双平行孔实测
> 报 2.996，真相 0.500）。本轮按方案 (a) 把这条路线做成 worker op 的骨架：
> **锚点来自 `list_features` 的平面面开口**（`centerMm` + `axisMm`）。

## 影响范围

  （+ 两个内部件：`_surface_topology`、`_anchored_void_section`）。

- **未动**：`tools.ts`（不接线，op 只进 worker 的 op 表）；规则层；示例台架（它是策略研究，保持不变）。

## 具体操作步骤
1. **`_surface_topology(mesh)`**：壳数 + 每壳亏格（`euler = 2 − 2g`），给出"有没有路"这个前置条件。
2. **`_anchored_void_section(mesh, axis, at, anchor, previous)`**：一张切片里的**空隙区域**，
   并从中挑出**锚点所属的那一个分量**：
   - 构造与台架一致（精确切割 → `polygonize` → 点内实体判材料 → `凸包(材料) − 材料`）；
   - 过滤「必须是内孔」（空隙截面不能碰到截面外轮廓）；
   - 分量选择：首刀取离锚点投影最近的分量，之后逐刀取**与上一刀所选分量距离最小**的分量
     （于是沿通路"跟着走"，而不是被同平面的其它通路带偏）。
3. **走查**：从锚点站位出发，沿 ±轴各走一趟（步长 = 轴向量程 / max(8, budget/6)），
   记录每刀接受的 MIC；某一方向连续两刀无有效截面即停。
   **两端判据**：停下的那一刀若**还切到材料**（`mesh_plane` 有线段）⇒ 通路在零件内部断掉（盲）；
   若**切不到材料**（射线离开零件）⇒ 这一端到了表面。两侧都到表面才算 `throughAlongAxis`。
4. **自适应细化**：在最小站位附近二分（预算的一半），沿用台架里 C 策略（实测 0.1%）。
5. **输出**：锚点、轴、拓扑、`reachable`/`throughAlongAxis`、`bottleneckRadiusMm`、
   `tightestAtMm`、两端终止位置与判据、切了多少刀、接受多少刀、披露。
6. **拒绝（不出数）**：不水密；亏格 0（没有通路）；有封闭内腔（转 S2-a 的 0）；
   锚点不在空隙里；一侧在零件内部断掉（盲特征 ⇒ 未判定）。

## 预期风险与验证
- **探针抓出的两个真 bug（都在本节记录里预判过，都发生在分量跟踪与两端判据上）**：
  1. **分量会"跳到另一条通路"**：跟踪规则"离上一刀最近"里的"最近者"**永远存在** ——
     锚的那条断掉之后，它安静地换到旁边那条通路上继续走。实测：零件有 Ø3 贯通排液孔 + Ø1 盲孔，
     锚在**盲孔**上时走查在盲孔底之后跳到排液孔，把死胡同报成"贯通、瓶颈 0.499"。
     **修**：加**跳跃上限**（2 倍步长），候选必须落在上一刀截面附近，超出即视为这一端断掉。
  2. **"断掉"被角料骗了**：原来用"这一刀还切不切到零件"判两端，但**斜孔出零件之后平面还会
     继续切零件的角**。实测 `03-tilted-bore`：斜孔出 y=10 面后平面在角上又切了约 2mm，
     于是贯通件被读成"两侧都是死胡同"。**修**：改用**延续点**判——把上一刀截面中心沿轴推到
     这一刀，看它还在不在实体里；不在 ⇒ 表面，还在 ⇒ 材料内部断掉。改后 03 恢复 3.998。
