# 执行摘要：面板三栏浏览（种类→条目→版本）

## 动机
> 用户方案：第一栏种类（零件/组件/整体及仿真/装配契约），第二栏具体条目，
> 第三栏版本（仅零件类，默认最新）；看旧版本要有醒目标识。名字由用户选定
> （组件、装配契约）。

## 影响范围
> - `src/client/panel.ts`：kind 状态、三类 run 池、三栏浏览条、旧版本横幅
> - `sandbox/preview/entry.tsx`：select 索引更新 + ?kind= 参数
> - `verification/shots/`：两张视觉存档

## 具体操作步骤
> 1. kind 状态四种；allRuns 拍平全部零件 runs+场景，按 kind 过滤三池。
> 2. 浏览条重写：种类 select；零件类→条目 select（零件）+版本 select（仅
>    版本、默认最新、跟随开关）；其余类→单条目 select（运行），版本列隐藏。
> 3. 旧版本横幅：视口顶部，含最新版本号与"回到最新"。
> 4. entry.tsx：selectByIndex 索引 0/1/2 对应种类/条目/版本；?kind= 驱动。

## 预期风险与验证
> - 风险点：组件/装配契约目前只有运行记录列表，manifest 全文视图属二期；
>   entry 索引与面板结构耦合（沙盒调试参数，会随面板演进再调）。
> - 测试方式：沙盒截图两张（三栏默认最新 + 旧版本横幅）已视觉确认；四套
>   验收回归全绿。
