# 执行摘要：厚壁腔穿透差异——定位到"投影在场却仍有粒子留在壁内"（未关闭，仍走 TS）

## 动机
> 上一轮修掉"没有壁面边界条件"后，`accept-fluid-sign`（厚壁腔）仍在**硬不变量**上分歧：
> Python 末态有 167(Ø60)/888(Ø100) 个粒子在壁内 >0.3mm，TS 为 0。本轮把差异**量化到机制层面**，
> 而不是停在"可能是混沌"。

## 影响范围
> - `dsh-cad-harness/python/cad_worker/worker.py`：`op_fluid_run` 增加**诊断块**
>   （`CAD_FLUID_DEBUG_PENETRATION=1` 时返回穿透深度分布、梯度、投影计数）
> - `dsh-cad-harness/src/host/fluid.ts`：把诊断字段透传到 report（**仅诊断**，不进工具 schema）
> - 文档：矩阵 row 16、DESIGN §26.4

## 具体操作步骤与数据
> 1. **穿透深度分布**（Ø60/Ø100，dx=2mm，近表面带 ±5mm）：
>    - Ø60：167 个，深度 **-0.94 ~ -0.89 mm**（均值 -0.906）
>    - Ø100：888 个，深度 **-1.00 ~ -0.32 mm**（均值 -0.887）
>    - **全部落在投影带内**（`withinBand = count`，`outsideBand = 0`）⇒ 不是"从带外进入"
> 2. **梯度**：`gradMin≈3.99 / gradMax≈4.01 / gradZero=0` ⇒ SDF 斜率正常（|∇d|≈1/mm），
>    **不是零梯度导致推不动**
> 3. **投影确实在工作**：600 次调用共移动 **278,692（Ø60）/ 676,630（Ø100）** 个粒子次，
>    推距累计 136,652 / 337,327（格）
> 4. ⇒ 结论：**投影公式与采样器都与 TS 一致**（采样器已做逐位单测：max|Δ|=0），
>    投影也**在场且大量生效**，但末态仍留下 ~0.9mm 的一层粒子。
>    **下一步（已写进代码与矩阵）**：只对**最后一次** `project_particles` 调用插桩 ——
>    记录当时 `inside` 的粒子数、推后深度、以及"推后仍 < -tol"的个数。
>    若推后仍在内 ⇒ 后置条件不成立（需要改推距/迭代）；若推后在外而**指标仍测到在内** ⇒
>    指标采样或活动集合不一致（更可能是真正的 bug 所在）。

## 预期风险与验证
> - **处置不变**：`runFluid` 默认 **TS canonical**（`accept-fluid-sign` 16/16、`accept-m4` 全过），
>   Python 路径需 `DSH_CAD_FLUID_PYTHON=1`（该路径 `accept-m4` 24/24 全过，`accept-fluid-sign` 14/16）。
> - 诊断开关全部**环境变量门控**，默认关闭，且**不进工具 schema**（`additionalProperties: false` 不受影响）。
> - 本轮没有把"可能是混沌"当作结论：给出了深度、梯度、投影计数三类量化证据，
>   把问题从"未知系统性差异"缩小到"投影后置条件或末态采样"这一个二选一。
