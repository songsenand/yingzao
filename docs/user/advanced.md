# 进阶用法

## 装额外的 Python 包

直接跟 Agent 说你要用什么库。包会装进**用户 overlay**（`$DSH_HOME/cad/runtime/user-site/`）：那是你的机器、你的线，装的东西**不会被运行时升级冲掉**，计算工具都能用，而且每次验证会把它记进 provenance。

- **默认：加装不覆盖。** 锁里已有的包仍以锁定版本为准，避免悄悄分叉 numpy。
- **要强制换掉锁定的依赖**：明确说明“覆盖锁定的 X，理由是……”。包会进一个单独目录并排在 `sys.path` 最前（真的替换，不是只报告），理由会写进安装记录和每次验证的 provenance。

## 外观 / 颜色（GLB 侧车）

如果你有自包含的 GLB，可以让 Agent 把它挂到版本（`appearance.glb` + `appearance.json`）。

- `model.stl` 仍是**几何真值**；面板仍只预览 STL。
- GLB 可在外部查看器打开；面板内 viewer 尚未实现。
- 颜色不是几何通过条件：彩色渲染不代表打印颜色，也不参与可打印性判定。

## 导入现成文件

面板顶部的 **📂**（或种类下拉里的 **未登记**）会列出工作区里没有版本的几何文件（STL / STEP / 3MF / DXF）。

- 选中即可预览：不登记、不测量、不进 Agent 上下文。
- 满意后填**零件名与单位**，点「导入为版本」，它才变成可测量、可装配、可交付的版本。
- 3MF 必须只含一个对象；DXF 需要填挤出深度。
- 文件不在工作区时，用「📂 按路径导入…」。

## 多项目 / 工作目录

大项目下多个组件（`components/*/`）或多套示例语料并存时，用面板顶部的**工作目录**下拉切换查看对象。

- 这是**只读浏览**：Agent 的写入始终留在会话所在目录。
- 切换不会改变当前会话的语料根；它只改变你在面板里看哪一套。
