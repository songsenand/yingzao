# 故障排查

| 现象 | 怎么办 |
|---|---|
| 会话中没有 CAD 工具 | 该会话不是「造物模式」；新建时选择该预设，或在设置中将其设为默认 |
| 提示“运行时未就绪” | 首次使用尚未完成供给；等首次准备完成，或设置 `DSH_CAD_PYTHON=eager` 让启动时预热 |
| 首次使用耗时较长 | 正在下载约 400MB 运行时；可更换镜像/索引源（见 [DESIGN.md](../../DESIGN.md)） |
| 长会话因图片过多被上游拒绝 | 默认保留 24 张图片窗口；headless 会话设置 `DSH_CAD_IMAGE_WINDOW=1` |
| 某能力报“不可用（缺包）” | 该平台缺少对应的预编译包，属预期行为；状态中会说明原因（见 [边界](limits.md)） |
| `include <BOSL2/std.scad>` 报 “Can't open include file” | `OPENSCADPATH` 必须指向**包含 `BOSL2/` 的父目录**（即 `lib/`），而不是 `lib/BOSL2` 本身 |
| 面板空白 / 模型不显示 | 先刷新页面；仍空白时确认会话是「造物模式」，并检查浏览器 WebGL 是否可用 |

## 还是不行

提供三样东西，定位会快很多：

1. 你用的 dsh 版本与操作系统；
2. 复现步骤（哪句话、哪个操作）；
3. 面板或日志里的原始报错文本（不要只写“失败了”）。

安装问题见 [安装与首次准备](install.md)；能力边界见 [边界](limits.md)。
