# 用户文档

这是给人看的文档。你不需要知道 Agent 用了哪个工具、参数叫什么——你只需要知道**你会看到什么、你要决定什么**。

0. [0.1.0 预览版说明](preview.md) —— 这一版能做什么、有什么已知边界。
1. [安装与首次准备](install.md) —— 装好、开启「营造模式」、准备运行时。
2. [它是什么，不是什么](what-is-yingzao.md) —— 先建立正确的预期。
3. [从描述到交付](workflow.md) —— 一次完整的使用流程，以及每一步你要做的判断。
4. [验证能力](verification.md) —— 五层检查各回答什么、报告怎么读。
5. [边界](limits.md) —— 它现在做不到什么，以及为什么。
6. [配置](configuration.md) —— 三个常用的环境变量。
7. [故障排查](troubleshooting.md) —— 常见现象与处理。
8. [进阶用法](advanced.md) —— 额外 Python 包、GLB 侧车、导入、多项目。

## 这里不写什么

- **不列 30 个工具。** 工具是 Agent 的选择，不是你的选择；你选的是结果。
- **不写字段名、JSON、引擎内部。** 这些在 `docs/llm/` 与 `docs/TOOL-CONTRACTS.md`。
- **不写“保证合格”。** 工具给数值和反例，验收判断保留给你。

## 三个词

- **版本**：每次生成或修改都是一个不可变版本，可以回看、对比、钉住。
- **面板**：右侧的模型视图。可以自由翻转、测量、标注问题、回放运动。
- **报告**：一次检查的结果。它可能说“未排除”“困难”或“被排除”，也可能说“这一项没评估”——**没评估不是通过**。
