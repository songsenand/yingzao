# 它是什么，不是什么

**用自然语言描述零件，得到经过验证、可以直接打印的模型。**

## 它解决的不是“生成”

生成几何已经不难。难的是**确认结果对不对**：尺寸、壁厚、配合、运动、能不能打印。一个能生成但不能验证的系统，只能产出“看起来对”的东西。

所以这个工具的闭环是：

> 描述 → 生成 → Agent 自检 → **你审阅** → 验证 → 交付

每一环都留下可回看的证据：不可变版本、四视图、数值报告、运动回放、检查记录。

## 你会看到什么

- **版本**：每次生成或修改都是一个新版本，旧的不会消失。可以对比、钉住、回看。
- **四视图**：顶/前/侧/等轴。没有坐标轴和尺寸线，所以旁边会给包围盒数字。
- **面板**：右侧的模型视图。可以自由翻转、量两点距离、用红框标问题、在回放里暂停指认。
- **报告**：一次检查的结果。它说“被排除 / 困难 / 未排除”，也列“哪些项没评估”。
- **回放**：机构运动、流体趋势的时间线，可以停在某一帧看。

## 你要决定什么

工具给真值，**判断保留给你**。典型的三类判断：

1. **意图**：0.75mm 的间隙是“配合”还是“缺陷”？取决于你想让它怎么动。
2. **取舍**：壁厚、重量、打印时间、装配难度，哪个优先？工具不会替你排。
3. **验收**：这一版能不能交？工具能说“没找到反例”，不能说“保证能造”。

## 它不是什么

- **不是建模界面。** 你不画草图、不拉伸；你描述，Agent 写代码。
- **不是自动合格证。** “未排除”只表示没找到几何反例，不表示可制造、可认证。
- **不是工业级 CAD/FEA/CFD。** 没有 B-rep、没有工程图、没有认证精度；应力和流体是趋势，不是保证。
- **不修复坏网格。** 坏几何会被拒收并告诉你坏在哪，而不是给你一个自信的错误数字。
- **不是多用户/云/移动端产品。** 本地单用户工具。

## 一个例子

你说：

> 做一个 60×40×8 的安装板，四角 M3 沉头孔，中心一个 20mm 通孔。

Agent 会生成、编译、渲染，先自己看图；你会在面板里看到板、四个沉头孔和中心孔。接下来你可以：

- 量孔距、量壁厚；
- 说“孔径改 22，保持同心”，得到一个新版本；
- 让它检查可打印性，看报告说哪里太薄；
- 满意后导出 STL。
