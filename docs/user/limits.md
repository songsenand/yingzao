# 边界

以下都是**已知边界**，不是待修的 bug。知道边界，才不会把“没检查”当成“没问题”。

## 精度与认证

- **不做工业级公差、工程图、成品 BOM。** 它是设计验证工具，不是生产放行系统。
- **没有认证精度。** 数值来自网格与采样；报告里会给测量条件，但不会给你一张证书。
- **尺寸单位是毫米，Z 轴向上。** 没有单位参数；导入件要自己填单位。

## 分析能力

- **不做精确 FEA / 应力分析。** 有趋势和热点位置，但没有“安全系数”。
- **流体是趋势判断，不是工业级 CFD。** 看流向、死区、压降趋势；不要拿它当验收数据。
- **刚体/机构是运动学 + 干涉时间线。** 它能告诉你“会不会撞、行程够不够”，不告诉你“要多大的力”。

## 网格

- **不修复坏网格。** 不封闭、非流形、多个不相连实体的模型会被**拒收**，并告诉你坏在哪；不会给你一个自信的错误数字。
- **一个零件必须是一个连通实体。** 多个碎片要么合并，要么拆成多个零件。
- **3MF 必须只含一个对象。** 切片软件导出的“一盘多件”会被拒收并说明体数。

## 版本

- **可以浏览、钉住、对比版本；没有 approve / rollback 动作。** 审批与一键回滚尚未实现。
- 每次生成/修改都是新版本，旧版不丢；但“哪一版是正式版”由你记录，工具不替你盖章。

## 导入格式

| 格式 | 状态 |
|---|---|
| STL / STEP / 3MF / DXF | 可用（DXF 需填挤出深度） |
| IGES、OBJ/OFF | **不支持**，会被明确拒绝并给转换建议 |

- 本地预览只读 **STL**；STEP/3MF 要走「导入为版本」，由服务器转换。
- 导入件可以参与装配和验证，但**没有 datum**，除非你导入时声明或之后补。

## 外观 / 颜色

- GLB 只能作为**侧车**保存；面板仍只预览 STL。
- 颜色不是几何通过条件：彩色渲染不代表打印颜色，也不参与可打印性判定。

## 平台差异

| 平台 | 差异 |
|---|---|
| Linux x64、macOS arm64、Windows x64 | 全部能力 |
| macOS Intel | 物理与机构仿真用内置引擎（结果可用）；不装 Python 物理库 |
| musl（Alpine 等） | STEP 导入与通用 CFD 不可用；其余正常 |

## 其他

- **一个会话必须先显式选择项目**（`bind_project` / `init_project`），之后固定；`cd` 不会切换。要换项目，请新开会话。
- **不做多用户 / 权限 / 云部署 / 移动端。** 本地单用户工具。
- **长会话图片过多可能被上游拒绝。** 默认保留 24 张图片窗口；headless 会话可调小。

## 遇到边界怎么办

1. **先看报告说“未评估/跳过”的项**——那通常就是边界所在。
2. **不要用“没报错”代替“检查过”**；边界内的能力也要看证据。
3. **需要边界外的保证**（认证、精确 FEA、工程图）时，明确说“这个工具不给”，改用专业工具，而不是让它假装给。
