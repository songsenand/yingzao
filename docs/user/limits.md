# 边界

以下都是**已知边界**，不是待修的 bug。知道边界，才不会把“没检查”当成“没问题”。

## 精度与认证

- **不做工业级公差、工程图、成品 BOM。** 它是设计验证工具，不是生产放行系统。
- **没有认证精度。** 数值来自网格与采样；报告里会给测量条件，但不会给你一张证书。
- **尺寸单位是毫米，Z 轴向上。** 没有单位参数；导入件要自己填单位。

## 分析能力

- **不做精确 FEA / 应力分析。** 有趋势和热点位置，但没有“安全系数”。
- **流体是趋势判断，不是工业级 CFD。** 看流向、死区、压降趋势；不要拿它当验收数据。
- **刚体/机构是运动学 + 干涉时间线。** 它能告诉你“会不会撞、行程够不够”，不告诉你“要多大的力”。例外是装配检查的轴向弹簧/卡扣静力筛选：它可报安装力、行程端点力、卡扣插入/保持力，但不是接触、疲劳或认证。

## 网格

- **不修复坏网格。** 不封闭、非流形、多个不相连实体的模型会被**拒收**，并告诉你坏在哪；不会给你一个自信的错误数字。
- **一个零件必须是一个连通实体。** 多个碎片要么合并，要么拆成多个零件。
- **3MF 必须只含一个对象。** 切片软件导出的“一盘多件”会被拒收并说明体数。

## 版本

- **可以浏览、钉住、对比版本。** Agent 可以提议“回退到某一版”，你在面板里批准后会生成一个新版本（历史不改写）；没有独立的“版本审批 / 签核”流程。
- 每次生成/修改都是新版本，旧版不丢；但“哪一版是正式版”由你记录，工具不替你盖章。

## 导入格式

| 格式 | 状态 |
|---|---|
| STL / STEP / 3MF / DXF | 可用（DXF 需填挤出深度） |
| IGES、OBJ/OFF | **不支持**，会被明确拒绝并给转换建议 |

- 本地预览只读 **STL**；STEP/3MF 要走「导入为版本」，由服务器转换。
- 导入件可以参与装配和验证，但**没有 datum**，除非你导入时声明或之后补。

## 外观 / 颜色

- GLB 只能作为**侧车**保存；面板仍只预览 STL。
- 颜色不是几何通过条件：彩色渲染不代表打印颜色，也不参与可打印性判定。

## CadQuery（可选内核）

- **CadQuery 不是默认内核，也不是必需依赖。** OpenSCAD 始终保留；四视图渲染、剖切、运动/装配关键帧和网格导出仍走 OpenSCAD。
- **pack 约 1.4–1.6 GiB**，由用户显式安装到 `$DSH_HOME/cad/packs/cadquery`（或 `DSH_CAD_CQ_PACK`），不随 npm 包分发，`setup` 不自动下载。
- **CadQuery 脚本是 Python，以用户权限执行**，不是沙箱。只运行你信任的模型/示例；pack 里的 VTK/OCP 是导入与 B-rep 依赖，不用于本插件渲染。
- **一个项目一个作者内核。** 新版本记录 `backend.kernel`；旧版本不重写。切换内核后旧版本仍按自己的 pin 编译。
- **STEP 是原生旁路产物，不是设计证据。** 设计验证仍以 STL 网格为准；`BRepCheck` 通过不等于尺寸/壁厚/装配通过。
- **Windows/macOS 的本版状态：** 代码已去掉 Linux 专用的 `xvfb-run`/路径假设，但尚未在真机 smoke；不要把它当成“已验证跨平台”。

## 平台差异

| 平台 | 差异 |
|---|---|
| Linux x64、macOS arm64、Windows x64 | 全部能力 |
| macOS Intel（x64） | **不支持**：该平台没有内置 Python 运行时构建（2026-11-16 退役）；请换 Apple Silicon 或 Linux/Windows |
| musl（Alpine 等） | STEP 导入与通用 CFD 不可用；其余正常 |

## 其他

- **一个会话必须先显式选择项目**（由 Agent 选择或新建），之后固定；`cd` 不会切换。要换项目，请新开会话。
- **不做多用户 / 权限 / 云部署 / 移动端。** 本地单用户工具。
- **长会话图片过多可能被上游拒绝。** 默认保留 24 张图片窗口；headless 会话可调小。

## 遇到边界怎么办

1. **先看报告说“未评估/跳过”的项**——那通常就是边界所在。
2. **不要用“没报错”代替“检查过”**；边界内的能力也要看证据。
3. **需要边界外的保证**（认证、精确 FEA、工程图）时，明确说“这个工具不给”，改用专业工具，而不是让它假装给。
