# 从描述到交付

一次完整的使用流程。每一步都写清：**你会看到什么、你要决定什么、不要假设什么。**

## 开始前

- 新建会话时选预设 **「营造模式」**。普通编程会话看不到 CAD 工具，这是有意的：不为没用的插件付工具表开销。
- 第一次用到计算功能会下载约 400MB 的运行时，几分钟；之后所有项目共用。

## 1. 描述

好的描述通常包含五样东西：

| 要素 | 例子 |
|---|---|
| 功能 | 一块安装板，承受一个 20mm 轴承 |
| 尺寸 | 60×40×8mm |
| 接口 | 四角 M3 沉头孔，中心 20mm 通孔，孔距 50×30 |
| 工艺 | FDM / PLA，0.4mm 喷嘴 |
| 验收 | 轴承能压入但不晃；底面必须平 |

不用一次写全。缺的可以后面补；但**工艺和验收标准**越早说，后面的检查越有意义。

## 2. 生成与自检

Agent 会写几何代码、编译、渲染四视图，并**先自己看图**；不满足就自己改。

你会看到：

- 一个新**版本**（v001、v002…），旧版本不会消失；
- 四张视图 + 包围盒尺寸；
- 如果网格有问题（不封闭、多个不相连的实体），会直接警告。

**不要假设**第一版就是最终版。第一版是“代表件”：先确认它的形状和关键特征，再让 Agent 生成同族的其他零件。

## 3. 审阅

在右侧**面板**里看模型。三个问题，按顺序问：

1. **形状对不对？** 旋转看整体；对照你描述的功能，有没有多余/缺失的特征。
2. **配合对不对？** 量关键尺寸（孔距、壁厚、间隙）；用红框标出你怀疑的地方。
3. **动起来对不对？** 如果是机构，用回放看轨迹；在可疑的一帧暂停、指认。

反馈越具体越好：

- 好：“中心孔改成 22，和底面保持垂直，其他不变。”
- 差：“感觉不太对。”

## 4. 迭代

每次修改生成一个新版本。你可以：

- 对比两版的视图和数值；
- 钉住一版作为基准；
- 回看任意旧版，不会丢。

**保留意图**：说“改什么、不变什么”。例如“孔改 22，孔距和外形不变”——否则 Agent 可能顺手改了别的。

## 5. 验证

需要时发起检查。四类，按你的问题选：

| 你想知道 | 检查 | 你会看到 |
|---|---|---|
| 零件本身对不对 | 几何/可打印性 | 尺寸、壁厚、打印悬垂、是否一个实体 |
| 装配对不对 | 装配检查 | 接口逐条结果、间隙、有没有**漏声明**的相邻件 |
| 机构动不动、撞不撞 | 运动检查 | 轨迹、干涉时间线、行程 |
| 流体通不通 | 流体检查 | 粒子回放、趋势数字 |

报告怎么读（被排除 / 困难 / 未排除 / 未评估）见 [验证能力](verification.md#报告怎么读)。报告里的每个“被排除”都会给位置和“实测 vs 要求”，可以直接去面板看那个点。

## 6. 交付

满意后导出：单个版本可选 STL / 3MF / OBJ / OFF / WRL；要交整个项目时用「整机 ZIP」——
每个零件的 STL + 装配清单 + 说明（有清单时另含按位姿摆好的 `assembly.stl`），或「整机 STL」
把整机按装配位置合并成一个多壳网格（不做布尔并集，适合预览/报价）。

交付前建议确认：

- 每个零件都跑过可打印性检查（按你声明的工艺）；
- 装配的每份接口都有结果，没有“跳过”；
- 你要主张的东西（“这个装配能装”“这个件能打印”）有对应的检查记录，而不是只看渲染图。

## 7. 手边有现成的文件

见 [进阶用法 · 导入现成文件](advanced.md)（预览、导入为版本、3MF 单对象、DXF 深度、按路径导入）。

## 一张“不要假设”清单

- 不要假设“渲染好看”= 能打印；
- 不要假设“未排除”= 合格；
- 不要假设“没报错”= 检查过了（看“未评估/跳过”）；
- 不要假设第一版就是对的（先审代表件）；
- 不要假设改一个尺寸不会影响别的（看新版本的报告）。
