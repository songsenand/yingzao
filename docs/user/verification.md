# 验证能力

工具提供**真值**，判断保留给你。下面是它能回答的问题、你会看到什么，以及它**不能**证明什么。

## 五层能力

| 层 | 回答的问题 | 你会看到 |
|---|---|---|
| 几何 | 尺寸对不对、壁厚够不够、有没有干涉、是不是一个连通实体 | 数值 + 报告卡片 |
| 装配 | 谁和谁配合、间隙多少、有没有**漏声明**的相邻件 | 接口清单逐条核对结果 |
| 刚体 / 机构 | 会不会倒、运动过程中会不会撞、行程够不够 | 轨迹与时间线回放 |
| 流体 | 流得通吗、有没有死区 | 粒子回放 + 趋势数字 |
| 工艺 | 按**你声明的工艺**（FDM/SLA/SLS/…），这个件做不做得出来 | 被排除的工艺 + 反例；不给推荐 |

## 报告怎么读

- **被排除**：找到了反例（例如某处壁厚 0.2mm，低于你声明的 0.4mm 喷嘴）。最硬的结论。
- **困难**：有可疑项，或余量落在测量噪声里。不是通过。
- **未排除**：没找到几何反例。**不等于“可制造”**，也不等于“安全”。
- **未评估 / 跳过**：这一项没检查。**没评估不是通过。**

报告里的每个“被排除”都会给位置和“实测 vs 要求”，可以直接去面板看那个点。

## 它不能证明什么

- 不能给**合格证**、安全系数、寿命；
- 不能给认证级精度或工业级公差；
- 不能替代专业 FEA / CFD 的验收数据；
- 不能替你选工艺/材料（那是业务决定）。
