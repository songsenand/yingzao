## The three words

- **Version**: every generation or edit is an immutable version; browse, compare, pin.
- **Panel**: the 3D viewport on the right; orbit, measure, mark problems, replay motion.
- **Report**: the result of one check. It can say “excluded”, “difficult”, “not excluded”, or “not evaluated” — **not evaluated is not a pass**.
