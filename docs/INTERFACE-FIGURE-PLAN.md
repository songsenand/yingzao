## 0. 一句话

**每条装配接口（以及未声明邻接对），在契约表里点击后按需生成一张能自解释的图**：
剖面或局部特写 + 实测值 + 公差 + 判定 + 一句"这意味着什么"。
不预生成、不调 LLM、图随 run 存，作为契约表那一行的补充。

它要解决的不是"没有剖面看"，而是 HARNESS §11.14 的那句话：
**任何"通过/不通过"都要附上"下一步该看哪一张图"**——现在只给了数字和判定。

## 1. 目标 / 非目标

**目标**

- 把 §11.14 的"该看哪一张图"落到每一行，而不是让人自己在 3D 里找。
- 没看过这个零件的人，只看图能回答"这个配合可不可信"。
- 图与数同源：**数字取报告，几何取版本 STL**，不重算（§11.8）。
- 第二消费者：图从 worker 的位姿出，3D 视口从面板的位姿出；两者不一致时能当天发现
  （判例：面板 Euler 顺序 bug 让 3D 视图错位 28°–141°，契约数字却是对的）。

**非目标**

- 不做模板目录 / 场景清单（不按机构分类：圆柱、燕尾、卡扣、齿轮共用一套选面策略）。
- 不预生成、不批量跑、不在 `check_assembly` 里出图。
- 不做独立图库 / 画廊；图只挂在它解释的那一行上。
- 不替代 3D 视口、剖切、测量工具；它是"行的附件"，不是新视图模式。
- 不在本轮改任何代码。

## 2. 用户故事与 UX

1. 人在契约表看到一行 `同轴-B01-a · O5.sock0 ↔ B01.pegA · 0.000 · pass`。
2. 行尾有"图"入口（无图时置灰并说明原因）。
3. 点开浮层：左边图，右边该行的 `measured / expected / detail`；底部
   「下载 PNG」「下载 SVG」「换一个方向」「重新生成」。
4. 默认 1 张；「换一个方向」按需生成下一张（懒生成），最多 4 张，缩略图条 + 当前平面参数。
5. 图角写身份：`run / interfaceId / manifestHash / versions / 模板 / 平面参数`。
6. 仿真运行：事件行 → 三联图（接近 / 干涉 / 就位）+ 事件时间 + 干涉体积；同样懒生成。
7. 无图原因（不静默，§11.7）：`缺 datum` / `未声明邻接` / `切面退化` / `版本 STL 缺失`。

## 3. 数据与生命周期

```
点击行
  → GET /api/cad/figure?run=r099&iface=同轴-B01-a&plane=roll:45
  → host: 读 run 的清单快照 + 版本 + 报告（数字只从报告取）
  → worker: figure_section（两实体 + 任意平面 + loops/holes）
  → host: 写 runs/<id>/figures/<slug>.svg + figures/index.json
  → panel: <img> + 该行 measured/expected + 下载
```

- **懒生成**：`check_assembly` 不跑图；首次点击才生成，之后读缓存。对应 §11.11
  （"成本方案的第一判据是对正在进行的会话有没有影响"）。
- **缓存键**：`manifestHash + versions + interfaceId + 模板 + 平面参数`。
- **清单快照**：check 时把 manifest JSON 存进 run（现在只有 `manifestPath` + `manifestHash`）。
  否则清单改了会出现"图是新的、判定是旧的"。
- **失效**：hash 变 → 旧图标 stale（红点），**不删**（还能对照）。
- **存储**：SVG（无新 pinned 依赖）；PNG 在浏览器里把 SVG 画进 canvas 再下载。
  若坚持要 PIL 那张的观感，需把 `pillow` 加进 `python-lock.ts`（+1–2 人日）。

## 4. 视图选择：通用策略，不按机构

清单里的接口本来就有 datum 类型（`datum` 点 / `datum_axis` 轴 / `datum_plane` 面 /
`datum_cyl` 圆柱）和测量量（距离 / 同轴 / 直径 / 行程）。切面从这两样推：

| 接口声明 | 切面 | 图上标什么 |
|---|---|---|
| 轴 ↔ 轴（同轴 / 直径） | 含公共轴；滚转角取"切到最多材料"的那一个 | 单边间隙、入孔深度、卡珠/槽 |
| 轴 ↔ 点 | 含轴与点 | 点到轴距离、端隙 |
| 面 ↔ 面（贴合 / 滑动） | 垂直于接触面、过接触点 | 面间隙、重叠量 |
| 点 ↔ 点（距离） | 含两点连线；滚转取最多材料 | 距离、公差带 |
| 没有 datum（未声明邻接） | 最近点连线；切不出东西就退局部轴测 | 最近距离 + "未声明"徽标 |

**选面启发式**：在候选滚转角里取"切到最多材料 / 最少碎片环"的那个；用户可手动滚转，
按接口记住选择。切面退化（切空、只切到缝）时自动退到局部轴测特写，并在图角注明。

**为什么不是"每种机构一个模板"**：燕尾、卡扣、齿轮的差异在**切面方向**和**标注语义**，
不在渲染器。按 datum 类型选面 + 按 `check` 类型选文案，一套编译器覆盖全部；
真正决定图好不好看的是**清单有没有把这对零件的 datum 声明出来**。

## 5. 同一接触面多平面

两种"多平面"，不是两个模板：

| 模式 | 用在 | 怎么切 |
|---|---|---|
| **绕轴滚转**（roll fan） | 轴↔轴、圆柱配合 | 0° / 45° / 90° / 135° 绕 datum 轴；默认 45° 避开卡脚缝，按需换到 0°/90° 把缝和倒扣露出来 |
| **沿法向平移**（offset stack） | 面↔面、平面接触 | 在接触重叠区的 25% / 50% / 75% 各切一刀，看间隙沿接触面的变化 |

- **默认只出 1 张**；"换方向"再生成下一张（仍懒生成），最多 4 张；缩略图条 + 平面参数。
- 对圆柱配合，绕轴转不改变名义配合（轴对称），改变的是"切到了哪个特征"——
  多平面的价值是**暴露被单平面藏住的缝/倒扣/卡珠瓣**，不是看"另一个配合"。
- 判例：`examples/glucose-molecule` 的 `y=0` 剖面正好落在 0.6mm 开缝里，剖面里根本没有
  卡脚壁——"单平面骗人"的现成例子。

## 6. 图上必须有什么

- 两个实体的剖面填充 + 剖面线 + 轮廓；datum 轴线（点划线）、定心平台线。
- 尺寸线：实测值 + 公差带，颜色按判定（pass/warn/fail）。
- 引线标注：单边间隙、壁厚、入孔深度、卡珠/槽（能取到就取，取不到不编）。
- 图角身份 + 一句"这意味着什么"（按 `check` 类型 + 实测值生成，例如
  "单边 0.10mm，卡珠过喉口靠弹性；刚性引擎报的 0.769mm³ 不是干涉"）。
- **所有数字只从报告取**（§11.8）；几何只负责画。

## 7. 覆盖不变量（"所有交互"的可测试定义）

> 对 `report.results` 里的每一条接口、`report.undeclared` 里的每一对邻接：
> **要么有一张图，要么有一条 `noFigureReason`**；面板每一行都有入口（无图时置灰并说明）。

这是验收判据，也是"降低心智负担"的关键：图挂在用户正在看的那一行上，不是另一个要导航的图库。

## 9. 施工门槛（先做 3 天原型）

- **P0（3 天）**：一个接口、一张图、懒生成、数字取报告、图角带身份。
- **度量**：找一个没看过这个零件的人，只看图回答"这个配合可信吗"，数**追问次数**；
  和现在的纯文本表对比。追问明显下降 → 投 MVP；没有下降 → 保留原型，不扩。
- **第二度量**：图（worker 位姿）与 3D 视口（面板位姿）不一致的次数——上次 Euler bug
  这类问题本可以当天暴露。
- P1（+2 天）：多平面按需。
- P2（+4 天）：关键帧三联图，只在 P0/P1 证明有用后。
- **不做**：模板目录、批量预生成、独立图库。

## 10. 对照 HARNESS.md

**支持它的条款**

- **§11.14**："任何'通过/不通过'都要附上可疑位置——哪里、为什么可疑、下一步该看哪一张图
  或哪一个坐标。" 本功能就是这句话的实现。
- **§4**：人的通道"看/指"；图是预先瞄准的"指"。
- **§11.8 单一权威副本**：图上的数字必须来自报告，不重算。
- **§11.9 可证伪**：覆盖率不变量可写进验收。
- **§11.11**：懒生成，不影响会话。
- **§6.1**：渲染图的最低检查是"图出得来、参数可追溯"。

**张力**

- **§2**："查看是 commodity，闭环才是壁垒。" 做成"又一个剖面查看器"就是 commodity。
- **§11.1**："闭环优先于功能面。" 本功能不增加验证能力，只增加人的审阅带宽。
- **§11.17**："场地优先于产品。" 不能因为"CAD 有剖面"就补。

**结论**：窄定义匹配（每条判定的注意力附件），宽定义不匹配（所有交互的图库/模板目录）。
本轮按窄定义记录，按 3 天原型设门槛，不直接批 MVP。

## 11. 商业 CAD 参照（2026-10-27 查）

- **剖面本身是 commodity**：Fusion 360 的
  [3D section view](https://help.autodesk.com/view/fusion360/ENU/?guid=SLD-SECTION-ANALYSIS)、
  SolidWorks 的[图纸剖视图](https://help.solidworks.com/2026/English/solidworks/sldworks/HIDD_DVE_SECTION_PROP.htm)、
  Creo Illustrate 的[剖切](http://support.ptc.com/help/creo/illustrate/r5.1/zh_TW/creo_illustrate/shared/To_Section_in_the_3D_View.html)
  都有；交互式、临时、或图纸里手摆。
- **技术插图**：SolidWorks Composer、Creo Illustrate 能出带
  [引线/标注](https://www.goengineer.com/blog/make-callouts-visible-solidworks-composer-digger-tool)、
  爆炸、剖面的说明书图——但引线是人摆的，不是从接口契约生成。
- **公差分析**：[CETOL 6σ](https://www.sigmetrix.com/blog/cetol-v12-3d-tolerance-analysis-software-now-available-from-sigmetrix-)、
  [3DCS](https://www.3ds.com/partners/solutions/200000000001593_PDT00000000086_3DCS_Variation_Analyst__VA__CAAV5)
  给贡献量、敏感度、超差率，常带彩图；不是"每条接口一张剖面 + 判定"。
- **未找到**"由可执行 ICD 驱动、每条接口自动生成带实测值/公差/判定的剖面"的现成商业组合。
  差异化不在剖面，在**绑定**：interface row ↔ 图 ↔ 实测 ↔ 判定。

## 12. 未决问题

1. **SVG 还是 PNG/Pillow**：SVG 不加 pinned 依赖、可缩放、浏览器字体支持中文；
   PIL 更像 `examples/glucose-molecule/renders/interface_section.png` 的观感，但要加依赖。
2. **清单快照还是仅 hash**：没有快照就有"图新、判定旧"的风险。
3. **切面启发式**：默认滚转角、候选数量、是否按接口记住用户选择。
4. **字体**：SVG 在浏览器里能中文；导出到外部取决于查看器。
5. **是否同时开 `render_figure` 工具**：一门两开（UI 按钮 + 工具），还是只做 UI。
   若开，必须与 UI 走同一实现（DESIGN §30 的三发起路径纪律）。
