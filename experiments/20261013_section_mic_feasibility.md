# 实验报告：截面最大内切圆（MIC）量通道瓶颈半径 —— 可行性验证

## 目标

用户提出的路线（原话）：**"用空隙法向量垂直的界面平均截取多次，获取空隙的截面的最大内切圆，
并取其中最小的那个……（更换不同的角度）再求其最小的那个最大内切圆，最后根据这些数据评估这个空隙。"**

本实验回答两件事：
1. 这条路线**是否可行**（能不能量出通道瓶颈、成本如何）；
2. 它能不能**避开**体素小球那条路踩到的坑（`tightestPassageRadiusMm` 的 1.600mm 平台，
   见 `experiments/20261013_void_reach_tightest_plateau.md`）。

## 假设

- H1：截面最大内切圆的**最小值** = 通道瓶颈半径（能通过的最大球半径）。
- H2：它不需要体素、不需要 pitch、不需要"2 体素噪声地板"，因此不会重现 1.600 那类伪值。
- H3（反面）：任意角度取最小会**假报窄**（擦切出薄片），所以角度不能自由扫。

## 方法

探针：`experiments/scripts/probe_section_mic.py`（本次新增）。

数据通路全部是**已有构件**，没有新写几何算法：

| 步骤 | 现成构件 |
| --- | --- |
| 平面切网格（精确，非体素） | `trimesh.intersections.mesh_plane` —— `op_measure_section` 已在用 |
| 线段闭合成面、孔的处理 | `shapely.ops.polygonize` + `unary_union` —— `op_measure_section` 已在用 |
| 面属于材料还是空隙 | 面内一点做实体测试（`mesh.contains`）—— `op_measure_section` 的 `is_material` 同一手法 |
| **截面的最大内切圆** | `shapely.maximum_inscribed_circle`（shapely 2.2.0 / GEOS 3.14.1，**已随依赖装入**） |

夹具（全部已知答案，无随机）：
- 方槽 `20×20×10` 方块开 `宽 × 40 × 6` 贯通槽，宽 = 3.0 / 4.0 / 6.0mm ⇒ 真值半径 = 1.5 / 2.0 / 3.0mm；
- 盲腔：`10×10×2` 板开 `8×8×0.5` 口袋 ⇒ 真值半径 0.25mm（**阴性对照**：不该被当成通道能力）。

## 结果

### 1. 通道瓶颈：精确命中真值，且与体素小球同一批夹具对比鲜明

| 槽宽 | 横向单刀 MIC | 沿轴 7 刀取最小 | 真值 | （体素小球） |
| --- | --- | --- | --- | --- |
| 3.0mm | 1.5000 | **1.5000** | 1.50 | 1.600 |
| 4.0mm | 2.0000 | **2.0000** | 2.00 | 1.600 |
| 6.0mm | 3.0000 | **3.0000** | 3.00 | 1.600 |

三个宽度各自命中真值；体素小球把三个宽度全压成同一个 1.600。
单刀耗时 **1–2 ms**（体素小球单次 1.7–2.8s，且要先体素化 1.7M 体素）。

### 2. 换切法：擦切/平行切**不回答**，而不是给假窄值

| 切法 | MIC |
| --- | --- |
| ⊥ 通道轴（横向，中心线必须穿过） | 3.0000 |
| 与通道轴平行（x=0） | **无空隙面（不回答）** |
| 贴槽壁擦切（斜率 0.05） | **无空隙面（不回答）** |
| 斜切 11° | 3.0000 |

H3 担心的"擦切出薄片 → 假报窄"在这些夹具上没有发生：`polygonize` 只返回**闭合**的面，
擦切产生的开条带不构成面，于是直接"没有答案"。这比"给一个错误的窄值"安全。

### 3. 阴性对照：盲腔会**高报**（必须拦住）

| 切法 | MIC |
| --- | --- |
| ⊥ 薄的方向（腔内 z=0.75） | **4.0**（= 腔宽的一半） |
| ⊥ 腔宽方向（x=0） | 无空隙面 |

一个 0.5mm 深的口袋，几何上能过的球半径是 0.25mm，但截面法给出 **4.0mm**（高报 16 倍）。
换正交切法也救不回来（另一个方向没有面）。
⇒ **盲特征不能走这条判据**；这与 2026-10-11 的决定一致（盲特征一律报**未判定**，
"是否积住"不是几何事实）。

## 分析

### 为什么它是**可证**的（这是关键，不只是"更准"）

设空隙体为 V，`dt(p)` = 以 p 为心的最大内切球半径。对任一平面 P：

> 若 `B(p, r) ⊆ V` 且 `p ∈ P`，则 `B(p,r) ∩ P` 是 P 内一个半径 r 的圆盘，也落在 `V ∩ P` 里。
> 于是 **`MIC(V ∩ P) ≥ max_{p ∈ P} dt(p)`**。

因为"半径 r 的球穿过通道"意味着球的**心**必须从一端连续走到另一端，而一张**把两端分开**的
平面 P 必然被这条心路穿过。所以：

> **只要 P 把通道的两端分开（横向切），`MIC(V ∩ P) < r` 就证明半径 r 的球过不去。**

这是**否决方向的可证性**，与项目既有的"证明用于否决、估计用于放行"一致。反过来：
`MIC ≥ r` 只说明这张切片上放得下一个圆盘，**不能**推出球能穿过 —— 所以正面结论仍只能是
`not-excluded` + 实测值 + 披露（与 2026-10-11 对通道类规则的裁定一致）。

**推论 1**：切平面不能自由扫角度 —— 只有"分开通道两端"的平面才有上述含义；擦切/平行切
没有这个性质，其 MIC 可以任意小或不存在。用户说的"更换不同的角度"，必须加上这个前提。

**推论 2**：截面的**法向应由通道的局部轴向决定**（而不是扫角度）。轴向可从几何本身取
（空隙区的骨架/局部主方向，或"截面面积最小"的那个方向）。

### 为什么它天然避开了 1.600 那类问题

| 体素小球 | 截面 MIC |
| --- | --- |
| 判据是"球**扫不到**哪" ⇒ 圆球永远扫不到方角 | 判据是"这张切片里能塞进多大的**圆**" ⇒ 角不参与 |
| 需要离散步长 pitch，答案落在 pitch 整数倍上 | 精确几何，无步长 |
| 残片要跨过固定的"2 体素"噪声地板 | 无噪声地板 |
| 圆球 vs 方角的不匹配会**假报窄** | 角不进入判据，无此偏置 |

### 待定的"比值"（用户说可以继续讨论）

原带宽来自**体素 pitch**（±0.2mm）。截面法没有 pitch，带宽要换成"这次测量自身的分辨率"，
候选（都可从几何/容差本身算出，不需要自编工艺常数）：

1. **剖分误差**：`$fn=64` 的孔，多边形比真圆内缩 0.002mm 量级（弦高）。可由截面多边形
   自己算出来（内切圆 vs 外接圆之差），是**可测量的**仪器属性。
2. **MIC 求解容差**：现用 1e-4mm（GEOS 的收敛容差），可随报告披露。
3. **截面简化容差**：`op_measure_section` 现用 0.01mm。

若取候选 1（约 0.01mm 量级），"困难带"会从 ±0.2mm 收到 **±0.01mm 量级** —— 这既是收益
（"刚好塞满"能真正被标成困难，而不是被 0.2mm 的粗糙带宽吞掉），也是**新的权衡**：
带宽太窄，"困难"几乎不再触发。这一点需要拍板。

## 遇到的问题

1. **上一轮为什么走了体素小球**：查遍 `docs/DECISION-LOG.md`、`execution_summaries/`、
   `experiments/`，关于 S2-b 的记录只有**体素小球**那条（2026-10-11：`distance_transform_edt`
   + 阈值二分 + 连通性），以及"S2-b 闭环、体素引擎挂起"的裁定。
   **用户提的截面最大内切圆路线没有落进任何记录** —— 这是漏档，本轮补上。
2. 本探针只覆盖**贯通**通道的已知答案；变截面（锥形/弯曲）通道、带内部支柱的截面、
   以及"多开口腔"还没有夹具。`maximum_inscribed_circle` 对**带孔**的多边形是正确的
   （实测 10×10 减 4×4 的框给出 1.7574 = 真值，中心落在离外角与孔角等距处），所以带支柱的
   截面应当也能算对，但未验证。
3. 判断"这个截面属于贯通通道"仍是**未解决**的前置问题（P 是否把两端分开）。它决定
   一条测量值能不能进"通道"这条规则；需要单独设计。

## 结论与下一步

- **结论：这条路线可行，且优于体素小球**：精确命中已知答案（1.5 / 2.0 / 3.0），
  无 pitch、无噪声地板、单刀 1–2ms，且**在否决方向上是可证的**（横向切 + `MIC < r`）。
  三个宽度不再被压成同一个数，1.600 那类伪值的**产生机制不存在**。
- **必须先定死的三点**（否则会从一个错误滑到另一个）：
  1. **取最小，不取平均** —— 沿通道等距多刀，值是各刀 MIC 的**最小**（瓶颈）。平均会把最窄处抹掉。
  2. **切平面必须把通道两端分开**（横向切），法向由通道局部轴向决定；不满足就不回答。
     这是"可证"的前提，也是"换角度"的边界。
  3. **盲特征不走这条判据**（实测高报 16 倍），报未判定 —— 沿用 2026-10-11 的裁定。
- **待拍板的比值**：困难带的带宽（候选：剖分误差 ~0.01mm / MIC 容差 1e-4 / 简化容差 0.01）。
- **下一步（待确认后动手）**：写成 worker op（暂名 `op_passage_bottleneck`）→ 在
  0.8/3/4/6mm 槽 + 贯通孔 + 变截面通道 + 盲腔（阴性）上做已知答案验收 → 再接规则。
