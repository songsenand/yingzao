> 代码基线：`d6e237e`（2026-11-07）。所有“现状”断言都能落到文件与行；所有“实测”都能用

## 定位校正：这是场地能力，不是产品功能

> `HARNESS.md` §6.1 / §11.17：**我们不是产品公司，是场地。** 插件是厂房，不是产品；
> 场地提供三通（水/电/路）、质检、原材料与分级支持，不替用户决定生产什么，也不承诺
> “功能表完整”。缺口是否补，由真实任务与场地投资回报裁决，不按竞品功能表补齐。

本报告的早期草稿曾按“产品路线图”写（Stage 0→4），这是错位。按场地原则，弹性仿真应被定义为
**一类场地能力**，不是“弹簧设计产品”：

| 场地提供 | 用户/LLM 提供 |
|---|---|
| 弹性行为的**通用表示**（元件/区域/载荷/边界） | 设计意图：哪里要弹性、要多大行程、能接受多大变形 |
| **模型分级路由**：解析 → 线性 → 动力学 → 大变形 → 接触 | 选择哪条路、接受哪一级的支持程度 |
| **求解器/检查器**与适用域声明 | 材料数据、校准件、实测 `k`/曲线 |
| **质检**：单位、残差、收敛、证据、边界 | 产品决策、安全责任、最终验收 |
| **原材料**：示例、基线、skill 地图、材料 intake 格式 | 自带几何、自带脚本、自带第三方数据 |

因此，弹性仿真的目标不是“交付一个能设计弹簧/卡扣的产品”，而是：

1. **让这类问题在场地里可问、可算、可验**；
2. **每一级支持都写明能答什么、不能答什么、需要用户自备什么**；
3. **缺口明说**：S3/S4 没做到就标“实验/边界”，不拿线性结果冒充大变形，不拿一维弹簧
   冒充卡扣；
4. **不承诺全覆盖**：按真实任务与投资回报决定补到哪一级，而不是因为“竞品有”或
   “功能表该完整”。

这也是为什么它紧迫：真实玩具设计里弹簧/卡扣反复出现，场地目前对**一整类问题**无能为力；
这不是“产品少一个功能”，是**场地的一条路不通**（§6.1 的“电”——力学验证）。但补法仍然是
场地补法：通一条**通用**的路，而不是给每个产品做定制工具。

另一个定位含义：**我们还没到准生产力档**（HARNESS §7）。所以弹性仿真也不该按“认证级
FEA”立项。场地先要的是 **toy-grade 的通用可答性**：能判断“这个弹簧/卡扣能不能实现功能、
风险在哪、下一步看什么”，而不是 ±5% 的力。精度是边界，需要时交给认证工具；场地负责把
问题问清、把趋势/风险/证据给到、把不能答的部分标出来。

**场地明确不提供：** 弹簧/卡扣的“产品设计结论”、材料性能保证、认证/安全合格证、隐藏
模型类别的“自动答案”。场地提供的是能力、适用域、质检与交接；产品由用户定义、用户负责。

## 精度分层：功能性、数量级、精确值

> 这条要求**显著降低实现门槛**，但不是“不用算”。它把问题从“算准”改成“判对 + 给区间 +
> 知道何时不可判”。下面三层是场地对用户的承诺边界，不是产品功能表。

| 层级 | 回答的问题 | 输出 | 方法 | 谁负责 | 成本 |
|---|---|---|---|---|---|
| **A 功能性** | 装得上吗？压得动吗？扣得住吗？会不会卡死/屈曲/断裂？ | 三态（works / works-with-risk / does-not-work / unknown）+ 失败模式 | 几何/运动/干涉 + 解析/梁公式 + 保守判据 | 场地 screening | 低 |
| **B 数量级** | 力大概多大？人力/工具/机器？应变在弹性/屈服/断裂哪档？ | 十倍区间/档位 + 适用域 + 置信 | 解析/梁/线性 FEM + 参数区间 | 场地 screening | 中 |
| **C 精确值** | 具体多少 N？±10%？ | 点值 + 误差/校准/收敛 | agent 自写代码/外部求解器/实测 | agent/用户（场地只做质检） | 高 |

**A 层是“功能性”，不是“精度”。** 例如“弹簧可压缩”= 行程 > 0、安装长度 > 并圈高度、
压缩过程中不会先屈曲/卡死；“卡扣能扣上”= 倒扣深度 < 梁的最大可恢复挠度、根部应变 <
许用、插入路径无自锁；“按钮能按”= 行程足够、回弹力 > 摩擦、力档位落在用户声明的预算内。
这些多数是**几何 + 运动 + 解析判据**，不需要 FEA。

**B 层是“数量级”，不是“点值”。** 输出十倍档位（如 `1–10 N`、`10–100 N`），并写明
参数区间与适用域。材料 E 取 `[E_min, E_max]`、摩擦取 `[μ_min, μ_max]`，用**上下界**
而不是单点；只要上下界落在同一侧，结论就是稳健的。**若区间跨过判定阈值，返回
`unknown`/`works-with-risk`，不压成 pass/fail**——这是 HARNESS §11.10“阈值必须报余量”
在弹性件上的直接应用。

**力的显示档位（只用于沟通，不是验收标准）：**

> 这张表是**刻度**，不是**标准**。是否“人力可达”由用户/agent 声明的 `forceBudget`
> （`maxForceN`、适用场景、来源）决定；场地只负责把估算力放到刻度上、与预算比较、
> 报余量。没有声明预算 → `unknown` / `skipped`，不判 pass。场地**不替用户决定**
> 儿童/成人、玩具/工具的阈值——那是设计输入，不是场地政策。

| 显示档位 | 大致范围 | 参考例子（不是场地标准） |
|---|---|---|
| 极轻/摩擦主导 | `< 0.1 N` | 轻触、易脱落 |
| 手指轻 | `0.1–1 N` | 轻按钮、薄膜开关 |
| 手指舒适 | `1–10 N` | 普通按钮、小卡扣 |
| 硬按 | `10–50 N` | 紧卡扣、大按钮 |
| 双手/工具 | `50–200 N` | 紧配合、工具辅助 |
| 工具/机器 | `> 200 N` | 压机、结构卡死 |

这张表只是沟通刻度；你的按钮预算由你/agent 给，场地只负责把估算力落在刻度上并比较。
若预算未声明，场地报 `unknown`，不替用户决定“儿童/成人”阈值。**场地给尺子，不给标准。**

**阈值归用户，场地只给尺子。** 这里要区分两类判断：

- **内在不可能**：安装长度 < 并圈高度、行程为负、受压弹簧被当拉簧、几何上过不了倒扣——
  这些不需要用户阈值，场地可以直接判 `does-not-work`（但仍要写明判据）。
- **验收判断**：力是否“人力可达”、应变是否“可接受”、卡扣保持力是否“够”——这些必须由
  用户/agent 声明 `forceBudget` / `maxStrainPct` / `retentionLoadN` 等；没有声明就
  `unknown` / `skipped`，不判 pass。这和 `check_assembly` 的“没有 tolerance 就不是 pass”
  是同一条纪律（[assembly-check.ts](../dsh-cad-harness/src/host/assembly-check.ts#L380)）。

**C 层是“精确值”，场地不垄断。** 需要 ±10% 或复杂接触/超弹/疲劳时，由 agent 自写
代码、外部求解器或实测完成；场地提供几何/材料/边界导出、运行时、以及**质检**
（单位、平衡、能量、收敛、解析基准），但不替 agent 的模型背书。详见 §4.11。

**这条要求降掉了什么、留下了什么：**

| 原来难 | 在 A/B 层还需要吗 | 说明 |
|---|---|---|
| 材料精确参数 | 不需要点值，需要范围 | E ±30% 通常仍能判数量级；C 层才要校准 |
| 细网格/收敛 | 不需要 | 梁/解析/粗线性；薄件用梁/壳，不用体素硬啃 |
| 接触摩擦标定 | 不需要精确 | 摩擦角区间 + 保守假设；复杂接触转 C 层 |
| 非线性求解 | 多数不需要 | 大变形用梁公式/简化；跳跃用能量/极限点判据 |
| 疲劳/蠕变 | 不需要 | 明确说“不做寿命”，不假装 |
| **表示/选路** | **仍然需要** | 不知道 behavior/边界/载荷，就算不出 |
| **适用域/拒绝** | **更需要** | 粗糙模型越界会错 10 倍；必须知道何时停 |
| **失败模式** | **仍然需要** | 力够但会断/屈曲/卡死，等于没答 |
| **几何/接触拓扑** | **仍然需要** | 卡扣能不能过倒扣，首先是几何+运动问题 |

**结论：** 门槛确实降了，降的是“精度成本”（材料校准、细网格、接触标定、非线性求解、
寿命）；**没降的是“判据成本”**（表示、选路、适用域、失败模式、几何/接触拓扑）。后者
才是这条 lane 的主要工作量，也是场地该投资的地方。

## 摘要（先读这段）

1. **空白是结构性的，不是缺一个工具。** 五条引擎没有一条能**直接**回答弹性元件需要的
   力—位移/刚度/行程/接触行为；`stress` 只能在线性小变形下给一个载荷—位移点，给不了
   曲线、大变形、屈曲或接触。装配检查里 `spring-behaviour` 只有声明、没有实现。
2. **最痛的是“表示”**：弹性是行为，不是几何；当前没有地方声明 `k / L0 / 预紧 / 阻尼 /
   行程 / 座面 / 参数来源`。这比“求解器不够强”更靠前，也更容易补。
3. **第二痛的是薄特征 + 大转动**：体素网格对 0.4–1 mm 的 living hinge 是结构性不匹配；
   线性 FEM 对 30–90° 转动是模型错误。两条都不能靠“调细网格/调大载荷”绕过。
4. **接触是分水岭**：卡扣、并圈、自接触是另一个数量级的工程；材料数据不足时，优先
   梁理论 + 实测校准，不要自研全量非线性接触 FEM。
5. **rapier 弹簧关节可用，但必须包一层证据**：实测发现 mm/kg/s 下 `1 N/mm = 1000`
   内部单位（1000× 陷阱），且高阻尼会把 1 kg 质量停在离锚点 0.19 mm 处而不是正确的
   −19.81 mm——它会“settled 但错”。单位换算、力/能量输出、平衡残差、解析对拍缺一不可。
6. **场地能力分级（不是产品版本）**：S0 声明式弹性元件 + 行为校核（1–2 周）→ S1 线性
   刚度探针 + 简单卡扣梁校核（2–4 周）→ S2 力元件/弹簧动力学与静平衡（4–8 周）→ S3 大变形梁/壳（按需）→
   S4 接触/非线性（边界或外部求解器）。每一级独立可用，标明支持程度；材料校准与耐久性
   并行，没有校准件就不承诺精度。
7. **精度分三层，门槛降在“精度成本”上**：A 功能性（三态 + 失败模式）、B 数量级（十倍
   档位 + 参数区间）、C 精确值（agent 自写代码/外部求解器/实测）。A/B 不需要材料校准、
   细网格、接触标定、非线性/寿命；但表示、选路、适用域、失败模式、几何/接触拓扑仍是
   硬工作。C 层场地不垄断：提供几何/材料/边界导出、运行时与质检，agent 自写模型始终可走。
   力档位只是显示刻度；验收阈值由用户/agent 声明，场地不替用户定标准。

## 目标

> 插件目前对**弹性元件**（弹簧、柔性铰链、卡扣、弹性垫、橡皮筋等）的仿真几乎是空白。
> 本调研要回答三件事：
>
> 1. **空白到底有多大**——五条引擎各自能回答哪类弹性问题，哪类完全答不了；
> 2. **难点在哪**——是“加一个弹簧关节”这种工程量，还是模型、材料、接触、数值、
>    验证层面的结构性难题；
> 3. **怎么走代价最小**——哪些问题用解析/一维元件就能诚实回答，哪些必须上大变形
>    非线性有限元，哪些现在就不该碰。

## 假设

> 调研前的工作假设（后面逐条用代码与实测检验）：
>
> 1. 现有五条引擎中，没有一条能直接给出“可变形弹性件的力—位移曲线”（`stress` 的
>    小变形线性点除外）；
> 2. 最容易被低估的不是求解器，而是**表示层**：弹性是行为，不是几何，当前管线没有
>    地方声明 `k / L0 / 预紧 / 阻尼 / 行程 / 座面`；
> 3. 打印柔性件（living hinge、卡扣）的障碍分层：**A/B 层**主要是表示、选路、适用域、
>    失败模式；**C 层**才是大转动 + 薄特征 + 接触 + 材料本构；
> 4. rapier 0.20 的原生 `JointData.spring` 能覆盖“离散弹簧驱动机构”的一大半问题，
>    但它不是经过验证的力元件，不能直接当仿真结果暴露；
> 5. 材料数据（FDM 各向异性、TPU 超弹、蠕变）是 **C 层**精度的上限；A/B 层用参数
>    区间/默认范围即可，不需要精确校准。换更贵的求解器不能自动解决材料问题。

3. **实测 rapier 弹簧关节**：用一个 1 kg 合成质量、1 N/mm 弹簧、mm/kg/s 单位系，

4. **按难度分层**：表示、本构、几何非线性、稳定性、接触、动力学/静平衡、数值/性能、

5. **路线对比与分期**：解析元件、线性刚度探针、rapier 弹簧关节、梁/壳、非线性实体

## 结果

### 1. 现状：五条引擎各覆盖一段，弹性件没有完整答案

| 引擎 | 它实际在算什么 | 能回答的弹性问题 | 答不了的 |
|---|---|---|---|
| `simulate_motion` | **运动学 + 精确干涉时间线**；rapier 只当约束求解器，无碰撞体、无重力；驱动是规定的曲柄/振荡器（[motion.ts](../dsh-cad-harness/src/host/motion.ts#L1)） | 给定驱动下“会不会撞、行程够不够” | 弹簧力驱动的机构（没有规定驱动，位姿由力平衡决定）；任何力、变形、预紧 |
| `simulate_physics` | **刚体 + 重力 + 接触**；关节只有 `revolute` / `prismatic`；输出无力/扭矩（[physics.ts](../dsh-cad-harness/src/host/physics.ts#L31)） | 刚体在重力下会不会倒、滑块能不能停住（`staticFriction` 是解析估算） | 弹簧、柔性体、力—位移曲线、预紧力、弹簧驱动机构的稳态 |
| `simulate_stress` | **线弹性、各向同性、小变形、静态**体素 hex8 + matrix-free CG；只有力载荷/自重，没有接触（[stress_fem.py](../dsh-cad-harness/python/cad_worker/stress_fem.py#L1)） | 给定载荷下的位移/应力场、反力、截面力；薄件会被判“不可信” | 大转动、大变形、屈曲、跳跃、接触、塑性、超弹、疲劳；也不能直接给“弹簧刚度” |
| `check_assembly` | 几何接口检查；`弹簧` 类型默认映射到 `spring-behaviour`，但该算子**没有实现**，只有 `spring-preload` 是 `k·δ` 的算术（[assembly-check.ts](../dsh-cad-harness/src/host/assembly-check.ts#L415)、[L427](../dsh-cad-harness/src/host/assembly-check.ts#L427)、[L592](../dsh-cad-harness/src/host/assembly-check.ts#L592)） | 已知 `k`、自由长度、安装长度时的预紧力算术 | 弹簧行为本身；`k` 从哪来、是否合理；方向、座面、并圈、屈曲、疲劳 |
| `simulate_fluid` / `simulate_lbm` | 固定边界 MPM / 格点 LBM | 与弹性件基本无关 | 流固耦合、弹性边界（[engines.md](../docs/llm/engines.md) 明确“柔性体”在都不能回答之列） |

**结论 1：空白是结构性的，不是“少一个工具”。** 现状是“几何 + 刚体 + 线弹性静力”三条腿；
弹性件要求的是“**行为 + 几何非线性 + 接触 + 材料非线性 + 静/动平衡**”的组合，缺的是
一整套模型类别。

**结论 2：当前唯一能落地的弹簧能力，是 `spring-preload` 的算术。** 它把安装长度量出来，
乘上**调用者声明的** `k`，报一个力。它不验证 `k` 是否与几何/材料自洽，也不管方向、座面、
并圈、屈曲。这不算仿真，但它是诚实且有用的第一步。

### 2. 弹性元件的分类：不同类的难度差一个数量级

| 类别 | 典型件 | 主导行为 | 用户真正要的输出 | 主导难点 | 合适的模型 |
|---|---|---|---|---|---|
| 轴向螺旋弹簧 | 压簧、拉簧、模具弹簧 | `F = k·(L0−L)`，并圈、屈曲、颤振 | 安装力/预紧、行程、并圈余量、屈曲临界 | 低（有目录 `k`） | 一维弹簧元件 + 解析校核 |
| 扭转弹簧 | 扭簧、发条、双扭簧 | `T = kθ·(θ−θ0)`，非线性、线圈绑定 | 扭矩—角度、预紧角、最大转角 | 中（角弹簧、非线性） | 一维角弹簧 + 解析 |
| 柔性铰链 / living hinge | PP/TPU 薄片铰、交叉簧片 | 大转动、小应变；非线性弯矩—转角 | 刚度、行程、最大应变、疲劳 | 高（几何非线性 + 薄特征） | 共旋梁/壳 |
| 卡扣 / 弹性卡脚 | 悬臂钩、环形卡扣、snap-fit | 大挠度 + 接触 + 摩擦 + 屈服 | 插入力、保持力、是否断裂/白化 | 很高（接触 + 材料非线性） | 简单悬臂：梁级解析 + 摩擦角；复杂倒扣/自接触：非线性梁 + 接触，或实体 FEM |
| 弹性垫 / 密封圈 / O 形圈 | TPU 垫、硅胶圈 | 超弹、近不可压、大应变、粘弹 | 力—位移、接触压力、蠕变 | 很高（本构 + 接触） | 非线性实体 FEM（neo-Hookean 等） |
| 橡皮筋 / 弹力绳 | 橡皮筋、弹力绳 | 仅受拉、大应变、滞回、蠕变 | 力—伸长、寿命 | 高（材料数据） | 一维超弹/经验模型 |
| 打印弹簧 | 螺旋/叶片/蛇形打印弹簧 | 几何 + FDM 各向异性 + 蠕变 | 刚度、行程、是否断 | 高（材料 + 几何） | 梁/壳 + 校准材料 |
| 双稳态柔顺机构 | 双稳态夹子、跳跃机构 | 负刚度、跳跃、多平衡态 | 跳跃力/位移、稳态 | 很高（路径跟踪 + 接触） | 非线性梁/壳 + 弧长法 |

**关键区分：离散弹簧 vs 连续柔顺件。**
前者有目录参数，仿真问题主要是“装得下吗、力够吗、会不会并圈/屈曲”，一维元件就能答；
后者没有目录参数，刚度是几何与材料的结果，必须解变形，难度高一个数量级。
把这两类混在一个“弹性元件仿真”里，会低估前者、高估后者的可交付性。

### 3. 实测：rapier 原生弹簧关节的三个坑

`@dimforge/rapier3d-compat` 0.20 确实有 `JointData.spring(rest_length, stiffness, damping, anchor1, anchor2)`
（[Rapier JS `JointData`](https://rapier.rs/javascript3d/classes/JointData.html)；本仓库锁 0.20.0，
见 [package.json](../dsh-cad-harness/package.json#L104)）。
但它是**约束求解器里的弹簧**，不是经过验证的力元件。用一个 1 kg 合成质量、10 mm 自由长度、
1 N/mm 弹簧、`g = −9810 mm/s²`、`dt = 1/240 s` 实测（表中 `k`、`c` 均为 rapier 内部单位：
`k=1000` 即 1 N/mm，`c=63.2` 即 0.0632 N·s/mm，正好是 1 kg + 1 N/mm 的临界阻尼）：

| 工况 | 理论预期 | 实测 | 说明 |
|---|---|---|---|
| `k=1000`（=1 N/mm）、`c=10`、从自由长度释放 | 静态伸长 9.81 mm，即 `z = −19.81 mm` | `z = −19.81 mm`，速度 0 | 单位换算正确 |
| `k=1`（把“1 N/mm”原样传入）、`c=0` | 弹簧弱 1000 倍，应持续下落 | 8 s 后 `z = −3182 mm`，速度 400 mm/s | **1000× 单位陷阱**：mm/kg/s 下力的单位是 mN，`1 N/mm = 1000` 内部刚度 |
| `k=1000`、`c=2√(km)=63.2`（临界阻尼）、从自由长度释放 | `z = −19.81 mm` | `z = +0.19 mm`，速度 0 | **高阻尼把质量“吸”到锚点附近并停住**，与重力方向相反 |
| `k=1000`、`c=63.2`、从拉伸 `z=20` 释放 | `z = −19.81 mm` | `z = +0.19 mm`，速度 0 | 不是初值瞬态；与 `dt=1/60 … 1/1000` 无关 |
| `k=1000`、`c=49`（低于临界）、从自由长度释放 | `z = −19.81 mm` | `z = −19.81 mm` | 对照：低阻尼时正确 |

**这三个坑的含义：**

1. **单位不是“注意一下”的事，是默认会错的事。** 项目全程 mm/kg/s；rapier 是 unit-agnostic，
   力的内部单位是 `kg·mm/s² = mN`。目录上的 `k = 1 N/mm` 必须写成 `1000`；阻尼同理
   （`1 N·s/mm = 1000` 内部单位）。跨到 `simulate_stress` 的 N/mm/MPa 体系时，1000 倍
   错误非常容易发生。
2. **“settled”不等于“平衡”。** `simulate_physics` 的 `settled` 是“末速度 < 5 mm/s”
   （[physics.ts](../dsh-cad-harness/src/host/physics.ts#L610)），不是力残差。上表的高阻尼
   工况速度 0、位置却错了 20 mm；如果直接暴露，报告会说“settled”，而物理是错的。
3. **把阻尼当“让它停下来”的旋钮，会改变答案。** 物理阻尼是材料/结构属性；数值阻尼是
   为了让求解器收敛。两者混在一起，用户调 `damping` 直到“稳定”，得到的是一个被调出来的
   平衡位置，不是设计结果。

> 这不是说 rapier 弹簧关节不能用。它说明：**要用，必须带单位换算、力/能量输出、
> 平衡残差检查和一组解析对拍；不能把“关节建好了”当成“仿真有了”。**

### 4. 难度分层

#### 4.1 表示层：弹性是行为，不是几何

当前管线从 STL 出发，每个件要么是刚体，要么是体素实体。没有地方承载：

- `k`（或 `kθ`）、自由长度/自由角、安装长度/角、预紧；
- 阻尼、行程上下限、并圈高度、旋向、端部形式；
- 座面/导向面（弹簧抵在哪个面、是否受侧向约束）；
- 参数的来源（目录/实测/按材料估算）与不确定度。

`ManifestInterface` 的 `params` 只有 `Record<string, number>`，注释写着
“spring: freeLength/stiffness/damping”（[manifest.ts](../dsh-cad-harness/src/host/manifest.ts#L38)），
没有轴、没有座面、没有方向、没有来源。`spring-preload` 还假设 `a`、`b` 就是弹簧的两个端
（[assembly-check.ts](../dsh-cad-harness/src/host/assembly-check.ts#L592)），但真实弹簧的
“端”是座面/圆柱面，不是一个点。

更麻烦的是几何形态：

- 螺旋弹簧的 STL 是一根螺旋线。把它体素化成实体，既浪费（要解析 0.5 mm 的丝径），
  又丢信息（并圈、端部磨平、旋向）；正确模型是沿轴的**一维元件**，但需要显式声明
  轴、两端、自由长度。
- Living hinge 是实体上的一个薄区。要按梁/壳算，需要中面/中心线；当前管线不提取，
  也没有“这是一条柔性梁”的语义。
- 多材料共打印（TPU 铰 + PLA 主体）没有“按区域赋材料”的能力；`simulate_stress` 一次
  只解一种材料。

**失败模式：** 调用者只能把弹簧当刚体/实体，工具只能量“装得下吗”，答不了“力多大”。
这不是加个字段就能补的，要加一个**元件实体**（schema + 校验 + 工具参数 + 报告字段）。

#### 4.2 本构层：材料数据是精度的上限

当前只有一种本构：各向同性线弹性；一次只解一种材料；随包材料只有 `fdm-pla`
（E=3500 MPa、ν=0.35、强度取 25 MPa 的层间粘接带，`assumed: true`）
（[stress.ts](../dsh-cad-harness/src/host/stress.ts#L40)）。

弹性元件会把这条边界推到极限：

- **FDM 打印件**：E 随填充率、壁数、层方向变化；强度受层间粘接控制（通常 25–30 MPa，
  不是 bulk 的 50–60 MPa）；室温蠕变明显；打印方向决定断裂面。
- **TPU/橡胶**：超弹（neo-Hookean / Mooney–Rivlin / Ogden）、近不可压（ν≈0.49–0.5）、
  大应变（>100%）、滞回、Mullins 效应。当前 hex8 位移格式在近不可压时会体积锁死，
  需要混合 u-p 或选择性减缩积分；这不是改个 `poissonRatio` 能解决的。
- **金属弹簧丝**：线弹性够用，但疲劳、表面缺陷、端部应力集中是寿命问题；目录 `k`
  通常比“从 E 算”更可靠。
- **粘弹/蠕变**：预紧力会松弛；卡扣长期会松；玩具在夏天车里会软。当前没有时间相关
  本构，也没有实验数据。

**参数识别是瓶颈。** `k ∝ E`（梁/弹簧），E 差 2 倍，`k` 就差 2 倍；TPU 的超弹参数
需要拉伸/压缩/松弛试验拟合。工具可以诚实地标 `assumed: true`，但“诚实”不等于“准确”。
在没有校准件的情况下，**仿真精度很可能不如直接用目录/实测 `k`**。

#### 4.3 几何非线性：大转动不是“网格细一点”

线弹性小变形假设：应变小、转动小、平衡方程建立在未变形构型上。柔性铰链的典型工况是
**30°–90° 转动、1%–5% 应变**；卡扣的典型工况是**大挠度 + 接触**。这时：

- 线性 FEM 给出的是 `F–δ` 直线；真实曲线会因几何改变而 stiffening/softening，
  转动中心会移动，力臂会变。
- 线性解不能预测**屈曲**（受压柔性件的主要失效模式），也不能预测**跳跃**（双稳态）。
- 线性解不能处理**预紧**下的初始应力状态（安装时已经压缩/拉伸）。
- 大转动需要共旋（corotational）或 Total Lagrangian 格式、Newton–Raphson、切线刚度、
  载荷步进；这是**另一个求解器**，不是 `simulate_stress` 的一个开关。

**可测的失败模式：** 对同一柔性梁，线性 FEM 在 `δ/L = 0.05` 时可能只差几个百分点；
到 `δ/L = 0.3` 或转角 60° 时，误差是“量级”而不是“百分比”。如果工具不设适用域，
用户会拿一个线性数去设计一个明显非线性的铰。

#### 4.4 稳定性：屈曲与跳跃

- **屈曲**：细长压簧、受压柔性梁、薄壁卡扣。临界载荷是特征值问题或非线性路径问题；
  线性静力只会“压下去”，不会“失稳”。压簧的屈曲还和导向、端部约束、自由长度/直径比
  有关，一维模型可以给解析临界值，实体模型需要缺陷敏感性分析。
- **跳跃（snap-through）**：双稳态机构在极限点处切线刚度变负；力控制加载无法越过
  极限点（求解器会发散或跳到另一支）；需要位移控制、弧长法或动态松弛。跳跃过程中
  还有动能、接触、冲击。
- **多平衡态**：同一几何/载荷可能有多个解；结果依赖加载路径。报告不能只给一个位姿，
  要给“路径 + 稳态 + 能量壁垒”。

**失败模式：** 线性求解器在极限点附近给出“收敛失败”或“越走越远”，用户如果只看
最后一张图，会得到“机构卡住/飞出去”的错误结论。

#### 4.5 接触：弹性件最硬的组合

- **卡扣**：钩子在大变形下沿倒扣滑动，摩擦、粘滑、屈服、白化；插入力峰值和保持力
  是设计指标。接触面在变形体上，接触搜索、摩擦锥、非光滑求解都要有。
- **螺旋弹簧并圈**：压缩到并圈高度时线圈自接触，摩擦、侧向屈曲、颤振；一维弹簧
  模型直接丢掉了这些。
- **Living hinge 折叠**：两半在铰处自接触，夹住、挤薄、应变集中；这决定寿命。
- **弹性垫/O 形圈**：大变形 + 近不可压 + 接触压力；接触算法和本构耦合。

当前状态：`simulate_stress` **没有接触**；`simulate_physics` 只有**刚体**碰撞体
（hull/trimesh），关节对默认不碰撞（[physics.ts](../dsh-cad-harness/src/host/physics.ts#L31)）。
所以“变形体接触”是全新能力，不是把现有两条腿拼起来。

**难度排序：** 大变形 + 接触 + 摩擦 + 薄结构 + 自接触，是计算力学里最难的组合之一。
卡扣是其中最容易“看起来能算、实际不可信”的：网格稍粗、接触刚度稍大、摩擦稍小，
插入力就能差 2 倍，而且仍然收敛出一个漂亮曲线。

#### 4.6 动力学与静平衡：弹簧驱动的机构不是“规定运动”

`simulate_motion` 的驱动是规定的（曲柄恒速、振荡器正弦）；`simulate_physics` 是
时间步进的刚体动力学。弹簧驱动的机构两者都不适用：

- 没有规定驱动；位姿由**弹簧力、重力、摩擦、接触、关节约束**的平衡决定。
- 可能没有唯一解（双稳态、接触切换）；可能长期振荡（无阻尼）；可能“卡”在某个
  接触状态。
- 要回答“弹簧能不能把它推到位”，需要**静平衡**（求 residual = 0 的位姿）或**动态
  松弛**（加阻尼跑到稳态），而不是“跑 2 秒看末速度”。
- 当前的 `settled` 是速度阈值，不是力残差；高阻尼可以把系统“按”在一个错误位置
  （见 §3）。**必须同时报力残差、能量、接触状态，才能说“平衡”。**
- 时间步：高 `k` + 小质量 → 高频；固定 `dt=1/60`、默认 `durationSec=2`
  （[physics.ts](../dsh-cad-harness/src/host/physics.ts#L294)）可能不够；显式积分会失稳，
  隐式积分每步要解非线性方程。阻尼既是物理量又是数值旋钮，混在一起会改答案。
- 没有力/扭矩输出：用户看不到弹簧力、预紧力、支反力，也就无法判断“够不够”。

#### 4.7 数值与性能：体素网格对薄柔性件是“结构性不匹配”

当前应力求解器的优势是**规则体素 = hex8 网格**：单元刚度共享、matrix-free CG、无需
体网格剖分。代价是：

- 边界是阶梯；薄特征会被抹掉/加厚。工具已经明确：薄于体素的构件返回 `check`，
  零可信区域，`meshIndependence: drifting`（[engines.md](../docs/llm/engines.md)）。
- 柔性件的关键尺寸是 0.4–1 mm 的铰/卡扣根部。要解析 0.4 mm，`dx ≤ 0.2 mm`；
  一个 50 mm 见方的件就是 `250³ ≈ 1.56×10⁷` 单元（实际还要留边界），内存/时间都
  不可接受。`dx=1 mm` 时铰直接消失。**这不是“调细一点”，是方法选错了。**
- 非线性会再乘 10–100 倍：每次 Newton 迭代要重算内力/切线，接触还要内层迭代。
  现有线性静力在 toy-balance 托盘上“体素化 + 组装”就花了 223 s（代码注释实测），
  工具超时 900 s；非线性 + 接触很容易超出交互预算。
- 薄壁、近不可压、大变形都会恶化条件数；Jacobi 预条件 CG 不够，需要更好的预条件/
  直接法/混合格式。
- 单位：mm/kg/s 下力是 mN，`k`/阻尼要 ×1000；跨到应力 lane 的 N/mm/MPa 时又是另一套。
  这是“默认会错”的地方，必须有自动换算与量纲自检（例如静态伸长 `mg/k` 对拍）。

#### 4.8 验证与证据：没有基准，就没有“仿真”

当前证据模型是为应力设计的：`trustworthy`、`delivery`、`meshIndependence`、
`criticalDistanceMm`。弹性件需要新的证据语义：

- **模型类别**：一维弹簧、线性梁、共旋梁、非线性实体、接触；每类有适用域。
- **参数来源**：目录/实测/按材料估算；不确定度；校准件编号。
- **验证基准**：
  - 螺旋弹簧 `k = Gd⁴/(8D³n)`（或目录值）；
  - 悬臂小挠度 `δ = FL³/(3EI)`；
  - 大挠度悬臂 elastica（Bisshopp–Drucker）；
  - Euler 屈曲 `Pcr = π²EI/(4L²)`（悬臂）；
  - 卡扣插入/保持力的梁理论 + 大挠度修正；
  - Hertz 接触/弹性垫；
  - 弹簧—质量解析解、能量守恒。
- **指标**：刚度误差、力误差、能量误差、平衡残差、网格/路径收敛、接触穿透。
- **实物校准**：弹簧秤/砝码 + 卡尺 + 30 fps 视频是最低配置；有条件用拉伸机/载荷传感器。
- **拒绝规则**：超出适用域（`δ/L`、转角、应变、接触状态、收敛残差）时返回 `check`
  或拒绝，不给“最佳努力”的数。这个仓库的哲学是“宁可不答，不可假答”；弹性件尤其
  容易产生“看起来专业的错数”。

#### 4.9 工具面与交互（场地视角）：LLM 需要知道“该用哪个模型”

- 工具面：是新增 `simulate_spring`，还是给 `simulate_stress` 加 `stiffness` 模式，
  还是给 `simulate_physics` 加 `spring` 关节？这决定参数、报告、skill、验收脚本。
- Agent 行为：LLM 必须先判断“这是离散弹簧还是柔顺件”“小变形还是大变形”“有没有
  接触”，再选模型；选错模型比不算更危险。需要 skill 里的判据与拒绝话术。
- 可视化：变形动画、力箭头、预紧状态、并圈、跳跃序列；当前面板能放刚体轨迹和应力场，
  但没有“变形后的几何 + 力矢量”。
- 运行时：非线性求解可能几十秒到几分钟；要进度、取消、后台任务，不能把 agent 卡死。
- 安全：玩具涉及夹点、弹出、小零件；仿真不是认证，报告不能暗示“符合安全标准”。

#### 4.10 通用能力的形状：一套表示 + 一个路由器 + 多条模型路

场地不该为“弹簧”“卡扣”“柔性铰”各造一个专用工具——那是包工头；场地该造的是一套
**可组合的通用能力**：

1. **一套表示**：`ElasticElement` / `ElasticRegion`，承载 `behavior`、端点/区域、自由/安装
   状态、`k`/曲线、阻尼、行程/限位、座面、参数来源。所有弹性件共用这套表示。
2. **一个路由器**：按 `behavior + 几何 + 变形量级 + 是否有接触` 选择模型路——
   `declared`（S0 算术）→ `linear-solid`（S1）→ `force-element`（S2）→ `beam/shell`（S3）
   → `contact-solid`（S4）。路由器负责**拒绝**：模型路不适用时返回 `check`，不硬算。
3. **材料 intake**：用户自备 `k`/曲线/材料参数；场地给格式、默认假设、一致性检查；
   不保证材料性能（“原材料”原则）。
4. **证据契约**：模型类别、适用域、参数来源、残差/能量、校准件、不能回答什么。
5. **skill 地图 + examples**：告诉 LLM 什么问题走哪条路、每条路的陷阱和拒绝话术。

这就是弹性仿真的“三通”：**水** = 运行时/材料数据；**电** = 求解器/检查器；**路** = 工具面/
报告/证据。三通里缺哪一段，就在报告里标哪一段；不要把“没有”说成“通过”。

#### 4.11 Agent 自写仿真通道：场地不垄断求解

A/B 层是**地板，不是天花板**。需要 C 层精确值时，agent 可以自己写代码（NumPy/SciPy/
scikit-fem/CalculiX/自研梁单元……），这条路必须始终可走。场地要做的不是“把 agent 锁进
我们的工具”，而是**让 handoff 便宜、让结果可质检**：

| 场地提供 | Agent/用户提供 |
|---|---|
| 几何导出（STL/STEP/参数化模型）、材料范围、边界/载荷模板 | 模型、代码、假设、精度目标 |
| `run_python` / Python runtime / 外部求解器调用 | 数值方法、网格、收敛策略 |
| 质检：单位、平衡、能量、收敛、解析基准、与 screening band 交叉检查 | 对模型与结果负责 |
| 证据格式：模型类别、参数来源、误差/收敛、不能回答什么 | 决定是否采信、是否实测 |

**质检不替 agent 的模型背书**，但能挡住最常见的“看起来对”：单位错 1000 倍、边界条件
少一个约束、网格没收敛、能量不守恒、把线性结果用到大变形。Agent 写了一个梁/FE 模型，
场地可以要求它给出：反力平衡、`M = F·L` 对拍、网格/路径收敛、与解析解或 screening band
的交叉检查。这比“场地自己造一个全量 FEA”便宜得多，也符合“库给能力、runtime 给执行、
skill 给地图”的分工。

**screening 工具的产出必须带 handoff 提示**：例如“力档位 `1–10 N`，模型为梁级近似，
适用域 `δ/L<0.1`；要 ±20% 或复杂接触，走 C 层：导出几何/边界/材料，写模型或实测”。
这样 agent 不会因为“工具有个答案”就停在粗糙层，也不会因为“工具不算精确”就被阻断。

**原则：** 场地提供的是可组合的能力与质检，不是求解器垄断；agent 的自写仿真路径始终
开放，且越容易交接、越容易被验证，越好。

### 5. 路线对比：每条路能答什么、代价多大

> 这些路线是**场地里的可选工具**，不是产品套餐；用户/LLM 按任务组合，场地负责把每条
> 路的适用域、代价和证据说清楚。

| 路线 | 能回答 | 代价 | 精度/可信度 | 风险 | 建议 |
|---|---|---|---|---|---|
| **A. 声明式弹性元件 + 解析校核** | 安装力/预紧、行程、并圈余量、屈曲临界、固有频率（估算） | 1–2 周 | 高（前提是 `k`/`L0` 可信） | 低；但只能答“元件级”，不能从几何推 `k` | **先做** |
| **B. 线性刚度探针 + 简单卡扣梁校核**（复用 `simulate_stress`） | 小变形柔性件/梁的 `k`、柔度、应力；单悬臂卡扣插入/保持力 | 2–4 周 | 中；`δ/L` 小、无接触时可用 | 中；容易被误用到中大变形 | **第二步** |
| **C. rapier 弹簧关节 + 力/能量输出 + 静平衡** | 离散弹簧驱动的机构、预紧、动力学、稳态 | 4–8 周 | 中；需单位换算、阻尼/平衡校验 | 中；§3 的坑，必须对拍 | **第三步** |
| **D. 共旋梁/壳** | 柔性铰/living hinge 的大转动、屈曲、跳跃（无接触/弱接触） | 2–4 月 | 高（校准材料后）；薄梁/壳适用 | 高；需中面/中心线、接触、弧长法 | 有明确需求再做 |
| **E. 非线性实体 FEM + 接触** | 复杂卡扣/自接触、弹性垫、超弹、塑性 | 6–12+ 月 | 高（有校准）；但收敛/性能难 | 很高；等于造一个 FEA 内核 | 不建议自研全量 |
| **F. 外部求解器**（CalculiX/FEniCS 等） | 上面大部分，成熟 | 数月集成 | 高（取决于材料/边界） | 高；许可、安装、运行时、证据集成 | 若必须，优先评估 |
| **G. MPM/软体**（rapier Python soft body / MPM 弹性） | 定性变形、趋势 | 数天–数周 | 低；不能给力—位移证据 | 高；最容易“看起来像” | 只做演示，不做验收 |
| **H. 实测校准**（弹簧秤/拉伸机） | 真实 `k`、屈服、滞回 | 持续 | 最高（对特定打印参数） | 低技术风险；依赖设备 | 与 A/B/C 并行 |

**路线选择的判据：**

- 如果用户的问题主要是“这个压簧装进去有多大预紧力、会不会并圈/屈曲”，A 就够了，
  不需要 FEA。
- 如果问题是“这个打印柔性铰有多硬、90° 时应力多大”，B 只能答小变形，D 才是对的。
- 如果问题是“弹簧能不能把杠杆推到位、释放有多快”，C 是性价比最高的。
- 如果问题是“卡扣能不能插进去、会不会断”，E/F 才够；但材料数据可能比求解器更缺。
- G 不应进入任何“力/刚度”的交付证据。

### 6. 场地能力分级（不是产品路线图）

> 下面 S0–S5 是**支持级别**，不是产品版本；每一级都能独立使用，不要求前一级“产品化”。
> 级别越高，模型越贵、适用域越窄、越需要用户自备材料/校准。缺哪一级就明说，不拿低一级
> 冒充高一级。

| 能力层 | 回答什么 | 不回答什么 | 用户需自备 | 支持程度 |
|---|---|---|---|---|
| **S0 声明式弹性元件 + 行为校核** | 已知 `k`/`L0` 的预紧、行程、并圈余量、屈曲细长比、固有频率估算 | 从几何推 `k`；弹簧丝应力；疲劳；接触 | `k`、自由/安装长度、座面、材料来源 | **可用**（算术，非仿真） |
| **S1 线性刚度探针 + 简单卡扣梁校核** | 小变形柔性件/梁的 `k`、柔度、应力；单悬臂卡扣的插入/保持力（梁级） | 大转动、屈曲、跳跃、复杂接触/自接触、塑性 | 材料 E/ν；几何；摩擦系数；可接受的小变形域 | **可用**（线性/梁级，带门禁） |
| **S2 力元件/弹簧动力学与静平衡** | 弹簧驱动机构、预紧、释放、稳态；力/能量 | 弹簧本身变形/并圈/接触；角弹簧需单独验证 | `k`、阻尼、几何、力元件参数 | **可用**（离散，需对拍） |
| **S3 大变形梁/壳** | 柔性铰/living hinge 的大转动、屈曲、跳跃（弱接触） | 复杂接触、自接触、超弹、疲劳 | 校准材料、中心线/中面、边界条件 | **实验/按需** |
| **S4 接触/非线性实体** | 卡扣、弹性垫、自接触、超弹、塑性 | 认证级精度、疲劳寿命、材料保证 | 校准材料、摩擦、接触参数、试验对拍 | **边界/外部求解器** |
| **S5 材料校准与耐久性** | 特定打印参数下的 `k`、屈服、蠕变、寿命 | 通用材料常数；认证 | 试件、试验设备、打印参数 | **长期/用户自备** |

#### S0：让弹性行为可声明、可校核（1–2 周）

- 在装配清单/元件模型里加 **`ElasticElement`（不是 `SpringElement`）**：`behavior`
  （axial-spring / torsion-spring / flexure-beam / snap-fit / pad）、两端 datum 或区域、
  轴/中面、自由/安装状态（长度或角度）、`k`/`kθ`/曲线、阻尼、行程上下限、并圈/限位、
  旋向、座面、参数来源（catalog/measured/estimated）、容差。**同一套表示服务所有弹性件，
  不给每种件做专用工具**；具体走哪个求解器由 `behavior + 几何 + 用户选择` 决定。
- 实现 `spring-behaviour`（保留现有算子名以兼容；内部按 `behavior` 分派，新代码可叫
  `elastic-behaviour`），替换当前的 `skipped`：
  - `F = k·(L0 − Linstalled)`，报预紧力/安装力；
  - 行程端点力、并圈余量；
  - 压簧屈曲细长比（`L0/D`）与导向条件；
  - 一维弹簧—质量固有频率 `f = (1/2π)√(k/m)`（估算，标注“估算”）；
  - 方向/拉伸压缩符号检查（拉簧受压 → 硬错误）。
- 输出按 A/B 层组织：**内在功能性三态**（可压缩/可安装/不并圈/不屈曲——这些是几何/力学
  矛盾，不需要用户阈值）+ **力档位**（如 `1–10 N`，只作显示刻度，不报点值）。是否“够力/
  够行程/可接受”要等用户声明 `forceBudget`/`requiredTravel` 才判；没有声明就 `unknown`/
  `skipped`。并带“这是算术校核，不是仿真”的标签。
- 统一单位：N、mm、N/mm、N·s/mm；报告里显式写换算。
- 验收：已知 `k/L0/Linstalled` 的弹簧，力档位包含手算值；缺 `k` 来源 → `skipped`，
  不是 pass；拉簧受压 → hard violation。
- **这一步不叫仿真**，报告里明确“算术校核，不是求解器”。

#### S1：线性刚度探针（2–4 周）

- 给 `simulate_stress` 加 `mode: "stiffness"`：在声明点/方向施加单位力（或规定位移），
  读位移，算 `k = F/δ`；同时给应力场。**输出 `k` 的区间/档位与适用域，不报“精确 k”**；
  线性结果只用于 A/B 层，C 层须走 agent 自写模型/实测。是否“够硬/够软”由用户声明的
  `forceBudget`/`requiredTravel` 判定；没有声明就 `unknown`/`skipped`。
- 适用域门禁：`δ/L`、最大转角、最大应变；超限 → `check`，并提示“线性结果不可用，
  需要大变形模型”。
- 验收：100×10×10 mm 悬臂、E=200 GPa、L=100 mm、F=100 N → `δ=0.2 mm`、`k=500 N/mm`
  （仓库已有同算例的 0.2 mm 实测，见 `20261008_cantilever_voxel_fem_probe.md`）。
- 卡扣验收：单悬臂钩的插入/保持力与手算梁理论对拍；根部最大应变与材料许用应变比较；
  偏差和适用域一起报告，不承诺认证级精度。
- **梁级卡扣校核（通用，不是“卡扣产品”）**：对单悬臂钩，用梁理论 + 大挠度修正 +
  摩擦角，算插入力、保持力、根部最大应变；适用域：单悬臂、浅倒扣、无自接触、摩擦系数
  已声明；超出 → `check` 并路由 S4。它回答的是“这个卡扣能不能扣上/会不会断”的
  toy-grade 版本，不需要全量接触 FEA。
- 价值：小变形柔性件、梁、卡扣根部（小挠度阶段）的快速估算；也能为 S2 的
  离散弹簧提供“从几何估 `k`”的入口。

#### S2：力元件/弹簧的多体动力学与静平衡（4–8 周）

- `simulate_physics` 加 **`forceElement` 关节**（通用力元件，不是只加“弹簧”）：轴向
  `spring` / `damper` / `constant-force` / `tension-only`；参数含 `restLength`、`k`、`damping`、
  两端 anchor、行程限位、预紧。rapier 原生 `JointData.spring` 只是 `spring` 这一种的实现。
- 加**力/扭矩输出**：弹簧力、支反力、关节约束力、能量；`settled` 之外加
  `equilibriumResidualN`、`energyErrorPct`。
- 加**静平衡模式**：阻尼爬升/动态松弛/最小势能，检测残差；残差超限 → `check`，不报 pass。
- 单位换算集中在工具面：`k_internal = k_N_per_mm × 1000`，`c_internal = c_Ns_per_mm × 1000`；
  加一个 `mg/k` 自检（静态伸长与解析值对拍）。
- 角弹簧：rapier 没有原生被动角弹簧；用 `configureMotor` 的 stiffness/damping 近似，
  但必须验证能量行为与“马达”语义，或者自己施加 `T = kθ(θ−θ0) − cω` 的力矩。
- 验收：弹簧—质量解析解；弹簧—杠杆静平衡；能量守恒 <5%；§3 的高阻尼工况必须被
  残差检查识别为“未平衡”，不能报 settled。
- 输出按 A/B 层组织：**moves / does-not-move / settles / oscillates** + 力档位/能量量级；
  不追求精确阻尼时间历程。它能回答“弹簧驱动机构能不能到位、释放大概多快、预紧多大”，
  但不模拟弹簧丝本身。注意：`moves` 是内在事实；“够不够快/够不够力”要用户声明阈值，
  没有就 `unknown`。

#### S3：共旋梁/壳（2–4 月，按需）

- 针对柔性铰/living hinge：一维共旋梁单元（大转动、小应变），或壳单元；支持屈曲
  特征值、弧长法跟踪跳跃、刚体接触。
- 需要“柔性梁/铰”的显式声明或中面/中心线提取；不能指望从任意实体自动识别。
- 验收：大挠度悬臂 `δ/L=0.3` 与 elastica 误差 <5%；Euler 屈曲 <5%；双稳态跳跃力
  <10%；90° living hinge 与实测 <15%（材料校准后）。
- 仍不覆盖：卡扣的复杂接触、弹性垫的超弹、自接触。

#### S4：非线性实体/接触，或外部求解器（6–12+ 月，战略决策）

- 如果当前任务反复出现卡扣/弹性垫：优先评估外部求解器（CalculiX/FEniCS）的许可、安装、
  运行时、证据集成；自研全量非线性实体 FEM 的代价很容易被低估。
- 若自研：Total Lagrangian hex8/tet4、neo-Hookean/Mooney–Rivlin、塑性、接触、摩擦、
  Newton + 弧长法；需要共形网格或 cut-cell；薄特征/近不可压是硬骨头。
- 验收：卡扣插入/保持力与实测 <20%；弹性垫力—位移 <20%；收敛失败率与拒绝语义明确。

#### S5：材料校准与耐久性（持续）

- 打印参数—材料数据库；狗骨拉伸/压缩/松弛；弹簧 `k` 直接实测；蠕变/疲劳；
- 没有校准件时，工具必须把“材料假设”放在报告第一行，并降低结论等级。

### 7. 验收基准与“可证伪”指标

> 这些目标是**能力层的验收基准**，不是对用户的精度承诺。toy-grade 的 S0–S2 可以用
> 趋势/风险/相对比较交付；只有报告声明“力值可引用”时，才要求达到对应数值。精度是
> 边界，不是场地必须承诺的产品指标。

> 下表的“通过”都以**用户/agent 声明的阈值**为前提；没有阈值时只报事实/区间，不判 pass。
> 场地不替用户定“儿童/成人/玩具/工具”的门槛——那是设计输入。

| 层级 | 验收指标 | 证伪方式 |
|---|---|---|
| **A 功能性** | 三态结论与实物/高保真模型一致；失败模式不漏 | 负样本：必然卡死/断裂/并圈/屈曲的件，工具必须判 `does-not-work` 或 `works-with-risk` |
| **B 数量级** | 区间包含实测/高保真值；判定阈值不被跨档区间掩盖 | 用已知 `k`/梁理论/实测做包含检验；跨阈值区间必须报 `unknown`/`works-with-risk` |
| **C 精确值** | 点值误差 ±5%/±10%/±20%（按能力层） | 解析解/实测/网格与路径收敛 |

| 对象 | 基准 | 目标 | 证伪方式 |
|---|---|---|---|
| 螺旋弹簧 | `k = Gd⁴/(8D³n)` 或目录值 | ±10% | 实测 `F–δ` 斜率 |
| 小变形悬臂 | `δ = FL³/(3EI)` | ±5% | 与梁理论对拍 |
| 大变形悬臂 | elastica | ±10% | 与 Bisshopp–Drucker 对拍 |
| 压簧屈曲 | Euler/弹簧屈曲公式 | ±10% | 与解析临界值对拍 |
| 弹簧—质量 | 解析 `ω=√(k/m)`、能量守恒 | 频率 ±5%，能量 <5% | 时间历程 |
| 静平衡 | 力残差 / 外力 | <1% | 残差报告 |
| 卡扣 | 插入/保持力 | ±20%（有校准） | 弹簧秤/拉伸机 |
| 弹性垫 | 力—位移 | ±20%（有校准） | 压缩试验 |
| 网格/路径 | 两次细化/两步长 | <5% | 收敛检查 |

**报告必须带的字段**（建议）：模型类别、本构、参数来源与不确定度、适用域、边界条件、
收敛/残差、验证基准、不能回答什么。

### 8. 不建议做的事

1. **不要用线性 `simulate_stress` 直接给柔性铰/卡扣的“弹簧刚度”**，尤其当 `δ/L>0.1`
   或转角 >10°；这是把不同物理 regime 的数混用。
2. **不要把 MPM/软体结果当力—位移证据**；它们适合趋势/演示，不适合验收。
3. **不要直接把 rapier 弹簧关节暴露给用户**，除非有单位换算、力/能量输出、平衡残差
   和解析对拍；§3 的高阻尼工况会给出“settled 但错”的结果。
4. **不要把螺旋弹簧当实体体素化**；一维元件 + 目录/实测 `k` 更准、更便宜。
5. **不要承诺疲劳/蠕变寿命**；没有数据、没有试验、没有标准。
6. **不要隐藏单位**；mm/kg/s 与 N/mm/MPa 之间的 1000 倍是默认陷阱。
7. **不要把“跑完了”当“收敛了”**；非线性/接触必须报残差与适用域。
8. **不要把跨判定阈值的区间压成 pass/fail**；区间跨档就报 `unknown`/`works-with-risk`，
   让人/agent 决定是否走 C 层。
9. **不要用“精确求解器”的外观包装粗模型**；输出必须写清模型类别、适用域、参数区间，
   不报没有依据的点值。
10. **不要因为提供了 screening 就阻断 agent 自写仿真**；screening 是地板不是天花板，
    C 层路径始终开放，场地负责交接与质检，不垄断求解。

### 9. 场地裁决问题（不是产品需求清单）

1. **当前真实任务**：最近/下一批玩具设计里，哪类弹性问题出现最多——目录弹簧、打印
   柔性铰、卡扣、弹性垫？这决定 S0–S2 的投资顺序；不按“功能表该完整”排期。
2. **支持程度**：现阶段要“能判断能不能工作/风险在哪”，还是“力值可引用”？前者
   S0–S2 足够；后者要 S3/S4 + 材料校准，并接受更长的运行时间。
3. **用户自备材料**：用户手里有什么——目录 `k`、实测 `k`、打印参数、拉伸曲线，还是
   只有几何？场地按“原材料”原则接受自备数据，提供 intake 格式与一致性检查；不保证
   材料性能。
4. **缺口 vs 边界**：哪些是场地该补的通用能力（S0–S2），哪些是边界（认证级精度、
   疲劳寿命、全量接触 FEA），哪些交给外部求解器/专业工具？按 §6.1/§11.17 裁决，
   不把边界当产品债。
5. **外部求解器**：是否接受它作为场地的一个 utility（安装、许可、运行时、证据集成）；
   还是必须进程内？CalculiX 是 GPL，需评估与 Apache-2.0 项目的边界。
6. **交互预算**：单次查询可接受的时长/资源？这决定 S3/S4 是否能作为场地能力上线。
7. **阈值输入**：用户/agent 如何声明力预算/许用应变/保持力——`maxForceN`、
   `maxStrainPct`、`retentionLoadN`、适用场景、来源？场地只提供输入格式、比较和余量；
   没有声明 → `unknown`/`skipped`，**不替用户定儿童/成人标准**。
8. **C 层 handoff**：agent 自写仿真时，场地最该提供什么——几何/材料/边界导出、运行时、
   还是质检模板（单位/平衡/收敛/解析基准）？这决定 §4.11 的接口优先级。

## 分析

### 为什么“加一个弹簧关节”不是答案

弹簧关节解决的是“两个刚体之间有一根理想弹簧”，它不解决：

- 弹簧本身的几何/材料/并圈/屈曲/疲劳；
- 柔性铰的连续变形；
- 卡扣的接触与屈服；
- 材料参数从哪来；
- 结果可不可信。

它解决的是“离散弹簧驱动机构的动力学/静平衡”，这恰好是当前 `simulate_physics` 最接近
的缺口，也是性价比最高的一步。但要把它做成**证据**，工作量主要在单位、力输出、
平衡残差、对拍和拒绝语义，不在“调用一个 API”。

### 为什么“上非线性 FEM”也不是万能答案

非线性实体 FEM 能算卡扣/弹性垫，但：

- 需要共形网格/局部细化，现有体素管线要重写或大改；
- 需要接触/摩擦/自接触，收敛是主要成本；
- 需要超弹/塑性/粘弹参数，材料数据比求解器更缺；
- 玩具的卡扣往往可以用**梁理论 + 大挠度修正 + 安全系数**给出足够好的工程答案，
  不一定需要全量 FEA；
- 全量 FEA 的“精确感”会诱导用户忽略材料/打印方向/摩擦的不确定度，反而更危险。

### 为什么“先做声明式弹性元件”是诚实的

它把问题从“仿真一个弹簧”变成“核对一个弹簧的选型”：

- 用户/目录给 `k`、`L0`、`Linstalled`、行程、并圈高度；
- 工具算预紧力、端点力、并圈余量、屈曲细长比、固有频率；
- 每一步都是算术/解析，误差来源清楚；
- 不假装知道打印件的 `E`，也不假装模拟了弹簧丝。

以压簧为例，对“这个压簧装进去够不够力/会不会并圈”这类高频问题，这已经能答 80%；
剩下的 20%（弹簧驱动机构、柔性铰、卡扣）再按 S2/S3/S4 逐步补。对柔性铰/卡扣，同一
思路是先核对“声明的参数/适用域/材料来源”，再决定要不要上更贵的模型——**先用便宜的路
把问题问清，再为需要精度的部分付费**，这也是场地分级支持的经济学。

## 遇到的问题

1. **rapier 弹簧关节的高阻尼平衡是反直觉的。** 最初以为“临界阻尼 = 最快稳定”，实测
   却停在 `z=+0.19`（离锚点 0.19 mm），而不是 `z=−19.81`。换 `dt`、换初值都复现；
   低阻尼 `c=49` 正常。说明它不是“物理 dashpot + 弹簧”的直译，至少在这个单位/质量
   比下，高阻尼会改变平衡。**结论：不能拿它当验证过的力元件，必须加残差检查。**
2. **单位的第一版探针就掉进 1000 倍陷阱。** 直接把 `k=1` 当 1 N/mm 传进去，8 秒掉了
   3.2 m。这个错误太容易发生，应该在工具面做换算 + 自检，而不是靠文档提醒。
3. **“薄件不可信”不是理论担忧，是现有工具已经会拒的。** 应力工具对薄于体素的构件
   返回 `check`、零可信区域；柔性铰正好落在这个区间。也就是说，即使只做线性，
   现有体素管线也覆盖不了 living hinge。
4. **`spring-behaviour` 是“声明了但没实现”的典型。** 类型映射里有 `弹簧`，算子表里
   没有；默认落到 `skipped`。这不是 bug，但会让用户以为“检查过了”。S0 应该
   优先把它补成显式的算术校核，而不是继续 `skipped`。

## 结论与下一步

1. **空白是结构性的。** 五条引擎没有一条能**直接**回答弹性元件需要的力—位移/刚度/
   行程/接触行为；`stress` 只覆盖线性小变形的一个点，`physics` 只覆盖刚体，
   `motion` 只覆盖规定运动，`check_assembly` 只有 `k·δ` 算术。
2. **最痛的点不是“求解器不够强”，而是“问题没有被表示”。** 没有弹性元件、
   没有参数来源、没有力输出、没有适用域，用户连问题都问不清楚。S0 的收益
   远大于它的成本。
3. **第二痛的是薄特征 + 大转动。** 体素网格对 0.4–1 mm 的 living hinge 是结构性
   不匹配；线性 FEM 对 30–90° 转动是模型错误。要么上共旋梁/壳，要么明确拒绝，
   不能拿线性数凑。
4. **接触是分水岭。** 卡扣/并圈/自接触是另一个数量级的工程；在材料数据都不足的
   情况下，优先用“梁理论 + 实测校准 + 安全余量”，不要自研全量非线性接触 FEM。
5. **rapier 弹簧关节可用，但必须“包一层证据”。** 单位换算、力/能量输出、静平衡
   残差、解析对拍、拒绝语义，一个都不能少；§3 的高阻尼工况就是反例。
6. **能力分级：** S0（声明式弹性元件 + `spring-behaviour`）→ S1（线性刚度
   探针 + 简单卡扣梁校核）→ S2（离散弹簧动力学/静平衡）→ 按需求决定 S3（共旋梁/壳）
   或 S4（外部求解器/非线性实体）。S5（材料/耐久）与前面并行，但不要
   在没有校准件时承诺精度。
7. **精度要求把门槛降在“不必算准”，但不降“必须判对”。** A 功能性 + B 数量级可以
   覆盖当前档的大部分问题；C 精确值交给 agent 自写代码/外部求解器/实测，场地提供
   几何/材料/边界导出与质检。**screening 是地板，不是天花板**——不能因为工具有个
   粗糙答案，就阻断 agent 走 C 层；也不能因为走了 C 层，就放弃场地的单位/平衡/收敛
   质检。**场地给尺子，不给标准**：力档位只是显示刻度，验收阈值必须由用户/agent 声明；
   没有声明就 `unknown`，不替用户决定“儿童/成人/玩具/工具”的门槛。

**下一步（场地裁决，不是产品立项）：** 先确认 §9 的真实任务与支持程度。若当前任务是
“玩具机构里的压簧/拉簧/扭簧 + 少量打印柔性铰”，S0 + S1 + S2 是一条 2–3 个月、风险可控
的**通用路**，而且 A/B 层（功能性 + 力档位）就能回答大部分“能不能工作”；只有“力值要
可引用/复杂接触”才需要 S3/S4 或 C 层 agent 模型。若真实任务反复出现“卡扣必须一次做对、
插入力/保持力要准”，则把材料校准和接触求解作为 S4 的场地投资评估，而不是把“全量 FEA”
当成产品必须补的缺口。
