# 实验报告：体素可达性与拔模可行方向锥

## 目标

两条新规则的几何引擎，都要求"**结论必须可证明**"（工艺判定只做否决，DECISION-LOG 2026-10-11）：

1. **体素可达性**（S2-b 排粉/排液通道瓶颈、S4 非圆槽刀具可达）：半径 r 的球从远场能到达哪里？
2. **拔模可行方向锥**（S3）：零件的可行抽芯方向集合是否为空？

本次实验要在**已知答案**的用例上确认这两个引擎给出正确结果，并把若干"看着合理"的错误实现
作为阴性对照一起跑出来 —— 使结论是**被演示的**，而不是被声称的。

## 假设

- H1：体素可达性能精确给出通道瓶颈半径（对阈值二分），且窄于球直径的槽被正确识别为不可达。
- H2：**成对矛盾（两个面在任何方向下都无法同时满足拔模）足以判定可行方向锥为空。**
- H3：在 26 个候选脱模方向里取违规面积最小者，可以判定零件是否可脱模。

## 方法

- 环境：插件自带 Python 运行时 `~/.dsh/cad/runtime/venv/bin/python`（CPython 3.13 + numpy/scipy/trimesh）。
- 脚本：`experiments/scripts/probe_void_reach.py`、`experiments/scripts/probe_draft_cone.py`。
- 体素参数：`pitch=0.20mm`、`requiredRadius=1.50mm`（即 Ø3 的球/刀具）。
- 用例：
  - 20×20×10 方块开一条 **0.8 / 3.0 / 4.0mm** 宽、20 长（贯通）、6 高的槽；
  - **封闭内腔**（icosphere R10 外套 + 反向 R9 内壳）；
  - **20³ 立方体**，拔模要求 δ = 1° / 45° / 50°。
- 阴性对照（错误实现，写在脚本内）：
  - BUG1：把"`dt < r` 的空隙"当成不可达；
  - BUG2：用 `binary_dilation` 默认结构元（**菱形/L1**，不是球）做球扫过；
  - 变体 A：26 方向搜索取最小违规面积（S3 被撤回的设计 1）；
  - 变体 B：只查成对矛盾（S3 被撤回的设计 2）。

## 分析

**H1 成立。** 0.8mm 槽（窄于 Ø3 球）报不可达 20.952mm³、瓶颈半径 **0.400mm**；3.0mm 槽报 **0**——
这不是漏报：Ø3 的球在 3.0mm 槽里**恰好放得下**（零间隙），几何上确实可达。4.0mm 同样为 0。
封闭内腔经 `op_connectivity` 报 `voids=1`、体积 3027.3mm³（解析 3053.6，icosphere 离散误差 1%）。

**H2 被证伪 —— 这是本次实验最重要的结果。** δ=45° 时立方体的锥**确实为空**
（要求 `|d·x|,|d·y|,|d·z| ≥ sin45° = 0.707`，三者平方和 ≥1.5 > 1，不可能），
但**成对矛盾数为 0**。原因是矛盾由**三个面联合**产生：

| 组合 | 能否同时满足 | 见证方向 |
| --- | --- | --- |
| +x 与 +y | 能（零余量） | `(0.707, 0.707, 0)` |
| +x 与 +z | 能 | `(0.707, 0, 0.707)` |
| +y 与 +z | 能 | `(0, 0.707, 0.707)` |
| **+x、+y、+z** | **不能** | 需 `|d·x|²+|d·y|²+|d·z|² ≥ 1.5 > 1` |

即"成对矛盾 ⇒ 不可行"是**充分**的，但"不可行 ⇒ 必有成对矛盾"**不成立**。原实现把它当成充要条件，
是一个真实的逻辑错误。（δ=50° 时成对矛盾为 12 —— 立方体的 12 对垂直面，此时确实成立。）

**H3 被证伪。** 变体 A 对零拔模立方体报 **0.000 mm² 违规**：26 个候选方向里总有一个与每个面
接近平行，于是"总能找到某个魔法方向" ⇒ 该判据**对任何合理拔模角都不会否决**，是同义反复。

**替代方案（已实现并验证）。** 球面盖交集非空 ⟺ 要么某个**盖心**可行，要么某两个盖的
**边界圆交点**可行（交集若非空，要么含盖心，要么有极点，而极点必落在至少两个盖的边界上）。
故检查 2k 个盖心 + O(k²) 个交点即可**精确**判定，探针结果与真值全部一致。

## 遇到的问题

1. **BUG1（假 2676mm³）**：把"`dt < r` 的空隙"当成不可达。整个贴壁空隙层的 `dt` 都小于 r，
   于是外面那一层全被算成"腔"。4mm 槽也报 2972mm³。→ 不可达的定义必须是
   "t=0 时与远场连通，但半径 r 的球到不了"。
2. **BUG2（4mm 槽报 18.56mm³）**：`ndimage.binary_dilation` 的**默认结构元是菱形（L1）不是球**，
   对角方向覆盖不足，于是宽槽也被判为不可达。→ 必须显式传入球结构元。
3. **界面壳伪影**：修正后仍有一层 ~1 voxel 厚的残留（体素化误差）。→ 对残留**再做一次球腐蚀**：
   一 voxel 厚的壳消失，真实腔体存活。判据因此是"至少约 2 voxel 厚的不可达区域"。
4. **padding 必须按搜索上限定**：否则当 r 超过 padding 时没有任何球心触到栅格边界，
   全体读成不可达（曾表现为所有槽都报同一个 1.600mm 上限）。**此条已修 padding，但 1.600 平台
   在宽槽上仍复现，真因未定位**；首要嫌疑是 `ceil(mid/pitch)` 的取整台阶（1.600 = 8 × 0.2，
   而 8 = ceil(1.5/0.2)）。**该引擎因此尚未接线**（排除半边已可用，余量半边不可信）。
5. **公式错误（已修）**：`bestWorstDraftDeg` 曾写成 `90 − (margin + δ)`，而 `margin = draft − δ`，
   重复减了 90，把体对角线的 34.9° 报成 55.11°。

## 结论与下一步

- **可用**：体素可达性的**排除半边**（窄于球直径的槽被正确识别，且给出瓶颈半径）；
  拔模锥的**完备判定**（盖心 + 交点枚举）与采样报告（可行占比、余量、收紧面）。
- **不可用（未接线）**：体素可达性的**余量半边** —— `tightestPassageRadiusMm` 在宽槽上有虚假下限
  1.600mm，会让"困难带"误报。接线前必须先定位该平台的真因。
- **已撤回**：26 方向搜索（同义反复）、只查成对矛盾（不完备）。两者都保留在探针脚本里作为反例。
- **下一步**：① 定位 `1.600` 平台（首要嫌疑：`ceil(mid/pitch)` 取整台阶）；
  ② 定位后把引擎接线到 `toolRadiusMm`（非圆槽）与 `escapePassageMinMm`（通道瓶颈）。
