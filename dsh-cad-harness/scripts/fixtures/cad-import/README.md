# CAD import acceptance fixtures

Deterministic samples for `scripts/accept-import-cad.mjs`. Measured baselines
lived in `experiments/20261015_cad_import_probe.md` (2026-10-15).

| file | origin | provenance |
|---|---|---|
| `colored.step` | FreeCAD export ("half_round_screw001"), upstream cascadio test model | github.com/trimesh/cascadio `tests/models/` (MIT repo), fetched 2026-10-15 |
| `multibody.step` | 10-body assembly, upstream cascadio test model | same |
| `microstrip.igs` | IGES sample used only for the boundary-message test (cascadio cannot read IGES — fails silently, no output) | same |
| `profile-mm.dxf` | ezdxf 1.4.4 generated: 40×40 LWPOLYLINE + CIRCLE r6 hole, `$INSUNITS=4` (mm) | generated by `experiments/20261015_cad_import_probe/probe.py` |
| `profile-inch.dxf` | same geometry, `$INSUNITS=1` (inch) | same |
| `profile-bin.dxf` | binary DXF round-trip of `profile-mm.dxf` | same |
| `polyface-box.dxf` | POLYFACE mesh, 20 mm cube (12 quad faces) | same |

Expected values (worker `import_mesh`, Manifold verdicts):

- `colored.step` → solid, 1 body, volume ≈ **242.2 mm³** (default tessellation; 242.9 at tol 0.0005)
- `multibody.step` → solid, **10 shells**, volume ≈ **263544.1 mm³**, genus 12
- `profile-mm.dxf` + `depthMm=10` → volume ≈ **14870.5 mm³** (theoretical 14869.3), genus 1
- `profile-inch.dxf` + `depthMm=10` → exactly **25.4²** the mm file (≈ **9 593 723 mm³**):
  `$INSUNITS` scales the profile to its real size; `depthMm` is millimetres in the
  stored frame and does NOT scale with the file's units
- `polyface-box.dxf` → solid, volume **8000.0 mm³**, genus 0
