# β-D-吡喃葡萄糖 球棍模型 —— 设计规格（SPEC）

> 本文件是**设计与接口的唯一真源**，装配数据由脚本从它派生，不手抄坐标。
> 生成链：`spec/build_molecule.py` → `molecule.json` → `spec/gen_scad.py` → `spec/parts/*.scad` + `instances.json`
> → `spec/build_assembly.py`（+ `versions.json`）→ `assembly/assembly.json`。

## 1. 模型与约定

- 分子：**β-D-吡喃葡萄糖**（六元环：O5–C1–C2–C3–C4–C5），C6H12O6 = 24 个原子。
  5 个碳与 C6 都是四配位、5 个羟基氧/环氧都是二配位 —— 所以**按元素共 3 种球**。
- 24 根键 = 24 根棍。球棍可完全拆开、可任意换位（同类球是同一个零件）。
- 单位 mm，z-up。全部件同一套 socket / peg 几何，只有球径与棍长不同。

| 参数 | 值 | 说明 |
|---|---|---|
| 环键中心距 | 22.0 | 理想椅式六元环，**全等键长 + 四面体角 109.4712°** → 环精确闭合（残差 0.000 mm） |
| 环外键长 | C–C 22 / C–O 20 / C–H 18 / O–H 17 | 按真实键长比例缩放（1.54/1.43/1.09/0.96 Å） |
| 球半径 | C 8.6 / O 8.0 / H 6.0 | 比例 1.075 : 1 : 0.75（真实 vdW 1.12 : 1 : 0.79） |
| 键角 | 全部 109.4712° | 理想四面体；C–O–C 真实值 113° 是已知简化 |

**已知简化（写进 README）**：环键等长、键角全四面体。真实值 C–O–C ≈ 113°、C–C–C ≈ 111°。
等长键是让六元环**精确闭合**的前提；否则 6 个关节会带着 1–2° 的残差装配。

## 2. 接口：一个 socket，一根 peg，全件通用

```
socket（球上）                          peg（棍端，两端相同）
 ├ 定心平台 Ø6.32–6.80，深 0.9          ├ 台肩面（定位面）Ø5.0 → Ø6.2 环带
 ├ 直孔 Ø5.20，深 3.40                  ├ 定心圆柱 Ø5.00 × 2.18
 ├ 环槽 Ø5.90，2.15–3.05                ├ 卡珠 Ø5.40，2.18–2.68（后侧 90° 止退）
 └ 泪滴排屑 Ø1.0 偏心 2.85（朝 +Z）      └ 导入锥 Ø5.0→Ø3.2 @ 2.88–3.20
```

### 2.1 六个自由度各由谁负责（"定位准确"的依据）

| 自由度 | 由谁约束 | 数值 |
|---|---|---|
| 轴向平移 Z | 台肩面 ↔ 定心平台 | 名义 0 mm；接触环带宽 0.5 mm（Ø5.2→Ø6.2） |
| 绕 X / 绕 Y 转动 | 同一对面接触 | 面接触，**理论倾角 0**；见 §2.4 的实际限制 |
| 横向平移 X / Y | Ø5.00 轴 ↔ Ø5.20 孔 | 直径间隙 0.20 mm → 横向 ±0.10 mm（只影响键长 0.5%，不影响键角） |
| 绕 Z 转动 | 不约束（故意） | 棍是回转体，转不转无意义；也免掉一个防转特征 |

**关键点：键角精度来自球，不来自棍。** 球的 4 个 socket 方向由零件的制造精度决定；
棍只负责把两个球按定心平台的距离撑开。所以"键角准不准"= 球的 socket 角精度；
"键长准不准"= 棍的两台肩面间距 ± 落座重复性。这一分工让 48 个关节的误差**不累积到键角上**。

### 2.2 为什么不是这些方案（选型依据）

| 候选 | 为什么不用 | 定量理由 |
|---|---|---|
| 圆柱压配（Ø5.00 进 Ø5.00，摩擦保持） | 摩擦保持依赖打印公差；48 个关节逐个插拔会磨松 | FDM 孔径 ±0.1 → 同一个模型上有的 0.05 干涉（≈30 N 插不进去）、有的 0.15 间隙（一碰就掉） |
| 螺纹 M5/M6 | 装拆慢，24 根棍 × 2 端 × 3 圈 | 144 圈；Ø6 螺纹在 0.4 喷嘴下牙型不完整 |
| 磁吸 | 不是纯 FDM，48 颗磁铁；克级吸力 | 需外购件、需胶；成本与工艺都不在"打印即得"范围内 |
| 球头 + 球窝（经典分子模型） | 球窝允许自由转动 → 键角会漂 | 分子模型要的是**刚性角**，可动球窝正好相反 |
| 纯锥面摩擦（莫氏锥） | 反复插拔后锥面磨损、保持力不可控；1:20 自锁锥打印不出来 | 直径 ±0.1 就足以让 1:20 锥完全失去接触 |
| 卡口（L 形槽，推入后旋 45°） | Ø12–17 球内做 L 槽是内倒扣，要支撑或分半；24 个关节推+旋太慢 | 正锁最可靠，但可制造性与装拆工时都最差 |
| **定心平台 + 短圆柱 + 弹性卡珠（本方案）** | — | 定位与保持**分开**：面接触管位置，卡珠管不脱出 |

### 2.3 弹性卡珠的力（解析估算，**未实测**）

四瓣卡脚按悬臂梁估：`k = 6EI / (a²(3L−a))`，`I = w·t³/12`（w≈3.3 mm 弧宽，t=0.40 mm 壁厚），
`E = 3500 MPa`，`L = 2.8 mm`（固定环到底端的开缝长），`a = 2.0 mm`（卡珠中心到固定端）。

- 单瓣 `k = 369.6 / 25.6 ≈ 14.4 N/mm` → 四瓣径向合力 `4kδ ≈ 5.8 N`（δ = 0.10 mm）
- 经 45° 导入面 + 摩擦（μ≈0.3）：轴向系数 `(tanα+μ)/(1−μtanα) = 1.86`
  → **插入力 ≈ 11 N；拔出力（背面直角止退）同量级略高。量级 6–14 N，未实测。**

结论：单手可插拔、有"咔哒"手感、不留连续径向力（就位后卡珠落在 Ø5.90 槽内，径向自由，
所以不会像压配那样长期蠕变松脱）。**这个力值没有实测**，是公式估算 + 材料牌号假设；
第一版打印后应用弹簧秤拔一次校准。

### 2.4 已知的实际松弛量（必须写进交付说明）

- 卡槽 0.9 mm 宽、卡珠 0.5 mm 宽，且卡珠口侧面与槽口侧面同面（2.15 / 2.18）：
  **拔出方向无游隙**（要拔必须先挤过喉口），**推入方向留 0.03 mm 余隙**让台肩能落座。
- 若台肩没有落座（例如用户没有推到底），Ø5.00/Ø5.20 的间隙允许 **≤5.7° 倾角**
  （atan(0.20/2.0)）。装配后 24 根键的网络约束与重力会把台肩压回平台；
  这是本设计唯一"靠装配状态"维持的精度，仿真是刚性的、不建模这一项。
- 如果实测偏松：改 `PEG['bead_r']`（+0.05）重印棍即可，球不用重印。

## 3. 制造（FDM）

- **球**：按建模姿态打印（+Z 朝上）。4 个 socket 里 1 个正朝上（完美），3 个斜向下 19.5°：
  其定心平台是 0.8 mm 宽的环形悬空，直孔上壁近水平 → 已用**泪滴排屑**（Ø1.0，朝 +Z 偏心 2.85）
  把塌陷引到孔外。⚠ 不要把球翻过来打：泪滴方向是按 +Z 算的。
- **棍**：竖立，一端卡脚朝下。首层是 Ø5.2 的环，建议 **2 mm brim**；四瓣 0.4 mm 壁 = 1 圈线宽，
  是本件最薄处（见 §5 的打印性结论）。
- 材料：PLA 即可；PETG 卡脚更韧但更"黏"。
- 总料：**≈49.9 g PLA**（BOM 求和 40 205 mm³）；整机外形 **97.3 × 116.2 × 55.3 mm**。
- 颜色建议（CPK）：C 黑、O 红、H 白。

## 5. 验证计划（这次交付要跑的证据）

1. `generate_part` × 7：版本入库（几何真值）。
2. `check_printability`（`fdm-pla-0.4`）× 7：壁厚/悬空面积；预期会**排除** 0.4 mm 卡脚壁与
   球口 0.56 mm 环带 —— 如实报告并给出论证（弹性件/台阶，不是结构壁），不假装通过。
3. `simulate_motion`：真实版本的单接口插拔行程（0→3.2 mm），出干涉时间线 +
   关键帧。这是"能否正确安装"的直接证据：行程末位姿应无干涉，中段只有卡珠挤压。
4. `check_assembly`：48 节点 / 每对 peg-球 三条判据（同轴、就位距离、直径间隙）+
   一条 `motion-clearance` 引用第 3 步的运行。
5. `validate_assembly`：代表性子装配（1 球 + 4 棍）的逐对间隙数值。
6. `delivery_audit`：带 claims 收尾。
