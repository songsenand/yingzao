# 果糖球棍模型 · 几何与接口规格

> 本文件是**唯一几何权威**的说明；机器可读数据在 [`spec/molecule.json`](spec/molecule.json)，
> 可打印网格由 [`spec/scad/`](spec/scad) 生成，版本库在 `cad-data/`。

## 1. 分子身份

| 项 | 值 |
|---|---|
| 名称 | 果糖，β-D-呋喃果糖（β-D-fructofuranose） |
| 分子式 | C6H12O6 |
| 结构 | 五元呋喃环（O5–C2–C3–C4–C5），C2 为端基季碳，C1/C6 为两个 CH2OH |
| 3D 坐标来源 | PubChem CID 439709，3D conformer（`spec/fructofuranose_pubchem_439709.sdf`） |
| 原子/键 | 24 原子 / 24 键（5 C–C、7 C–O、7 C–H、5 O–H） |
| 尺度 | 35 mm/Å |
| 整体包络 | 223.95 × 200.69 × 129.01 mm；最远原子对 226.51 mm |
| 投影 | 未做额外旋转；坐标已平移到质心 |

选 β-D-呋喃果糖而不是开链或吡喃糖：它是果糖在溶液/蜂蜜中最常见的五元环形式，环上正好
有两个 CH2OH，球棍外形容易辨认。PubChem 的 3D conformer 给出可信的键角/二面角；本模型
保留其方向，只把键长按 35 mm/Å 统一缩放（实际键长差异 <0.1 Å，视觉上不可辨）。

H 球是一个零件、12 个实例：H 只有一个轻接口，球对称，绕键轴转不影响任何原子位置。
C/O 球各自唯一，因为它们的接口方向组合不同；这不是为了“好看”，而是让每个球只能装到
自己的位置（几何自索引）。

## 6. 装配坐标

每个零件都在**自己的局部坐标系**里建模：

- C/O 原子球：球心在原点，凸台方向 = 分子坐标方向；装配时只平移。
- H 原子球：一个轻凸台沿 +Z；装配时平移到 H 位置，再旋转 +Z 到“H→重原子”方向。
- 键棍：局部 +Z 从 A 原子指向 B 原子，原点在**两个球面间隙的中点**；杯底在
  `±(L/2 − 杯长)`，A 杯开向 −Z，B 杯开向 +Z。
- 12 根重键棍的 B 杯 key 槽与 A 杯同为 phase 0；每个凸台的 key 肋都按同一全局参考
  `n = normalize(Z − u(Z·u))` 定相。这样一根直棍两端的 key 槽能同时对上两端凸台，
  而 key 又消除了 30° 的多解。详细推导见 [`INTERFACE.md`](INTERFACE.md)。

装配变换、datum 点/轴/圆柱全部在 `spec/molecule.json` 的 `instance_translate`、
`instance_rotation`、`datums`、`bonds[].placement/rotate` 中；`spec/emit_manifest.py`
把它们写进 `assembly/assembly.json`。

## 7. 验收数字（设计目标）

| 项 | 目标 | 检查方式 |
|---|---|---|
| 球/棍水密、单实体 | 全部 48 实例 | `measure_part` / `check_parts` |
| 球心—球心距离 | 与上表 D 一致（±0.05 mm） | datum 距离 / 装配检查 |
| 同轴度 | ≤0.25 mm | `check_assembly` coaxial |
| 贴合面间隙 | 0–0.25 mm | `check_assembly` distance |
| 孔径/轴径间隙 | 0.05–0.35 mm | `check_assembly` diameter-match |
| 全装配干涉 | ≤0.01 mm³（多边形拟合残差） | `validate_assembly`，epsilon 0.01 |
| 插入路径 | 0–14 mm 全程无干涉（去卡扣导向件） | `simulate_motion` |
| 错相插入 | 5°/15°/30°/180° 均干涉 | `validate_assembly` 静态位姿 |
| 单关节拉脱 | 重 20–35 N，轻 15–25 N（估算） | 梁模型 + 实物拉脱试验 |
