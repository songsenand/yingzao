# 05 · 装配：把机架的一角装起来

工作目录里有两件**别人画好**的零件（只有 STL，没有图纸、没有源码、没有装配图）：

```
xBar.stl    机架的横杆
yBar.stl    机架的立杆
```

它们本来靠自身的配合特征（导槽、齿、螺孔）互相咬合成机架的一角。
**现在装配位姿丢了**——两件都还在原点、还没摆到一起。

请把它们**装成正确的一角**，并证明装得上。

## 要做到

1. **判断相对位姿**：从两件自身的配合特征看出谁插进谁、插到哪、朝向如何。
   两件的配合是**唯一**的——摆错一个面就会撞上或悬空。
2. **装起来不干涉**：装配后跑一次装配验证，得到的应当是"贴合"，不是"插进去"。
3. **连成一体**：把两件合并（`merge_parts`），结果应当是**一个**连通体。
   如果你得到两个体，说明它们根本没接触——位姿还差着。
4. **报出装配后的整体包络**（三个方向的起止），以及你判断位姿时用到的
   **关键配合尺寸**（哪两个面贴合、间距多少）。

## 交卷要交的东西

- 一个**装配**（用 CAD 工具的装配清单），包含这两件与你判定的位姿。
- 一次**装配验证**（干涉）的结果，与你据此做的**合并**（连通体数）。
- 工作目录下写一个 **`assembly-answer.json`**（机读，判据会直接读它）：

```jsonc
{
  "parts": [
    { "name": "xBar", "stl": "xBar.stl", "translationMm": [0,0,0], "rotationDeg": [0,0,0] },
    { "name": "yBar", "stl": "yBar.stl", "translationMm": [0,0,0], "rotationDeg": [0,0,0] }
  ],
  "envelopeMm": { "x": { "min": 0.0, "max": 0.0 }, "y": { "min": 0.0, "max": 0.0 }, "z": { "min": 0.0, "max": 0.0 } },
  "interference": { "pairCount": 0, "minDistanceMm": 0.0, "status": "…" },
  "mergedBodyCount": 0,
  "keyFits": [ { "what": "哪两个面/特征配合", "distanceMm": 0.0 } ],
  "measuredWith": ["…你用来判断与验证的工具名…"],
  "notAchieved": ["…没做到或不确定的部分，没有就留空数组…"]
}
```

## 规矩

- **用 CAD 工具量、用工具验证**。配合关系要从**实测**的几何读出来
  （哪些面平行、哪些槽对得上、孔距多少），不要凭"看起来应该这样"。
- 尺寸按 **mm**、保留到 0.001。工具返回什么就报什么。
- **不确定就说不确定**：某一处配合你判断不了，写进 `notAchieved` 并说明理由。
  诚实说明不扣分，硬报一个自己也不信的位姿会扣。
- 判据看的是**装配关系对不对**（包络、干涉、连通体），不是你用什么顺序装的。

这一轮用了多少**工具调用**、多少**图片**、多少**墙钟分钟**。一句话。
