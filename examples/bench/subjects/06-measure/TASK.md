# 06 · 量一个你没画过的零件

`part.stl` 与 `part-b.stl` 是**同一个零件的两个版本**，由别人画好、直接给你几何，
**没有图纸、没有源码、没有参数表**。`part-b.stl` 相对 `part.stl` 只改了一处尺寸。

这两个文件就是全部材料。不要去找它们的来源，也不要去猜建模脚本。

## 请回答这些问题

对 `part.stl`：

1. 它有几处**圆柱形特征**（通孔 / 盲孔 / 凸台）？逐一给出**直径**与**轴线位置**，
   并说明哪些是孔、哪些是凸台。
2. 两个**通孔**之间的**孔心距**（沿 X）。
3. 那个**圆筒（凸台）的壁厚**。
4. 那处**斜面与底面的夹角**。注意：两条线/两个面之间的夹角有"锐角"与"补角"两种
   说法，**把你报的是哪一个说清楚**。
5. 整体尺寸：沿 X / Y / Z 的**起止坐标**，以及沿方向 `[1, 1, 0]` 的**起止**。
6. 在**板厚的中高处横切一刀**，报出该剖面上**两个孔的孔心距**与**材料面积**。

对 `part-b.stl`：

7. 它相对 `part.stl` **改了哪一处**？给出**变化量与方向**（变厚还是变薄、变大还是变小），
   用同一套测量口径给出两个版本的数，让差值自己说话。

## 测量的规矩

- **用 CAD 工具量，不要自己解析 STL 字节**。这不是洁癖：这条题的判据要能追溯到
  可复现的工具调用记录，自己写脚本读二进制会把证据链断掉。
  如果你**不得不**用别的办法（例如工具报错、或某个量工具表达不了），
  **明说是什么量、为什么工具做不到、你用的是什么替代办法**——诚实说明不扣分，
  假装量到了会扣。
- 数值**保留到 0.001mm / 0.001°**。工具返回什么就报什么，不要"四舍五入到好看"。
- **量不到就说量不到**。宁可报"这个量我用现有工具测不出来"，
  也不要给一个看着合理的估计值。

## 交卷格式

在工作目录下写一个 `measure.json`（机读，判据会直接读它）：

```jsonc
{
  "part": {
    "cylinders": [
      { "kind": "bore|boss", "diameterMm": 0.0, "centerMm": [0,0,0], "lengthMm": 0.0 }
    ],
    "holeCentreDistanceMm": 0.0,
    "tubeWallThicknessMm": 0.0,
    "slopeAngleDeg": 0.0,          // 你报的是哪个角，见下面 angleConvention
    "angleConvention": "acute|as-given|supplement",
    "extentXMm": { "min": 0.0, "max": 0.0 },
    "extentYMm": { "min": 0.0, "max": 0.0 },
    "extentZMm": { "min": 0.0, "max": 0.0 },
    "extentDiagonalMm": { "axis": [1,1,0], "min": 0.0, "max": 0.0 },
    "section": { "atZMm": 0.0, "holeCentreDistanceMm": 0.0, "materialAreaMm2": 0.0 },
    "note": "孔距与材料面积在板厚范围内的任意高度都一样——你切在哪一层都行，写清 atZMm 即可"
  },
  "partB": {
    "changed": "一句话说改了哪一处",
    "beforeMm": 0.0,
    "afterMm": 0.0,
    "deltaMm": 0.0
  },
  "toolsUsed": ["…你实际用来得到上述数字的工具名…"],
  "notMeasurable": ["…工具测不出来的量，没有就留空数组…"]
}
```
