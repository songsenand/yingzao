# 01 · 榫卯木长凳（木质）

做一条农村常见的榫卯木长凳。**这是木工件，不是打印件**：不用金属紧固件、
不做可打印性检查。这活儿的难点在于把传统榫卯的配合关系想清楚，并且写成一份
可机检的契约。

## 尺寸（这些是给定的，不要改）

| 件 | 尺寸 | 位置 |
|---|---|---|
| 座面 | 1200（长，x）× 280（宽，y）× 40（厚，z） | 上表面在 z = 450 |
| 腿（4 条，40 × 40 方料） | 截面 40(x) × 40(y)，从地面到座面底面 | 中心在 x = ±500，y = ±80 |
| 端枨（2 条） | 截面 30(x) × 40(z)，连接同一端的前后两条腿 | 中心高度 z = 150 |

## 榫卯做法（做法给定，配合尺寸你自己定并说明理由）

1. **腿 ↔ 座面：透榫**。榫头穿过座面，**出榫 5mm** 露在座面上表面之上。
2. **腿 ↔ 端枨：半榫**（不穿透腿）。榫头插入腿上开的盲孔。
3. **榫肩必须坐实受力**——腿的上端面（肩面）要贴住座面底面，这是承力面，
   也是遮住缝隙的面。

## 你要交付的东西

- 座面、腿、端枨三类零件（**4 条腿必须是同一个零件的 4 份实例，2 条端枨同理**
  ——不要建 4 个几乎一样的腿）。
- 每个零件声明稳定的 datum 锚点（点、轴、平面按需要）。
- 一份**可执行的装配清单**（`assembly/assembly.json`）：每条接口写清
  名义值、公差、severity。
- 跑 `check_assembly`，把每条接口的 `measured` 值念给我听，不要只说"通过了"。

## 配合尺寸：这才是本题的重点

木材有**顺纹**与**横纹**两个方向，胀缩量差一个数量级。请你自己判断：

- 座面上那个榫眼，**哪一个方向是横纹（会随含水率胀缩）、哪一个是顺纹**；
- 相应的榫头，**哪个方向该留大一点的间隙、哪个方向可以紧一些**；
- 半榫的榫头长度与腿上的孔深，应该相等还是谁比谁短？为什么？

把你的取舍写进工作目录下的 **`joinery.json`**（格式如下），理由写在 `reason`
字段里，**不要只给数字，要给依据**：

```json
{
  "seatGrainAxis": "x",
  "fits": {
    "seatTenonAlongGrain": { "gapMm": 0.0, "reason": "……" },
    "seatTenonAcrossGrain": { "gapMm": 0.0, "reason": "……" }
  },
  "blindTenon": {
    "tenonLengthMm": 0, "mortiseDepthMm": 0,
    "reason": "……"
  },
  "shoulderSeats": true
}
```

`seatGrainAxis` 填座面**长纹**所在的轴（`"x"` / `"y"` / `"z"`）。

## 额外要求

- **端枨顶面与座面底面之间留 0.4mm 让位间隙**，这是设计上有意为之的，
  **不要**写进装配清单。
- 把"同一条腿与座面、与端枨"这几组配合写成机检条目；能写成
  同轴/贴合/间隙的，就用对应的类型，别一律用两点距离糊过去。

## 阴性对照（每步都要做）

把腿的榫头厚度加大 0.5mm，重跑 `check_assembly`，**必须**报出硬违反——
报不出来就是校验空了，直接告诉我。报完之后改回去，再跑一次确认回到 pass。

另外：如果你认为某条配合**表达不出来**，就直接说"表达不出来"以及为什么，
**不要绕过去编一个结果**。
