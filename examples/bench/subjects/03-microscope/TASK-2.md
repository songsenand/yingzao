# 03 · 第二段：把成品证明给我看

**不要重做已经定下来的几何。** 下面四件事做完就行。

## 1. 与参考图逐项对照

把成品和参考图放在一起对照，逐项列出**哪些像、哪些不像**，
然后修正**最不像的两处**。

## 2. 机构要进契约

会相对运动的部位，必须在装配清单里是**被机检的**，而不是只留一个静态距离。
补上，并**引用一次通过的运动 run**。

## 3. 整机级验证

补一次覆盖**全部交付件**的 `validate_assembly`，必须通过。如果你只跑过子集，
就说清哪些是子集结论。

再出一张**覆盖全部交付件**的整机渲染图，它必须对应你实际交付的最终版本。

## 4. 交付审计

跑一次 `delivery_audit`，把它的异议逐条回应。

## 交卷时要报的数

- 第 1 步的"像 / 不像"清单，以及你改了哪两处
- 第 2、3、4 步各自的结论，以及引用的 run id
- 本轮改动的零件与版本号
