# 03 · 单目复式显微镜（外轮廓照图，内部光学你定）

做一台**能真打出来、零件真买得到**的单目复式显微镜。

**分工先说清楚：**

- **外形**以附件参考图为唯一依据——**外轮廓服从图**；
- **内部光学**你自己定（用什么做物镜、单端口还是双端口、怎么照明），
  但**必须自洽**：你声明的光学参数和你的几何要对得上。

## 参考图：哪些要还原，哪些不要

附件 `参考图.png` 是一台经典单目显微镜的产品照。**照它做**，但下面两类要分清：

| **要还原** | **不还原 / 替换** |
|---|---|
| 马蹄形底座 + 两条前伸的弧脚 | 物镜转换器（**参考图里没有，别加**） |
| 连续 **C 形**弯臂（一体弧，不是直梁） | 台下聚光镜（参考图里没有，别加） |
| 弯臂上的竖向安装板 + 侧面大旋钮 + 小旋钮 | 反光镜（**外购件，不建模**——只给一个 M3 接口，见下节） |
| 白色筒体（上下各一圈黑环） | |
| 黑色目镜筒：上细 + 中部粗环 + 顶端喇叭口 | |
| **单个**物镜：黑身 + 银色滚花环 | |
| 黑色方形载物台（前伸、中心通光孔）+ 两个银色压片夹 | |

**外观收口时**出 **front / side** 两张图：方位约 35°、俯仰约 15°、纯白背景、
主体占画面高度约 80%。

## 硬约束

- **每件都要能打印**：常见 FDM，床 220×220×250，PLA 一种材料，尽量免支撑，
  单件 ≤ 6 小时。超了就拆件，**拆出来的接合面要写进装配清单**。
- **紧固件只用 M3**；要紧配的地方用热熔铜螺母或紧定螺钉，**不打印受力细牙螺纹**。
- **标准库可以用**：`gears.scad` / `threading.scad` / `screws.scad` /
  `walls.scad` / `ball_bearings.scad` 都在。齿轮、螺纹、壁这种别手搓。
- **外购件**（物镜、目镜、传感器板、LED……）由你自己选，好买便宜即可。
  它们怎么进接口契约，你自己判断并说明依据。

## 外构件与接口：反光镜（或你选的照明件）**不建模**

参考图台下那面**反光镜是外购件**——它不进你的模型：镜体、镜臂、万向节你都不用做。
你要做的只有**一个接口**：

| 项 | 规格 |
|---|---|
| 接口标准 | **M3**（与全卷紧固件标准一致，不引入第二种规格）：M3 螺孔有效牙深 ≥ 6mm，或 Ø3.2 通孔 + M3 螺母 |
| 数量 | **一个**（外购件自带的角度调整由它自己解决） |
| 位置 | 在**弯臂下端 / 台下支架**（参考图里反光镜叉架所在的位置）；具体坐标你自己定 |
| 声明 | 在 `assembly/assembly.json` 里声明该接口，并把外购件作为**未建模件**列出（名称 + 规格 + 来源） |

照明怎么走到标本下方仍然**由你定**：外购反光镜、或你自己选的 LED / 匀光方案都行，
但 `optics.json` 里的声明必须与几何一致（`g-optics-self-consistent`），并且**不许做台下聚光镜**。

## 四个阶段

### M1 · 骨架与高度链
底座、立柱、弯臂、载物台四件成形并装配到位。

- 抱箍座的中心高度**必须是算出来的**——它要保证接上镜头座之后，标本面正好落在
  你选的物距上。
- 凡后面要接东西的面，都用 `datum` / `datum_plane` / `datum_cyl` / `datum_axis`
  声明锚点。
- 写装配清单，跑 `check_assembly`，把每条 `measured` 念给我听。

### M2 · 调焦机构
镜筒滑座（背面一条齿条）、齿轮轴（直齿轮，用 `gears.scad`）、两侧粗调旋钮，
轴承座固定把轴压住。滑座沿弯臂导轨升降。

- **有效行程 ≥ 25mm**；齿条与齿轮在行程两端都不得脱开。
- **精调**：给出方案并说明它怎么消除回程间隙（打印件的回程间隙比焦深大一个数量级）。
  算一下你选的物镜下焦深是多少，再说你的精调能不能到那个量级。
- 跑 `simulate_motion`，报行程、干涉时间线、关节漂移。

### M3 · 光学链
镜筒、镜头座、目镜筒（或你的单端口方案）、照明座，按你选的光学做。

- 把选定参数写进工作目录下的 **`optics.json`**：

```json
{
  "objective": { "type": "……", "focalLengthMm": 0, "mount": "……" },
  "imageDistanceMm": 0,
  "objectDistanceMm": 0,
  "magnification": 0,
  "ports": "visual-only | visual+camera | camera-only",
  "condenser": "none | ……"
}
```

- 几何必须与它一致：`measure_distance` 量出来的像距/物距要和你写的一致
  （±0.3mm）。**这一条查的是"说到做到"**——不是看你选了什么光学。
- 如果有两个端口共用像面，就把共面这件事也写成接口。

### M4 · 稳定性
1. 整机放 5° 斜面上倒不倒？要不要配重（算出来，不是试出来）？
2. 玻片在载物台槽里倾斜 10° 会不会滑出？要不要压片簧？
3. 滑座在齿条上会不会自己往下滑——**这一问如果表达不出来，就直接说
   表达不出来以及为什么**，不要编一个结果。

## 契约（装配清单）

`assembly/assembly.json`：

- 每条写清名义值、公差、severity；
- 同轴/平行关系用 `coaxial`，不要用两点距离；
- 清单里**故意少声明一条邻近配合**（你自己挑一处让位间隙），
  看邻接发现抓不抓得到。

## 阴性对照三连（每步都做）

每次跑完都要把几何改回去再确认一遍：

- M1：把立柱根部止口直径改小 0.5mm → **必须** hard-violation；
- M2：把齿条与齿轮错开一个相位 → **必须**出现干涉或硬违反；
- M3：把光阑定位面挪 +1mm → **必须**出公差。

## 可打印性报告

工作目录下的 **`printability.json`**：每件一行，
`{ "part": "...", "verdict": "ok|check|unprintable", "minWallMm": 0 }`。
有 `check` 的要在回答里逐条回应（改掉或说明为什么可接受）。

## 交卷时要报的数

最后一并报，别铺开：

- 零件数与版本区间
- 接口统计：pass / hard / intent / undeclared
- 工具调用轮数、墙钟、图片数
- 本卷要求的机读文件：`optics.json`、`printability.json`、`assembly/assembly.json`
