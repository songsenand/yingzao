# 04 · 补一件：机架缺的底部堆叠接头

工作目录里有两件**别人画好**的零件（只有 STL，没有图纸、没有源码、没有参数表）：

```
mainRail.stl    机架的一根导轨
rackJoiner.stl  同族的一个接头（导轨对接用的）
```

机架现在要**上下堆叠**：下面一层的导轨端头，要接到上面一层的导轨端头。
导轨和接头都在，**唯独缺那件底部堆叠接头**（原设计里它叫 `stackConnectorBottom`）。

请把它补出来，并证明它装得上。

## 它必须做到

1. **能咬住导轨**：接头与导轨的配合截面要和导轨端头的方口对得上
   （同族的 `rackJoiner` 是现成的参照——它就是同一套配合的另一个接头）。
2. **跨得过对接缝**：长度要够跨住两段导轨的接头处；**也不要过长**，
   否则会顶到同族的 `rackJoiner`。
3. **锁得住**：至少一个 **M3 螺钉过孔**，位置要与导轨上的锁孔对得上。
4. **是一个连续实体、可打印**：不要靠支撑。
5. **装起来不干涉**：把导轨与新接头放进同一个装配里，跑一次装配验证看结果。

## 交卷要交的东西

- **新零件的版本**（用 CAD 工具建模并保存，别只在回答里描述形状）。
- 一个**装配**：`mainRail` + 你补的接头，并跑一次**装配验证**（干涉）与
  **装配检查**（若你声明了接口）。
- 工作目录下写一个 **`connector.json`**（机读，判据会直接读它）：

```jsonc
{
  "partVersionId": "v…",            // 新零件的版本号
  "crossSectionMm": { "x": 0.0, "y": 0.0 },   // 与导轨配合的两个方向的尺寸
  "lengthMm": 0.0,                  // 沿对接方向的长度
  "throughHoles": [ { "diameterMm": 0.0, "centerMm": [0,0,0] } ],
  "assemblyStatus": "…",            // 你那次装配验证/检查的结果状态
  "printability": "…",              // 可打印性结论（verdict）
  "measuredWith": ["…你用来得到上述数字的工具名…"],
  "notAchieved": ["…做不到的要求，没有就留空数组…"]
}
```

## 规矩

- **用 CAD 工具量、用工具验证**。导轨的配合尺寸要从**实测**来（同族接头是最好的参照），
  不要凭空假设"大概是 10mm"。
- 尺寸按 **mm**、保留到 0.001。工具返回什么就报什么。
- **做不到就说做不到**：某一项要求你判断无法满足（或不确定满足），写进 `notAchieved`
  并说明理由。诚实说明不扣分，假装满足会扣。
- 判据看的是**它能不能装、能不能锁、能不能印**，不是"像不像原件"——
  换一种合理的设计完全可以。
