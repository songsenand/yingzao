# 02 · 往复式蒸汽机（玩具级，单缸卧式）

做一台能演示往复运动的单缸卧式蒸汽机模型。

**先把范围说清楚：这台机器做的是"刚体运动 + 流道几何"，不是热力学。**
插件里没有压力、没有蒸汽膨胀、没有配气相位优化，所以**不要**去算热效率、
不要给锅炉建模。你要回答的是：**这套机构能不能动、动的时候打不打、流道通不通。**

## 尺寸（给定的，不要改）

| 件 | 尺寸 |
|---|---|
| 底座 | 220（x）× 140（y）× 10（z） |
| 气缸 | 卧式，沿 x；内孔 Ø30，长 80 |
| 活塞 | Ø29.6 × 12 厚，同轴装入气缸 |
| 活塞杆 | Ø8 |
| 连杆 | 两端 Ø8 孔，**孔中心距 100** |
| 曲柄 / 飞轮 | 飞轮 Ø120 × 12；曲柄销在半径 **r = 20** 处 |
| 十字头 | 沿导轨滑动，导轨有效长度 ≥ 60 |
| 轴承座 | 2 个，**同一个零件的两份实例**，各装一颗 608 轴承 |
| 滑阀 | 简化滑阀 + 阀杆，装在缸盖一侧 |

**行程 = 2r = 40mm。**

## 外购件：608 轴承（要 import，不要画）

`assets/608.stl` 是一颗买来的 608 轴承的示意实体。请**导入**它，而不是自己画一个：

- STL **不带单位**——单位是你的声明，声明错了整台机器尺寸全错；
- STL **不带 datum**——它要当接口端点，锚点得你自己补；
- 导入后先量一下它的外形，确认 22 × 8 × 7，再往下做。

## 机构（做法给定）

- 曲柄定速转动 → 连杆 → 十字头沿导轨往复 → 活塞杆推动活塞。
- 活塞销、曲柄销、十字头销都用 `Ø8` 销轴。
- 滑阀由**往复驱动**，相位与曲柄相关。

## 要跑的三件事

### 1. 机构运动（`simulate_motion`）

转两圈，报：**行程**、**干涉时间线**、**关节锚点漂移**。

要求：**全程 0 干涉**；两端不得脱开。

### 2. 刚体（`simulate_physics`）

三问，每问都要明确答案：

1. **飞轮惯性**：给飞轮一个初角速度，它能不能带着曲柄越过上死点？
2. **整机稳定**：放 5° 斜面上倒不倒？再加一次 10°。要加底板配重的话，
   自己算该多重。
3. **十字头导轨保持力**：十字头在导轨里会不会自己滑？这一问的表达方式
   由你选，但**结论要能站得住**——如果某个工具表达不了某件事，
   直接说"表达不了"以及为什么，**不要编一个结果**。

### 3. 流道（`simulate_fluid`）

把 进汽口 → 缸腔 → 排汽口 这条流道跑一次，报：**出口到达率、分段速度、死区**。

同样：**如果这个工具表达不了你想要的工况，直说表达不了以及为什么。**

## 契约（装配清单）

`assembly/assembly.json`，要求：

- 每条接口写清名义值、公差、severity；
- **至少 2 条运动类接口**（曲柄↔连杆 转动副、十字头↔导轨 滑动副）必须用
  `motion-clearance`，并**引用一次通过的运动 run**——用静态距离糊过去的
  不算；
- 同轴关系用 `coaxial`，别用两点距离；
- 608 轴承导入后要作为接口端点出现在清单里（这是本题唯一允许的"外购件当端点"）。

## 两份机读报告

在会话的工作目录下写出这两个文件：

**`motion.json`**

```json
{
  "strokeMm": 0,
  "crankRadiusMm": 20,
  "rodLengthMm": 100,
  "valveDrive": "prescribed | mechanism",
  "valveDriveReason": "……",
  "fluidStructureCoupling": "none | coupled",
  "couplingReason": "……"
}
```

**`stability.json`**

```json
{
  "flywheelOvershootsTDC": "yes | no | not-expressible",
  "toppleAt5deg": "yes | no",
  "toppleAt10deg": "yes | no",
  "counterweightNeeded": "yes | no",
  "counterweightMassG": 0,
  "criticalTiltDeg": 0,
  "crossheadHold": "holds | slides | not-expressible",
  "notes": "……"
}
```

`counterweightMassG` 与 `criticalTiltDeg`：判"不需要配重"就填临界倾角，
判"需要"就填所需质量；两个都算不出来就写进 `notes` 说明为什么。
`valveDrive` 与 `fluidStructureCoupling` 如实填写。

## 阴性对照（每步都要做）

- 连杆孔中心距改成 **97mm**（短 3mm）→ 重跑运动仿真，**上死点必须报干涉**；
- 把进汽口壁做成 **0.8mm** → `check_printability` **必须**报出来；
- 十字头导轨**不给**摩擦参数 → 看它报什么，然后说明这个结果能不能当设计结论。

做完把几何改回去，再确认一遍是 pass。

**整机刚体**：`merge_parts` 把整机并成一个体，`shells` 必须是 **1**
（不是 1 就说明有零件根本没接上）。

## 交卷时要报的数

最后一并报，别铺开：

- 零件数与版本区间
- 接口统计：pass / hard / intent / undeclared
- 工具调用轮数、墙钟、图片数
- 本卷要求的机读文件：`motion.json`、`stability.json`、`assembly/assembly.json`
