# 缝纫机旋梭机构（CadQuery 版，2× 演示尺度）

平缝机的**旋梭机构**：旋梭体绕竖轴连续回转，梭壳被定位钩定住不转、梭芯在梭壳里出线，
旋梭底部凸轮每转一次把梭壳顶起一次，为面线让出通路。底板—机架—两根轴—2:1 齿轮副串起来，
手轮驱动下轴，下轴经 20T/40T 齿轮带动旋梭轴 **2:1** 转动。

> 独立目录、独立版本链。`examples/sewing-rotary-hook/`（OpenSCAD 版）**未读取、未修改、未参考**。

**只用四种工艺、三种材料**（用户指定）：CNC 车/铣、激光切（钣金切割）、钣金折弯、FDM；
黄铜 H62、不锈钢 304、PLA。**没有使用范围外的工艺**（齿轮做成 1.2 黄铜片激光切轮廓，
不需要齿轮加工例外）。外购件只有 M3 紧固件（用户已批准采购标准轴承+紧固件，本设计未用滚动轴承）。

## 1. 它怎么动

| 输入 | 传动 | 输出 |
|---|---|---|
| 手轮 1 转（下轴 1 转） | 20T/40T，m=1，中心距 30.00 | 旋梭体 2 转 |
| 旋梭体每转 1 次 | 底部凸轮（r=22→22.4，170°–235°） | 开梭钩摆动 → 梭壳抬升 0.26 mm |
| 定位钩（静止） | 舌片插进梭壳压边缺口（82°–98°） | 梭壳角向锁定，随旋梭不转 |

关键尺寸（全部 mm，Z 向上，旋梭轴过原点，下轴在 `y=−30`）：

- **旋梭体**：外径 44，z=37…63.6；杯内径 36；**梭档**（内壁环槽）r=18…20.4、z=56…60.4；
  **落梭口** 60°（朝 +y）全高打通；**梭尖**从外缘 61.5 向内上翘到 r=18、z=63.6；键槽 3.0 宽。
- **梭壳**：外径 32.8；**唇边** r=16.4…20.2、z=56.6…59.6，坐在梭档里，两侧轴向净空各 0.6；
  顶部压边 r=23（z=67…69）带定位缺口与开梭受力面；中心柱 Ø10。
- **梭芯**：外径 27，座面 z=41.8，凸缘 1.6、纱管 Ø13×2.8，中孔 Ø10.2。
- **轴**：Ø14；旋梭轴顶部 2.4×1.0 平键（在衬套上方，可整根穿入衬套）；衬套 Ø18/Ø14.4，顶部 Ø24 法兰。
- **齿轮**：m=1，20T（外径 22）/40T（外径 42），1.2 厚，侧隙 0.2（齿厚减薄），40T 齿相位 +4.5° 与 20T 错开半齿。
- **开梭钩**：1.5 平板，铰轴 (y=26, z=33)，鞋面 y=22.55 跟踪凸轮，顶部舌片顶在梭壳压边下缘 z=66.6（0.4 间隙）。
- **定位钩**：1.5 钣金，立座在 y=30.4，舌片 z=67.2…68.6 插进梭壳缺口（侧隙 ≈0.8/边）。
- 整机外形 130 × 119 × 88。

## 4. 决定与假设（谁定的）

用户拍板：2× 尺度 / 运动可用 / 含 2:1 齿轮副 / 允许采购轴承+紧固件 / 四种工艺+三种材料。

Agent 假设（**未被确认，交付时请复核**）：

1. 演示线按 0.3mm（≈#50 涤纶线 2×）；梭壳抬升 0.26mm、梭档唇边两侧净空 0.6mm 按此反推。
2. 齿轮压配在 Ø14 轴上（0.05 过盈），**无键、摩擦传扭**；扭矩未验证（手轮工况约 1 N·m 量级可承受，未做计算）。
3. **motion 工具没有齿轮关节**，r018 只驱动旋梭体：2:1 由静态中心距 30.00 与齿相位保证，不由该 run 证明。
4. **开梭钩在 r018 中是静止从动件**：凸轮—鞋面接触未求解；run 证明的是梭壳在 0.26mm 抬升区间内与旋梭、定位钩、开梭钩静止位置的间隙。
5. 梭壳的往复为**规定正弦**（周期 1 转），不是由凸轮接触解出。
6. 夹线簧片与开梭钩回位簧**未建模**（标件/簧丝不在三材料内）；梭壳已开 12° 出线槽。
7. 旋梭体支承在衬套法兰上（黄铜对黄铜推力面），轴靠重力与键定位，无上推轴承。

## 5. 已知缺口（`cad_deliver audit` 仍报 excluded）

- **10 个机加工件的 visual review 缺失**：审计的 role 枚举只有 `printed/purchased/reference`，

## 9. 第四轮：挑线杆撞上了架构问题（未解决，r025 仍是可用状态）

想把挑线杆放进 run，试了三条路，都撞在同一件事上：

1. **留在针杆旁边（x≈4）**：挑线杆 197/180 mm³ 与针杆箱、顶臂底面干涉 —— 它的销轴在 z=176，正好是臂的下表面。
2. **挪到 +x 侧（x≈14）**：针杆导座是 Ø16 圆柱（x=0–16），挑线杆正好从其边缘穿过去，170–270 mm³。
3. **翻到 −x 侧（x≈−14）**：与机架、针杆都干净了（v071/v072），但**驱动接不上** —— 挑线杆的下销必须连到针夹块，
   而两者在 x 上隔了 18mm；−x 侧又没有可用的旋转轴（下轴在 (0,−30)，顶端只到 z=74，
   从这里拉一根连杆到 z=172 要 112mm，还得穿过台板）。

**根因不是尺寸，是布局**：真机的挑线杆是从**横置上轴**的曲柄吊下来的，横轴上同时挂着针杆曲柄。
我这台是"竖轴一系到底"，旋梭、送布、针杆都能从竖轴上取，**唯独挑线杆取不到** —— 它需要一个横轴。
这跟第一轮我问你"驱动怎么接"时的判断是同一件事：竖轴方案省了伞齿轮，代价就是挑线。

### 两条出路（下一步选一条）

| 方案 | 做法 | 代价 |
|---|---|---|
| **A. 加上轴（推荐）** | 在顶臂上加一根横轴（z≈170），上面挂：挑线杆曲柄 + 针杆曲柄；下轴经 **1:1** 齿轮或带传动到上轴 | 顶臂重做、多一根轴 + 两个轴承 + 1:1 传动；针杆从"面凸轮"改回"曲柄+连杆"，更像真机 |
| B. 竖轴拉长 | 下轴从 z=74 加长到 z=170，在 z≈150 装偏心，长连杆横到挑线杆 | 下轴变成 160mm 长轴、要过台板，振动与刚性都差；不是真机会这么做 |

现在的可用状态：**run r025 通过** —— 针杆（24mm 行程）、送布牙（2mm）、旋梭（2:1）、梭壳（0.26 抬升）
五个动作里前四个在跑，挑线杆只有几何（v071/v072）、没进 run。

另外，r025 里所有位移仍是我给的正弦，**凸轮/偏心轮都还没建**；这一条要等上轴定了再一起做（针杆曲柄会替代面凸轮）。

## 10. 第五轮：上轴 + 曲柄滑块（运动学成立，干涉未清零）

按 A1a 做完：空心顶臂、上轴、曲柄臂、针杆叉头、针杆连杆、挑线杆摇杆。整机总高 259。

**运动学结果（run r031）**：针杆行程 22mm、挑线杆连杆 20.3mm、关节漂移 0、closedLoop true —— **机构是成立的**，
针杆第一次由真实曲柄驱动，不再是规定正弦。

**未清零的干涉**：46 处，全部标了 `jointPair`，体积 2–301 mm³，集中在销轴孔区域。
`jointExemptRule` 说"只有声明了 joint.fit 的关节，包络内的重叠才算配合"，但本版工具**拒绝 `fit` / `overlapEnvelope` 字段**
（`additionalProperties: false`），所以这些销孔重叠无法声明为配合，run 一律判 fail。

## 11. 销独立件实验（有效，但干涉未归零）

按 §10 的下一步做了实验：把四个销做成独立外购件（Ø4 圆柱销），曲柄臂与连杆只留 Ø4.2 空孔。

**结果（run r034）**：

| 指标 | 销并入曲柄臂（r031） | 销独立（r034） |
|---|---|---|
| 关节漂移 | 0 | **0.0002 mm** |
| 最大干涉 | 301 mm³ | **301 mm³**（不变） |
| 干涉处数 | 46 | 74 |
| 关节违规 | 0 | **0** |
| 任务员行程 | 22 / 20.3 mm | **22 / 19.9 mm** |

**结论**：销独立化把关节漂移从 0 降到 0.0002（精度提升），但**干涉体积没变**（301mm³ 一模一样）。
这说明那 301mm³ 根本不在销孔，而在**曲柄臂与连杆本体**之间 —— 销独立与否不影响它。

所以这个实验否定了“销孔是干涉源”的假设。剩下的干涉都是 2–300mm³ 的小量，且都在关节包络内；
G 工具这版又不接受 `joint.fit` 声明，因此无法从“配合”角度豁免。

**下一步应该是**：用 `cad_inspect measure` 的 closest-point 找到 301mm³ 那对零件的**具体位置**
（不是继续猜），再决定是改曲柄臂外形还是改连杆头部形状。这是唯一还没试的定位手段。
