# 三速自行车后拨（CadQuery）

纯机械三速后拨：输入是**钢缆位移 + 张力**，输出是导轮笼的**三档横向位置 0 / 4 / 8 mm**。
三档定位在**外置指拨**里完成（指拨是边界，不在本装配内）；后拨只提供回位张力与两个机械端限位。
外购件只来自插件内置标准件库；自制件按 CNC 铣/车设计（6061-T6 与 POM）。

> 这是 `examples/bicycle-derailleur-3spd/`（OpenSCAD 版）的 **CadQuery 重写**，独立目录、独立版本链；
> 旧目录未读取、未修改。

## 1. 它怎么工作

- **输入**：钢缆从基座电缆座进入，绕过上连杆的拨线杠杆（力臂 R=20 mm），
  三档钢缆位移 0 / 2.21 / 4.56 mm → 杠杆角 0 / 6.33° / 13.07°。
- **放大**：上、下连杆是**等长平行四连杆**（L=40 mm，初始 φ=22°），B 铰固定在基座（z=±20），
  P 铰在从动节（y=0 平面，P=(14.984, −17.087) / (14.984, −57.087)）。
  杠杆 13.07° 使 P 铰沿 x 平动 **8.00 mm**（z 同时 +4.35 mm），从动节不转。
- **导轮笼**：从动节下面 C=(15, 0, −73) 挂导轮笼，导轮 G=(15, 30, −103)、张力轮 T=(15, −20, −123)，
  两个 10T POM 滑轮 OD44.45，6000 轴承 + Ø10×50 轴 + Ø10 孔压配。
- **回位**：基座弹簧筒（Ø12.5 腔，**顶部开通**）里放 din2098 压缩弹簧 + POM 推杆，
  推杆顶在上连杆弹簧座上；POM **顶盖**（Ø12.6 插头，过盈 0.05 压入 Ø12.5 孔，Ø20 法兰）
  从顶部压住弹簧。**推杆 Ø12 盘可从顶部装入**，解决了 v058 之前“6 mm 杆孔后面 12.5 mm 盲腔”的装配死路。
- **cage 张力**：cage 弹簧 + POM 滑块顶着从动节凸轮销。
- **端限位**：基座两条限位臂上的 M4×6 紧定螺钉，分别顶住杠杆下缘（低档）和上缘（高档）；
  中间档由外置指拨保持。

## 6. 装配契约与语料

- `assembly/assembly.json`（rev 18，sealed）含 **36** 个子件、**62** 个接口：
  19 coaxial、24 diameter-match、12 distance、2 spring-behaviour、5 motion-clearance。
- 真实源在 **`cq/`**；`cad-data/versions/vNNN/` 的 source 是**加载器**（读取 `cq/*.py` 后 `exec`）。
- 已退役 9 条 run（`cad-data/runs/.retired/`，原因保留）：r040–r046 是 maxSetups=2–4 的过紧声明
  （几何未变，r065–r070 以 6 重跑）、r047 是 v061/v062 的旧装配检查、r055 是世界坐标方形顶盖 v062
  的车削失败（v063 圆法兰已修）。这是语料整理，不是改写证据。

## 7. 明确的假设与未验证项

1. **横向 0/4/8 mm、钢缆 0/2.21/4.56 mm**：按 4.0 mm 飞轮间距与 R20 杠杆推算；飞轮未实测。
2. **弹簧刚度**：库内 din2098 无 k/并紧数据；按 8 圈可视估算 k=2.04 N/mm、并紧 9.6 mm，
   回位安装 25 mm→10.2 N，cage 25.02 mm→10.16 N；弹簧 BOM-only，不进干涉网格。
3. **外部边界**：链条、飞轮、车架、指拨、钢缆均为外部；**索引由外置指拨完成**，本装配无棘爪。
4. **齿形**：10T 滑轮为简化轮廓，未做链条啮合/齿根强度。
5. **运动**：无重力/弹簧/接触；预热截掉首 5%→行程 7.58 而非 8.00；高档静位姿的 `validate` 用 `pose`
   会绕零件原点（工具行为），所以高档由 r059 运动覆盖，低档由 r061 静检；本地 CQ 复核高档 b/upper 0。
6. **应力**：线性弹性、各向同性、6061-T6；薄夹块 3.5 mm 在 dx=0.9 下不可认证，只作方向性参考。
   dx=0.7/0.5 的细网格在本机均被 SIGKILL（内存），dx=0.9 是环境上限，未取得可认证表面应力。
7. **上/下连杆轮毂锐边**：0.5 倒角 0.86%/0.2%、0.3 倒角 0.68%/0.27%、R1 圆角 3.75% excluded。
   这是实心轮毂端面的**锐边**，不是结构薄壁（工具自己的判据把“薄边/薄壳”分开）；0.3 是三者中最好的折中，
   定稿为“实心薄边，去毛刺即可”，不再改几何。基座 v073 已 `not-excluded`；P/cage/滑轮/滑块 `not-excluded`。
   6 个铣件的可达性有 13.5–33.1% 内部孔/通道不可达，属屏幕警告。顶层 `manufacturing` 策略字段当前契约写入器不支持
   （`deliver plan` 的 M:policy 因此 blocked），用户批准的工艺集记录在 `brief.processes` 与子件 `process`。
8. **未装夹/夹具/刀具验证**：CNC 屏幕不含斜装夹、刀长/刀径碰撞、夹具刚性、振刀。

## 8. 复现

```bash
cd examples/bicycle-derailleur-3spd-cq
node ../../dsh-cad-harness/scripts/contract.mjs verify --manifest assembly/assembly.json
# 面板：版本 v064/v063/v060/v046/v056/v043/v012…；运行 r059/r060/r071 回放
```

几何改动后：改 `cq/*.py` → `generate_part` 新版本 → 更新契约 version/transform →
`cad_assembly check` → 重跑受影响的 motion/stress/printability/turning（证据随版本过期）。
