## 1. 高度链（M1 的核心：抱箍座高度是算出来的）

坐标系：z 向上，底面 `z=0`，立柱轴在 `x=-40`，光轴在 `x=+40`（= 载物台通光孔轴 = 照明轴）。

```
标本面            z = 155.00      = 槽底 153.63 + 载玻片 1.20 + 盖玻片 0.17
   │  u = 13.00   （f=12 / M=12× → u = f(1+1/M)）
镜头座安装面       z = 168.00      ← M12 板机镜头座面（M3 件，骨架先立基准）
   │  v = 156.00  （镜筒座面→像面，目视/摄像共用）
像面              z = 324.00
   ▲
   │  镜筒抱箍座中心 z = 256.00 = 168.00 + 88.00
   └─ 88.0 = 抱箍座中心到镜头座安装面的偏移，**M3 做镜筒时必须遵守的契约**
```

- 弯臂由此定高：立柱顶面 `z=220` → 梁 `z=220..236` → 抱箍座 `z=236..276`，**中心正好落在 256.0**。
- 载物台由此定高：台面 `z=155.13`、槽底 `153.63`（槽深 1.5），标本面 155.0 比台面低 0.13。
- 换镜头只换倍率与工作距离：f=6 → u=6.2、f=12 → 13.0、f=25 → 29.8 ⇒ **调焦行程 ≥25mm**（M2 要求）。

链上的数**全部落成了 datum 并机检**（见 §3 的 `chain-*` 三条），不靠文字描述：
`chain-u`(13.0)、`chain-v`(156.0)、`chain-clamp`(88.0)、`chain-specimen`(0.13)。

## 5. 邻接发现（这一轮的现场取证）

`PROJECT.md` 特意留了一条**不声明**的邻近配合：`弯臂前端面 ↔ 载物台后缘`，设计上 1.0mm 让位间隙。
本设计的实现是：导轨腿底面/裙板底面落在世界 `z=156.13`，载物台台面 `155.13`、抱箍上表面 `155.13`
—— 三处相邻面都是 **1.0mm**，清单里一条都没写。

### 结论 ①：默认阈值 0.75mm 抓不到设计留的 1.0mm 间隙

| 运行 | 邻接阈值 | 未声明 | overallStatus |
|---|---|---|---|
| r001 | 0.75（默认） | **0** | pass |
| r002 | 1.2 | **1：`arm ↔ stage min=1.0`** | check |

**这是真缺口**：`runAssemblyCheck` 的默认阈值（0.75）小于工程上常用的"让位间隙"（1.0），
所以"故意不声明、等邻接发现抓"这条通道，在默认参数下对 1.0mm 级别的间隙是**静默**的。
建议：要么把让位间隙设计到 <0.75，要么让阈值可随清单声明（例如清单里写 `adjacencyThresholdMm`）。

### 结论 ②：`declared` 判定是**按零件对**的 —— 声明其中一条，整对零件的邻近全部被遮蔽

第一版清单里，我把高度链的 `chain-u` 写成 `arm.镜头座安装面基准点 ↔ stage.标本面`。
结果：即把阈值提到 **1000mm**，`arm↔stage` 也再也不出现在未声明列表里。
证据（临时给 `assembly-check.ts` 加了一行 DBG 输出）：

```
DBG arm stage interVol 0 minDist 1 thr 1.2 near true      ← 判定"邻近"成立
undeclared: []                                            ← 但 declared=true，被吞掉
```

`assembly-check.ts:293` 的 `declared` 只看 `iface.a/b` 的**零件 id**，不看是哪两个 datum。
所以**任何**一条 arm↔stage 接口（哪怕是"尺寸链自检"这种不接触的声明）都会顺手替真正的结构间隙背书。
本报告采用的做法：把链路自检改成**零件内部**的（`chain-u`/`chain-v`/`chain-clamp` 全在弯臂内，
`chain-specimen` 在载物台内），把跨件的 u 链留给邻接发现去管 —— 于是 1.0mm 间隙在阈值 1.2 下如期出现（r002）。
建议：`declared` 判定应该按 **datum 对/接触面** 而不是零件对，否则清单里一条"名义尺寸"接口就能掩盖一个真实干涉。

### 结论 ③：同轴度仍然"声明了也不检"（`PROJECT.md` §6 缺口 ②）

`out/reports/check-coax-demo.json`（run r003）：额外加一条 PROJECT 接口 14 风格的
`if-coax-lightpath`（`stage.通光孔轴心 ↔ arm.镜筒轴`，`check: coaxial`）：

```
⏭ if-coax-lightpath: L0 check "coaxial" is unknown — skipped
→ overall=pass  skipped=1  undeclared=0
```

一次跑出两件事：**（a）同轴/轴向关系没有算子消费，只能 skipped**；
**（b）这条声明又把 arm↔stage 那对零件"认领"了，1.0mm 未声明间隙同时消失** —— 与结论 ② 互为印证。
本设计里 `datum_axis("镜筒轴")` / `datum_cyl("通光孔")` / `datum_cyl("立柱抱孔")` 都已解析出来，
就差算子；M3 要机检"镜头座轴心 ↔ 通光孔轴心 ≤0.30"必须等 `coaxial` / `axis-distance` 落地。

## 8. 与 `PROJECT.md` §1.3 BOM 的偏差（都写出来，不藏着）

| 项 | BOM 写法 | 本设计 | 为什么 |
|---|---|---|---|
| 立柱根部 | "Ø40 止口法兰" | **Ø40 止口 + Ø60 法兰** | Ø40 是止口（接口 3 的配合面）；但 Ø40 里塞不下 4×M3 铜螺母（Ø4.2，需在 Ø40.3 孔外侧），法兰放到 Ø60 才有壁厚 |
| 载物台 | "110×90×8，槽 + 通光孔" | 台面 110×90×8 **+ 两条后支撑臂 + Ø50 立柱抱箍** | 4 件里没有别的件能支撑载物台；抱箍抱住立柱、开缝 + M3 夹紧，同时把"台面高度"钉死。**这也是那次"未声明邻近"能被抓到的物理来源** |
| 弯臂顶端抱箍座 | "镜筒抱箍座" | Ø34.6 **滑配导向孔** + 开缝 + M3（不是聚焦夹持） | 镜筒要在 M2 由滑座驱动升降 ≥25mm；若 M1 抱箍夹死镜筒，M2 就没法动。故 M1 只做**上导向 + 可锁紧**，夹持归 M2 滑座 |
| 底座 | "150×120×12 + 配重腔" | 外形不变，**底面开 140×108×9 减料腔（即配重腔）+ 3 条加强肋**（178→118.7 cm³） | 硬约束"单件 ≤6h"；顺带肋把 3mm 顶皮跨距切成 23mm 桥，零支撑可打。腔在底部 = 配重更低，对 M4 的倾倒更有利 |
| 立柱柱身 | Ø22×200 | 实心（靠切片 15% 填充减重） | Ø22 内孔留给 M3 的 2×M3 底孔只剩 ~1.7mm 壁，不划算 |

**一个设计侧的坑也记一笔**（不属于 harness，但值得进 §5 的记录表）：
`difference(){ union(){ 板; 台墩; 垫脚柱 } 腔 }` 在 OpenSCAD 里**不会**保护台墩/垫脚柱 ——
它们整块在板内部，对 union 的边界没有贡献，union 退化成板，腔照样切穿。
必须写成"先 difference 开腔，再把实体 union 回来"。第一版就这么错了，
靠 `tools/pair-distance.mjs` 式的**数值互查**（射线/体积探针）才发现 —— 渲染图上看不出来。
