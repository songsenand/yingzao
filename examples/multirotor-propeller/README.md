# Ø144 三叶多旋翼螺旋桨（叶长 60mm）· 一体 FDM 打印

> **一句话**：一只**叶长 60mm、桨径 Ø144** 的三叶多旋翼螺旋桨，正反桨各一（四轴对角一对），
> 桨毂本身就是电机安装座——**Ø5.2 中心轴孔 + M5 尼龙锁紧螺母压紧 + 3×M2 沉头防转孔**。
> 平放、零支撑、一体成形；装配接口写成可机检的清单，24 条全部通过。

本目录是**自洽可复跑**的：两件 SCAD 源码、装配清单、编译产物（STL + 四视图）、版本库、
5 次运行记录、以及三个复核脚本全在里面。所有数字都由 `dsh-cad-harness` 的真实工具跑出来，
不是手写报告。

**本示例的边界**：目标是"**画得出、打得成、装得上、转得动**"。它**不是**气动优化设计，
也没有台架实测推力——见 §8。

## 2. 怎么和电机连接 ★

这是本示例的重点：桨毂就是安装座，一共三个配合面，全部在 `assembly/assembly.json` 里写成了可机检的接口。

```
              M5 尼龙锁紧螺母
                    │         ┌── Ø10 平垫圈
                    ▼         ▼
              ┌───────────┐
              │  沉台 Ø11.5×2.0 │ ← 座面 z=5.0
   桨毂 Ø26×7 ├───────────┤
              │  Ø5.2 轴孔  │ ← 套在 Ø5 电机轴上
              └───────────┘
        3× Ø2.4 沉头孔 @ Ø16 分布圆（可选防转）
              ─────────────   ← 毂底平面 z=0，整面坐在钟壳顶面上
              ═════════════   ← 电机钟壳顶面
                    │ Ø5 轴（露出 ≥10mm）
```

### 2.1 三个配合面

| # | 配合 | 设计尺寸 | 清单里的实测 | 作用 |
|---|---|---|---|---|
| ① | **毂底平面 ↔ 钟壳顶面** | 整面贴合 | 距离 **0.000mm** | 定桨盘高度；**也是摩擦传扭的承载面** |
| ② | **中心孔 Ø5.2 ↔ 电机轴 Ø5.0** | 单边 0.1mm | 直径差 **0.20mm**；同轴度 **0.000mm** | 定心；M5 螺母压紧后靠①的摩擦传扭 |
| ③ | **沉台 Ø11.5 ↔ 垫圈 Ø10** | 单边 0.75mm | 直径差 **1.50mm** | 让螺母压在**垫圈**上而不是桨毂顶面；整圈不变，所以桨转、垫圈不转也不蹭 |
| ④ | **3× M2 沉头孔 @ Ø16 ↔ 钟壳 3×M2 螺纹孔** | 3 对同轴 | 轴线偏移 **0.000mm** ×3 | 可选的正传动（受剪）；电机没有这组孔也能装 |

清单里另外两条是**装配前提**，不是配合：

- **轴长**：沉台面 z=5 到轴端 ≥5mm（实测本项目检具 **6.0mm**）。螺母高 5mm，
  所以**买电机要核"轴露出钟壳顶面 ≥10mm"**：`(7−2) + 5 = 10`。
- **叶根离钟壳顶面 0.955mm**：桨整转时叶根下缘从这个间隙里扫过去（见 §5 的运动证据）。

### 2.2 装配步骤

1. **断电**、卸下旧桨、清干净钟壳顶面。若顶面有**凸台/滚花**，先量它的高度——
   桨毂 Ø26 是整面贴合的，凸台会顶住桨毂、也会吃掉叶根那 1mm 间隙。
2. 检查轴：Ø5、**露出钟壳顶面 ≥10mm**、没有毛刺。
3. **认准正反桨**（见 §2.5），把桨毂套到轴上，**毂底平面朝下**。
4. 放 **Ø10 平垫圈**，拧 **M5 尼龙锁紧螺母**，扭矩 **1.5–2.0 N·m**。
   - 不要用普通螺母 + 弹簧垫圈代替尼龙锁紧螺母：振动会把它们抖松。
   - 不要超 2.5 N·m：PLA 桨毂会被压塌（垫圈就是为了把压力摊开）。
5. （可选）若钟壳上有 3× M2 @ Ø16 螺纹孔：**M2×8 沉头螺钉**×3，扭矩 **0.15–0.2 N·m**。
   沉头会落进沉孔里，不会碰到垫圈。M2 牙很脆，手感"到位即止"。
6. **手转一圈**：桨应能自由转动、不刮钟壳（间隙是 1.0mm，能明显看出来）。
   轴向旷量应该几乎为零（毂底贴着钟壳顶面）。
7. 首次上电前做**动平衡**（§4）。

### 2.3 传扭走哪条路

- **主路径（一定有）**：M5 螺母的预紧力 → 毂底平面与钟壳顶面之间的**摩擦力矩**。
  M5 拧到 2 N·m ≈ 2 kN 预紧，μ≈0.3、等效摩擦半径 ≈5mm ⇒ 可传 **≈3 N·m**，
  远大于 2207 级电机在 4S 上的堵转扭矩。**前提是螺母不松。**
- **副路径（可选）**：3× M2 螺钉**受剪**。电机钟壳没这组孔就用不上，不影响安装。
- **一个必须记住的物理事实**：**PLA 会蠕变**。长期预紧下桨毂会被慢慢压扁、螺母预紧力衰减。
  所以：**每次起飞前复紧一次螺母**（手感"再拧不动"即可，别追加扭矩）。
  一旦发现桨毂沉台周围有发白/裂纹，直接换桨——不要修。

### 2.4 买电机要核的尺寸

| 尺寸 | 要求 | 为什么 |
|---|---|---|
| 轴径 | **Ø5.0**（±0.05 最好） | 孔 Ø5.2，做成滑配才好拆装 |
| 轴长（露出钟壳顶面） | **≥10mm** | 沉台面 + 5mm 螺母高 |
| 钟壳顶面 | Ø26 范围内是**平面** | 毂底整面贴合，凸台会顶住 |
| 钟壳外径 | ≥Ø26（常见 Ø28） | 桨毂不悬空 |
| 3× M2 孔 | Ø16 分布圆、方位 60°/180°/300°（**可选**） | 防转；没有也行 |
| 级别 | **2205 / 2207 / 2306 级**（Ø144 ≈ 5.7 寸级） | 4S 上常见 1700–2400KV |
| 转向 | 与桨的旋向配套（§2.5） | 四轴必须正反成对 |

> ⚠️ **打印桨比商品桨重**：本件 9.7g，同级商品 5 寸桨约 4–5g，而且桨叶更厚、更钝。
> 惯性载荷更大、效率更低。**这不是"性能对标商品桨"的替代品**，是"能自己造、能改参数"的方案。
> 第一次试转请先用低 KV / 3S，转完立刻摸电机温度，烫手就停。

### 2.5 正反桨（四轴必须成对）

`scad/prop-ccw.scad` 与 `scad/prop-cw.scad` **只差 `HAND` 一行**：`HAND = 1` 是正桨（俯视逆时针转产生 +Z 推力），
`HAND = -1` 是反桨（正桨关于 XZ 平面镜像）。因为镜像时 3 叶的方位角集合与 3 个 M2 孔的方位角集合都不变，
**正反桨能装同一个钟壳，孔位逐点重合**（清单 B-9/B-10/B-11 就是这条的机检）。

- **四轴**：对角两个电机同向、相邻反向，所以 **2 只正桨 + 2 只反桨**。飞控里设好每个电机的转向后，
  **桨的旋向必须跟电机的转向一致**：桨叶的**前缘要迎着旋转方向**。
- **30 秒判断法**：把桨装好，用手按电机该转的方向快速一带——**能把空气往下压**的那只就是对的；
  往上抽风说明装错手性（不要靠"翻过来装"来补救：翻过来弯度也反了，效率更差）。
- 建议用记号笔在桨毂上点一个点区分正反（本模型没有做凸字标记——那需要改源码重新出件，
  见 §8 的说明）。

## 4. 平衡与安全 ★

**这不是可选项。** 桨径 144mm、8000 RPM 时叶尖线速度 **60 m/s**（≈216 km/h）。
不平衡的打印桨会把振动直接灌进电机轴承和机架，也可能把叶片甩出去。

**怎么做动平衡**（业余条件够用的做法）：

1. 做一个**平衡架**：两根平行的刀口/光滑圆棒（或两根拉直的鱼线），水平、等高、间距略小于桨毂直径。
2. 把桨**空套在一根 Ø5 光轴上**（或直接用电机轴），横放在两把刀口上，让桨能自由转动。
3. 松手，让它自己停：**停在下面的那一叶偏重**。
4. 用**砂纸/美工刀**在偏重叶片靠近**叶尖**处**轻磨上表面**（每次极少量，磨完再测）。
   不要磨前缘，不要削薄后缘。
5. 反复到"每次松手停的位置都不同"为止。
6. 两只正桨、两只反桨分别平衡；同一只桨的两个方向都测。

**安全清单**：

- 首次试转：**装好、人不站在桨盘平面内**、戴护目镜，从低速起。
- 每次起飞前：**复紧 M5 螺母**（PLA 蠕变）、手转一圈确认不刮。
- **摔过、撞过、或者听到异响之后**：直接换桨，不要继续用。
- 看到桨毂沉台发白、层间开裂、桨叶有白化折痕 → **报废**。
- 不要在室内满油门试转（打印桨断叶是抛射物）。
- 打印桨不适合大功率/高转速场景；有人的地方、载人设备附近不要用。

## 5. 验证结果（机检，全部可复跑）

### 5.1 装配清单：24/24 通过

`check_assembly` 原始结论：

```
overallStatus = pass    interfaces=24  pass=24  hardViolations=0  intentFlags=0  skipped=0  undeclared=0
```

每工位 12 条接口（A 工位装正桨、B 工位装反桨，共用同一电机接口）。A 工位实测：

| # | 接口 | 算子 | 名义 | 实测 | 结论 |
|---|---|---|---|---|---|
| A-1 | 桨毂底面 ↔ 钟壳顶面 | distance | 0 | **0.000** | ✅ |
| A-2 | 中心孔 Ø5.2 ↔ 电机轴 Ø5.0 | diameter-match | 0.2 | **0.200** | ✅ |
| A-3 | 轴孔轴 ↔ 电机轴轴 | coaxial | 0 | **0.000** | ✅ |
| A-4 | 叶根最低点 ↔ 钟壳顶面（转动副） | motion-clearance ← **r001** | 0.955 | **0.955** | ✅ |
| A-5 | 沉台孔 Ø11.5 ↔ 垫圈 Ø10 | diameter-match | 1.5 | **1.500** | ✅ |
| A-6 | 螺母座面 ↔ 垫圈底面 | distance | 0 | **0.000** | ✅ |
| A-7 | 螺母座面 ↔ 轴端（轴长余量） | distance | 6.0 | **6.000** | ✅ |
| A-8 | 叶根前缘 ↔ 垫圈外缘（转动副） | motion-clearance ← **r001** | 7.76 | **7.760** | ✅ |
| A-9/10/11 | 3× M2 孔 ↔ 钟壳 M2 孔 | coaxial | 0 | **0.000** ×3 | ✅ |
| A-12 | 螺母内孔 ↔ 电机轴（示意件间隙） | diameter-match | 0.2 | **0.200** | ✅ |

**注意 A-4/A-8 的读法**：两条端点都是**特征 datum**（"叶根后缘下棱"、"叶根前缘点"），
不是零件间最小距离——清单量的是**这两个具名特征之间**的距离。
四条 `转动副`（A-4/A-8/B-4/B-8）**全部**用 `motion-clearance` 且都引用了一次**通过**的运动运行；
A-3/B-3（孔轴对中）刻意标成 `紧固` 而不是 `转动副`——它管的是**对中**这个装配要求，
旋转自由度由 A-4/A-8 声明并取证。**"某接口是转动副"和"这台机器能转"是两件事**，
判决书里前者数量不构成后者的证据。
零件级的真值另有证据：顶点扫描得叶根到钟壳顶面最小 **1.001mm**；
全装配 6 件 solid-vs-solid 静态互查（r005）**干涉 0、过紧 0**，接触面间隙 0.000mm（就是设计上的贴合面）。

### 5.2 运动：转得动，且**能失败**

| 运行 | 场景 | 结果 |
|---|---|---|
| **r001** | 正桨绕电机轴 **2 整转** | 干涉 **0 次**、关节漂移 **0mm** |
| **r003** | 反桨（反向驱动，跑 2s ≈ 6.4 转） | 干涉 **0 次**、关节漂移 **0mm** |
| **r002** | **阴性对照**：在 r=40 桨盘平面内塞一块 10×10×3 的方块 | **干涉 12 次**，`❌ 不可交付` |

阴性对照是关键的一条：它证明 r001/r003 的"0 次"**不是因为运动没跑起来**。
12 次事件的间隔是 **0.104s = 1/3 转**——正是三叶桨"每转一圈、三片叶子各扫一次"的周期。
（本例还顺手暴露一个工具侧现象：**四张 keyframe 图完全相同**，即关键帧渲染没有跟随关节位姿——
所以判据只能是**干涉时间线**，不能拿 keyframe 图当运动证据。工具自己也这么提示。）

### 5.3 可打印性：`check`（不是 `ok`，也不是 `unprintable`）

`check_printability`（`samples=2500`）：

```
verdict = check     minWall 0.628mm @ [71.7, -5.6, 3.8]（叶尖后缘）
thinSamples = 327 / 2613        朝下悬垂 200mm² 比 45° 更平（抽样值）
```

两条 finding 都**成立但已确认为设计固有**，逐条回答：

**① "最薄壁 0.63mm"** —— 位置在**叶尖后缘**，是刻意的**钝缘**，不是薄壳。
本件是**实心翼型**截面，切片实测：

| r | 12※ | 20 | 30 | 40 | 50 | 60 | 70 | 71.5 |
|---|---|---|---|---|---|---|---|---|
| 弦长 | 15.0 | 14.1 | 12.9 | 11.7 | 10.6 | 9.4 | 8.2 | 8.1 |
| **截面最大厚** | — | **3.45** | 3.17 | 2.88 | 2.59 | 2.31 | 2.02 | **1.98** |
| 前/后缘厚 | 1.08 | 0.95 | 0.87 | 0.79 | 0.71 | 0.63 | 0.55 | **0.54** |

※ r=12 的切片会同时切到桨毂，数字无意义。
**受力截面（中段）1.98–3.45mm 全部远高于 1.2mm 阈值**；薄面全部落在**前后缘的收敛楔形**上——
真实的注塑桨也是这个量级。为什么不做成刀刃边：**FDM 打不出零厚度边缘**，
那几层会被切片器直接丢掉或拉丝，所以源码里给了 1.1mm 的基准钝缘（`TE_T_BASE`，随弦长缩放到叶尖 0.54mm）。
**如果还是嫌叶尖太薄**：把 `TE_T_BASE` 调到 1.4–1.6，叶尖就是 0.7–0.8mm（代价是叶尖变钝、效率略降）。

**② "朝下悬垂面比 45° 更平"** —— 全量复算（`tools/printability-report.py`，不抽样）：

```
朝下总面积 2890.9 mm²；其中比 45° 更平、且不在打印平台上 = 2022.0 mm²
   倾角  0~15° = 1708.9 mm²（去掉毂底 530.9mm² 贴床面后）
   倾角 15~30° =  205.6 mm²
   倾角 30~45° =   72.3 mm²
   分布高度   z = 1.02 .. 4.64 mm
```

> ⚠️ 工具抽样（2500 个采样面 / 26122 个三角面）只报 **200mm²**，全量是 **2022mm²**——
> **低估 10 倍**。这是抽样步长（triangles/samples）的固有代价，大曲面上尤其明显。

这 2022mm² 就是**桨叶下表面**：它按桨距角倾斜 10–17°，比 45° 平，所以必然计入"需要支撑"。
**这是螺旋桨的固有属性，不是缺陷**：桨叶是**实心楔形截面**，逐层横向偏移只有 `0.2/tan(β) ≈ 0.7mm`，
而同一层的截面宽度有好几毫米——每层都压在上一层上，所以**平放、零支撑能打**。
（真要"零悬垂"，只能把桨距角降到 45° 以上才能自支撑，那已经不是桨了。）

**毂部壁厚**（由设计尺寸直接给出，不是抽样）：轴孔到 M2 孔 4.20mm、M2 孔到毂外圆 3.80mm、
沉台面到毂顶面 2.00mm——全部远高于阈值。

### 5.4 桨叶几何复核（不信渲染图，逐站反测）

`tools/check-pitch.py` 沿径向切片、用截面主轴（PCA）反解弦线倾角：

| r | 15 | 20 | 30 | 40 | 50 | 60 | 70 | 71.5 |
|---|---|---|---|---|---|---|---|---|
| 实测桨距角 | 15.61° | 15.08° | 14.05° | 13.09° | 12.07° | 11.07° | 10.07° | 9.91° |
| 设计值 | 16.06° | 15.48° | 14.33° | 13.18° | 12.03° | 10.88° | 9.73° | 9.56° |

`r > 桨毂半径 13mm` 各站最大偏差 **0.45°**（PCA 对带弯度+钝缘的截面有系统性小偏置）。
反桨同样的表、**等值负号**——镜像关系成立。

想改设计？只动 `scad/prop-ccw.scad` 顶部那组带 `// PARAMS` 注释的常量即可：

| 参数 | 作用 | 改它会牵动什么 |
|---|---|---|
| `BLADE_LEN` / `CHORD_ROOT` / `CHORD_TIP` | 叶长与弦长 | 桨径、实体体积、质量 |
| `PITCH_ROOT` / `PITCH_TIP` | 桨距角（决定"几寸桨"） | 拉力/电流；**调大会压低叶根下缘**，见下 |

| `Z_PITCH` | 桨距轴高度 | **叶根离钟壳顶面的间隙**（调小会撞钟壳） |
| `PCD_M2` / `M2_D` | 防转孔分布圆与孔径 | 要和你电机的桨夹对得上 |

| `HAND` | 1=正桨 / −1=反桨 | 一字之差就是另一只桨 |

改完**务必重跑** §6 的第 1、2 条 + `check_printability` + `check_assembly`——
`Z_PITCH`/`PITCH_ROOT` 这两个参数会直接吃掉叶根间隙，是唯一会"看起来没事、装上就刮"的地方。

## 8. 已知问题与局限（不藏着）

**设计侧**

1. **毂顶面之上露着 0.19mm 的叶根端面**。叶根拉伸端面被要求整个躲进 Ø26 桨毂里，本件的最高点
   是叶根上表面 z=7.19，比毂顶面 z=7 高 0.19mm，于是那圈极小的一块平端面是露在外面的。
   不可见、不影响任何配合（螺母/垫圈在 r≤5 的沉台里、叶片在 r≥9），但严格说它是一个台阶。
   要彻底消掉：把 `HUB_T` 提到 7.5（`SEAT_T` 同步提到 2.5 以保住 z=5 座面）。
2. **毂顶面有一道 0.11mm 的薄唇**（复查第 9/12 条时用定向射线量出来的，不是推测）：
   螺母沉台 Ø11.5（壁在 r=5.75）与 M2 沉头锥（Ø4.3，孔心在 r=8）在毂顶面附近互相逼近——
   z=6.5 处壁厚 0.60mm、z=6.9 处 0.20mm、**z≈7 处 0.11mm**。
   三个孔位各一道、总面积极小（≈3mm²），且**不受力**（Ø10 垫圈只到 r=5，在这道唇的内侧），
   所以最坏结果是一点工艺毛边，不是结构问题。
   但**抽样检查测不到它**（`samples=2500` 报的最薄壁是 0.604mm），这一条是定向射线查出来的——
   也正是它催生了工具侧第 9/12 条的修法。
   想彻底消掉：`M2_HEAD_D 4.3 → 3.8`（M2 沉头真实头径就是 Ø3.8）+ `SEAT_D 11.5 → 11.0`，
   薄唇升到 ≈0.6mm；这两处一改就要重新出件并作废本轮的运行证据，所以本轮**先记录不改**。
3. **叶根露出桨毂的位置是斜的**（叶片后缘比前缘早离开毂外圆），所以"叶长 60mm"这个数字
   是**从 R12 这个约定半径起算**的，不是"从一个平齐的叶根面起算"。
4. **没有做气动优化**：翼型是教科书 NACA 4 位，扭转是线性，弦长是线性收缩。
   没有 CFD、没有台架拉力/电流曲线、没有颤振/发散分析。
   名义桨距 2.67″ 是按 75% 半径的几何桨距算的，**不等于实测桨距**。
5. **强度只做了手算**：8000 RPM 时叶根离心拉力 ≈59 N、根部截面应力 ≈1.6 MPa，
   弯矩应力 ≈3 MPa（按 6 N 总拉力粗估）；PLA 层间强度 25–30 MPa ⇒ 静强度裕度很大。
   **但打印件的真实失效是疲劳、层间缺陷和碰撞损伤**，这些手算覆盖不了——所以 §4 的
   "摔过就换"不是客套话。
6. **示意件不是真件**：`v003` 电机检具与 `v004` 螺母/垫圈是**为了机检接口而建的简化体**
   （螺母内孔按 Ø5.2 光孔、不表达螺纹）。它们**不能打印**，也不代表任何具体品牌型号。
7. **没有做正反桨标记**：桨毂上没印 CW/CCW。加标记要改源码重新出件，会作废本轮全部运行证据，
   所以留在 §2.5 的"30 秒判断法"里——用记号笔自己点一个点更省事。

**工具侧（本节结论已逐条回源码复核；标注 ✅ 的已在 2026-10-11 修掉）**

7. ✅ **关键帧图曾经整批丢失旋转**——根因不是"没跟随位姿"，而是
   `src/host/physics.ts:626` 用了 `rotate(m=[…])`：**OpenSCAD 的 `rotate()` 没有 `m=` 参数**
   （矩阵要走 `multmatrix`），矩阵被静默丢弃、`rotate(a=undef)` 退化成单位阵，
   OpenSCAD 只发 `WARNING:` 不报错、**exit code 仍是 0**。系统 2021.01 与插件内置
   2026.09.23 上行为一致。后果：**平移保留、旋转全丢**，所以纯旋转的机构运动
   四张关键帧逐字节相同（`sha256 c8d95946…` ×4），刚体物理的倒塌也只能看见平移。
   影响面是两个工具（`tools.ts:546` simulate_physics、`tools.ts:1739` simulate_motion）。
   修法：`multmatrix` + 改用 `resolveBinary()` 体系的 `renderScadPng`（原 `renderPng`
   硬编码 PATH 上的 `openscad`，绕过内置快照）+ 渲染警告回传。
   **判据只能是干涉时间线**，但现在图也可信了（四张位姿 → 四张不同图）。

8. ✅ **悬垂面积曾经是"有偏低估计"**：`worker.py:3558` / `inspect.ts:101` 在 1/step 的
   采样循环里 `+= area`，没有步长补偿。26122 面 / 2500 采样：报 **200mm²**，
   全量 **2022mm²**——**差 10 倍**，而它是以"mm²"报出来的。修法：这一半是纯算术，
   改为**全量三角面精确求和**（壁厚那一半仍采样，因为它才是昂贵的射线）。

9. ✅ **壁厚曾经接受任意命中当"对面壁"**：一处 **0.012mm²** 的共面退化面（Manifold
   在折痕/外露端面处的产物）报出过 **0.17mm** 的假壁（出射面法线 dot = **−0.084**，
   根本不是对面）。修法：只认**反向命中**（`dot(n_in, n_exit) < −0.5`）。
   对真实几何是**无操作**（v044 `0.604→0.604`、v034 `0.499→0.499`），
   只掐掉假报那一类。
   另：`unprintable` 曾经由**单个采样面**决定（`min < 0.4×阈值`）。现在追加
   "薄区成片"条件（面积下限），并新增 **`thinAreaMm2` / `thinAreaPct`** 两个字段——
   它们才是区分"薄**壳**"（成片、会断翘）与"实心件收敛的**薄边**"（翼型前后缘）的依据。
   本件：薄区 338mm²/5.3%（钝缘）；对照法兰 v034：4164mm²/11.9%（真的薄壁筒）。

10. ✅ **OpenSCAD 的 `linear_extrude(twist=)` 转向与 2D `rotate()` 相反**
    （正 twist 是顺时针）。本设计第一版（v035）桨距角随半径**从 16.6° 涨到 24.2°**，
    而渲染图上"看起来就是一片有扭转的桨叶"。判据只能是 `tools/check-pitch.py` 那种
    **反测截面的数值检查**。这条属于 OpenSCAD 语义（不是插件 bug），已补进
    `skills/cad-toolbox/SKILL.md` 的陷阱清单。

11. **叶根端面必须完全埋进实体里**：第一版把拉伸起点放在 r=9.5，端面在毂外露出一圈，
    Manifold 在那里生成退化三角面，正是第 9 条那个假 0.17mm 的来源。
    把起点移进毂内（r=6）后端面被布尔并集吃掉，三角面数 26930 → 26122，
    最薄壁回到真实的 0.63mm。**"端面藏进实体里"是一种可打印性手段。**

12. ✅ **最严重的一条：运行时会"假装健康"，让壁厚半边静默失效。**
    本机 venv 的标记文件写着 `requirementsSha=08b72cc0…`，而当前锁算出的是 `a21baffa…`
    ⇒ **这个 venv 根本不是按当前锁装的**（它建于旧锁时期）；`python_runtime status` 却报 `ready`，
    因为就绪判据只看标记文件的五个字段、**从不验证包能否 import**。实测 `rtree` 与 `shapely`
    都 import 不了（两者都在当前锁里、且没有 cad-exclude）。
    后果：`trimesh` 的 `mesh.ray` 每次调用都抛 `ModuleNotFoundError`，
    而 `worker.py:3574-3584` 的 `except BaseException: continue` **逐条射线吞掉异常** →
    `min_wall` 保持 `inf`、`thin_samples` 保持 0 → **工具对任何零件都报"干净"**（悬垂面积小的话就是 `ok`）。
    冷跑同一个 op 的实测：`thinSamples: 0`、**没有 `minWallMm`**、**没有壁厚 finding**。
    修法三处：① `check_printability` 新增 **`wallMeasured`**，未测到就追加显式 finding
    且**永不返回 `ok`**；② 运行时的就绪判据从"标记文件匹配"改成"**锁定包真的 import 得动**"
    （装完先验后写标记；`python_runtime status` 新增 `missingPackages` 并在非空时报 `failed`）；
    ③ 本机 `pip install rtree==1.4.1 shapely==2.2.0` 补齐。
