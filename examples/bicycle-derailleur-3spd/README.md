# 自行车三级变速器 — 3 档索引式后拨（bicycle-derailleur-3spd）

一台**纯机械 3 档后拨链器**：输入是钢缆的位移与张力，输出是活动座沿飞轮轴向的
3 个定位位置（0 / 5 / 10 mm）。自制件全部走 **CNC（3 轴铣 + 车）**，外购件**只允许
插件标准件库内的件**（ISO 15 轴承、DIN 2098 压缩弹簧、ISO 紧固件）。功能在交付前
用运动学仿真验证：1→3 档全行程 24 个位姿、0 干涉。

> 本目录的 `cad-data/`（版本、run、轨迹）是本地语料，gitignored；克隆后需要按
> “复跑”一节重新生成。设计参数在 `source/layout.py`，零件源在 `source/parts/`。

## 1. 规格与目标

| 项 | 值 |
|---|---|
| 档位 | 3（内置 3 凹槽索引板，机械自定位） |
| 飞轮节距（假定） | 5.0 mm（1/8 寸三速量级） |
| 活动座横向行程 | 0 / 5.0 / 10.0 mm（仿真 0 / 5.05 / 10.00） |
| 每档钢缆位移 | 5.0 mm（总 10.0 mm；仿真 10.05） |
| 平行四边形摆角 | 19.19°（±9.59°，对称于中位） |
| 机构平面倾角 | 16°（横向 96.1%、前后 27.6%：给链线让出侧向行程） |
| 钢缆张力（弹簧平衡） | 7.6 N（1 档）→ 20.3 N（3 档） |
| 定位保持力 | 8.2 → 10.9 N（球头 R1.9 落 R2 凹槽） |
| 导轮架预载 | 11.6 N → 凸轮扭矩 ≈ 0.33 N·m（演示级，非骑行额定） |
| 外购件 | `iso15.6000` ×2、`din2098.1.5x16x40`、`din2098.0.8x8x20`、`din2098.1x10x25`、`iso4762.M3x10` ×3 |

## 2. 机构

```
            钢缆 (输入 s, T)  ↓
      ┌────────┴──────────────┐
      │  底座（安装座）          │  吊耳 Ø10、壳管止挡、索引齿
      │  [索引齿 ▁ ▁ ▁]        │  3 凹槽 @ X=0/5/10
      └──┬──────────────────┬─┘
         │ 外连杆(带钢缆臂)   │ 内连杆      平行四杆，绕 Y 轴 ±9.59°
      ┌──┴──────────────────┴─┐
      │      活动座            │  Ø9 定位柱塞腔 + 张紧弹簧塔
      └──┬──────────────────┬─┘
         │ 导轮架(cage)      │ 回位弹簧 din2098.1.5x16x40（同轴于钢缆）
      ┌──┴───┐
      │ ⊙导轮 │  ⊙张力轮       各 1 只 6000 轴承，V 槽 Ø42
      └──────┘
```

- **四杆**：A(0,0,0)–B(12,0,0) 为底座枢轴，C/D 为活动座枢轴，连杆长 30 mm；
  `X_body = L·sinθ`，θ 从 −9.594° 扫到 +9.594° 恰好 0→10 mm。
- **回位**：压缩弹簧与钢缆同半径（r=30 mm）同轴布置在钢缆线上，弹簧力 = 钢缆张力；
  1 档预压 6 mm / 7.6 N，3 档压缩 16 mm / 20.3 N（弹簧刚度按 DIN2098 名义几何估算）。
- **定位**：活动座下凸台里的柱塞（Ø8，球头 R1.9）落进底座顶面的 3 个 R2 凹槽；
  柱塞由 `din2098.0.8x8x20` 压紧，越槽时抬升 2 mm。
- **钢缆接入**：外连杆的钢缆臂把 clamp 放在 r=30 mm；扫角 ±9.59° 时 clamp 的
  Z 行程 10.0 mm、X 投影恒定，所以钢缆始终竖直（夹具在底座壳管止挡上）。

## 5. 已知缺口（不是隐藏项）

1. **交付审计：0 blocked，判 `difficult`**（不是 pass，也不是 excluded）。difficult 来自三处“读数而非通过”的检查：
   应力（r018/r023）在该网格无法认证表面应力、外观（r038）没有声明阈值、CNC 可达性（r041–r047）
   是筛不是证书。审计的 0 blocked 是在**用户 2026-11-20 批准退役三条已失效 run** 之后得到的：
   `cad-data/runs/.retired/` 里保留原 run 与退役原因（`retired.json`），run 索引已剔除它们：
   - `r006`（motion）：v017 垫圈端面与轴承端面重合的贴面重叠；v026 已改为 0.8 厚 + 0.4 间隙，r036 0 干涉。
   - `r054`/`r055`（turning，导轮架枢轴 v025）：车削屏幕把回转直径量在世界原点轴上（不是文档说
     的过包围盒中心轴），把一个 Ø8 的阶梯轴报成 46.8/68 mm。件本身可由 Ø10 棒料车成。
   当前几何的失败已由 r039（cage+inner_link 2.05 mm 间隙）与 r036（0 干涉）覆盖。
2. **弹簧刚度是估算值**（DIN2098 名义几何 + k=Gd⁴/(8D³n)）：k=1.27 / 1.36 / 1.70 N/mm，
   未实测；库内 `part.json` 不含刚度。`spring-behaviour` 的力是“声明值下的点”。
3. **钢缆与链条不建模**：钢缆只作为输入边界（s, T），链条啮合、飞轮齿形不在本轮范围；
   导轮为 V 槽轮，无 11T 齿形。
4. **回位/张紧力受限**：库内没有扭转弹簧，张紧只能用压缩弹簧，导轮架预载 ≈0.33 N·m，
   是演示级、**不按骑行链张力额定**；定位保持力 2–4 N 量级。
5. **应力不可认证**：dx=0.7 时壁厚/缺口处无法给出可信表面应力；dx≤0.6 的网格在本机
   被 OOM 杀掉。只报告 declared-distance 读数与积分平衡，**不当安全系数**。
6. **CNC 筛查档**：内置 `cnc-3axis` 模板假设 Ø6 铣刀（toolRadius 3），本项目 M3 螺纹孔
   （Ø3.3）是钻出来的，因此模板会把它们判为不可达；`profiles/cnc-3axis-alu.json` 是项目
   声明档（钻头半径 1.3、壁厚 0.9），但**当前工具只接受 shipped profile id**，
   自定义档只能通过 `profilesJson` 单件传入（未批量跑）。
7. **壁厚筛的边缘伪影**：外连杆 0.50 mm / 活动座 0.43 mm 的读数都落在孔口/棱边
   （采样器量“两个自由面之间距离”，孔口处必然趋 0），不是薄壳；薄区面积占比 <0.2%。
8. **配合按名义尺寸留 0.05–0.2 mm 建模间隙**；垫圈与轴承端面留 0.4 mm 保持间隙
   （求解器轴向漂移 ~0.2 mm，螺钉预紧未建模）。真实装配需要压装/预紧。
9. **底座为演示布局**：50 mm 自由长的库内弹簧迫使弹簧塔外置，底座比真车 B-knuckle 大；
   安装孔轴线随机构平面偏 16°（真车需要转接座吸收）。

## 6. 复跑

```bash
python3 source/layout.py                 # 全部布局参数（唯一数值来源）
# 零件源：source/parts/<name>.scad，逐个 cad_part generate（OpenSCAD 内核）
# 装配：cad_assembly check → cad_simulate motion（驱动外连杆，cycles=0.0533）
# 交付：cad_deliver plan → audit
```

目录：
```
source/layout.py        布局参数（θ、坐标、弹簧、缆移）
source/parts/*.scad     零件源（base/outer/inner/knuckle/cage/pulley/plunger/screw/pin/washer）
profiles/               项目 CNC 筛查档
assembly/assembly.json  21 节点 BOM + 29 条接口契约（密封，含变更记录）
```
