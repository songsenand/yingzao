# 准生产级罗伯威尔天平 · 需求提示词

> 在 `examples/` 做一台准生产级罗伯威尔（Roberval）天平：

1. **六铰点平行四边形框架**：上下两根横梁各以中点铰接在固定立柱上，两端各用一根竖直边杆连接；边杆在全部工作行程内保持竖直，盘面因此保持水平。
2. **位置无关**：同一质量放在盘面任何位置，读数不变；这是本机要证明的第一性能。
3. 双盘、桌面量级；单盘容量 **0–200 g**；标尺分度 **1 g**（估读 0.2 g 不作为保证值）。
4. 主体 FDM 打印；外购件只用常见 **M3 螺钉/螺母/垫片**；不用轴承、不用胶。
5. **三脚调平**、**零点微调**、指针与可读刻度；工作行程有限位，限位前不得干涉。
6. 配 5 个 **1:2:4:8:16** 等比砝码（10/20/40/80/160 g），最大者底面积占托盘内底面积 **0.500 ± 2%**。
7. 每个结论都要有可复跑的 run 号或实测数字；拿不到的写"未测，因为…"。
