# 显微镜（microscope2）· 设计说明与验收记录

> 单目复式显微镜，**无专件**：物镜用 M12 板机镜头（f=12mm，**只做一个物镜、不做切换**），
> 目视端口 Ø23.2 目镜 / 摄像端口裸 M12 传感器板**共用同一像面**。
> 外形参考图片（马蹄形底座、C 形弯臂、黑色载物台、镜筒上抱箍），**凡与 PROJECT.md 冲突处一律以 PROJECT.md 为准**。

## 1. 高度链（整机唯一的主尺寸链）

全部零件**按装配位姿直接建在世界坐标系里**（装配变换为单位阵），所以 datum 就是世界坐标。

| 环节 | 值 | 依据 |
|---|---|---|
| 台面 / 底座上表面 | z = 0 → 12 | 底座 150×120×12 |
| 立柱顶面 = 弯臂底面 | z = 212 | 立柱 Ø22×200 |
| 槽底 | z = 228.63 | 台面 230.13 − 槽深 1.5 |
| **标本面** | **z = 230.00** | 槽底 + 载玻片 1.2 + 盖玻片 0.17 |
| **镜头座安装面** | **z = 243.00** | 标本面 + **物距 u = 13.0** |
| **像面（目镜筒光阑定位面）** | **z = 399.00** | 安装面 + **像距 v = 156.0** |
| 抱箍座中心 | z = 365.00 | 156.0 − 13.0 − 8.0(镜头座高) = **135.0** |

**光学核算**（M12 f=12 有限共轭）：`M = v/f − 1 = 156/12 − 1 = 12×`，`u = f(1+1/M) = 13.0mm`。
f=25 → 5.2×/u=29.8；f=6 → 25×/u=6.2 → 调焦需覆盖 **u 6.2…29.8**。

## 4. 各里程碑验证记录

### 4.1 尺寸链的两条独立通道（M3 点名）
- datum 链：`u = 13.000`、`v = 156.000`（`measure_distance` 走 datum，精确解）
- 表面吸附：镜头座安装面 ★ → 载物台**槽底** ★ = **14.37** = u(13.0) + 标本面高出槽底(1.37) ✅ 两条通道对得上
- `measure_closest` 镜筒下端 ↔ 载物台面 = **12.87**（= u − 0.13，标本面比台面低 0.13）✅

### 4.2 点名的位姿干涉检查（`validate_assembly`，16 件全上）
全机 **16×15/2 = 120 对，interferenceVolume 全为 0**；只有已声明的贴合/滑动面落在 0.75mm 阈值内。

### 4.3 机构运动（`simulate_motion`）
- 行程 **24.91 mm**（指令幅度 ±12.5 → 25.0；采样点未正好落在峰值），干涉时间线 **0 次**，关节漂移 **0.0325 mm**，`diverged false`，`overallStatus pass`
- 第二趟按**实际需求区间** δ∈[−16.8,+6.8]（对应 u=6.2…29.8，换 f=6/12/25 三种镜头）跑，同样 **0 干涉**
- ⚠ **仿真器没有齿条-齿轮耦合**：滑座的往复是**给定正弦**（`oscillator`），齿轮轴是独立匀速转动。
  硬把两者对上会让齿面互啃（正弦 ≠ 线性），所以运动仿真里把滑座齿条去掉、啮合另行几何核对。
  这是工具的缺口，不是模型的近似偷懒。

### 4.4 稳定性（`simulate_physics` + 精确质量特性）
把 16 件按装配位姿并成**一个刚体**（`out/asm.scd` → `out/asm.stl` → 语料 v036"整机刚体"），
并用 STL 直接算了精确质量特性（`out/massprops.py`）：

| | 总质量 | 重心 | 前倾临界角 |
|---|---|---|---|
| 配重腔**空** | 902.5 g | (0.7, 29.1, **197.9**) | 11.7° |
| 腔内**加铅丸** 114 g | 1016.7 g | (0.6, 26.9, **176.3**) | 13.7° |

- 5° 斜面（重力 `[855, 0, −9775]`）：**两态都不倒**（`fellOver = false`）。
- 整机外观尺寸 **155 × 155 × 433 mm**（到相机托板顶）。

### 4.5 M4 的两个设计问题（要答案，不要"仿真通过"）

**① 底座配重腔要不要填？→ 填，但理由不是"5° 会不会倒"。**
5° 两态都稳（临界角 11.7° vs 13.7°）。填 114g 铅丸/钢珠的收益是：重心降 **21.6mm**、
临界角 +2°，而且它是**唯一**能改善"被人碰一下"这种瞬态的量。腔已经开好了，成本只是几块钱的配重。
> 注：腔目前**开口朝下**（为打印免支撑）；实际灌配重后建议贴一片胶带/热熔胶封口，或反过来从台面侧灌。

**② 压片簧要不要做？→ 做，但仿真给了一个反直觉的中间结论。**
`simulate_physics` 在**载物台倾斜 10°**（绕 X 与绕 Y 两向都试）下：
**不加压片簧，玻片也没滑出来**（最大水平位移 0.15 / 0.24 mm）——
因为 μ≈0.5 > tan10°=0.18，静摩擦就够了；槽深 1.5 对片厚 1.2 还留 0.3 的挡边。
加了簧反而多动了 0.6mm（刚体簧只是压在上面，仿真里没有预紧力）。
所以"10° 会掉"这个直觉是**错的**。仍然建议做，理由是：
- 悬臂 24×1.5、下压 0.30mm，PLA E≈3.5GPa → 预紧力 ≈ **1.7N** → 摩擦力 ≈0.85N，
  对玻片自重 0.055N 是 **15× 余量**；μ 撑不住的角度 tan⁻¹μ≈26° 才是真正的失稳角。
- 它把玻片**压平**在槽底：玻片在 1.5 深的槽里能微翘，翘 0.17° 就意味着视场边缘跑出 ±6µm 焦深。
- 成本 2.2g PLA。

**③ 滑座会不会自己往下滑？→ 表达不出来（如实说）。**
`simulate_physics` 只有 revolute 关节（PROJECT 缺口 ④），没有 prismatic，
也没有"齿条-齿轮保持力/摩擦"语义。要答这个问题需要给机构加**保持力模型**，现在没有。
工程上本设计的对策写在 `if-11` 的 note 里（弹簧预压消隙 2N + 单向逼近），但**它无法机检**。

## 5. 踩到的坑（都是几何/清单问题，已修）

| # | 现象 | 根因 | 修法 |
|---|---|---|---|
| 1 | 弯臂裙板切进立柱 102 mm³ | 防转平面只到 z=206，其上是 Ø22 圆柱，裙板却做到 228 | 裙板 z>206 段收进到 y=−11.3（v009） |
| 2 | Ø22 齿轮齿顶切进 Ø40 精调环 59.9 mm³ | 齿轮中心距镜筒轴太近（齿顶只差 0.55） | 齿轮中心 y 31.25→**26.5**，齿条节线随之 21.25→16.5（4 件联动） |
| 3 | 轴承座与滑座抱筒环贴合 → 被判未声明邻近 | 凸台前面正好做到 y=40 | 凸台收到 y=39 |
| 4 | 精调环滚花凸台顶进滑座 54 mm³ | 滚花圆柱 z 做到 279（越过 278） | 收到 252…278 |
| 5 | 滑座前伸臂上行撞弯臂"颈"87 mm³、下行撞齿轮 460 mm³ | 前伸臂的 z 窗口两头都顶 | 颈去掉（立板直接搭抱箍梁）+ 前伸臂定在 **z294…310** |
| 6 | 压片簧悬臂起点已开始下压 → 切进台面 0.27 mm³ | 起点 y=46 在槽口 47.35 之前 | 起点挪到 y=47.35（v038） |
| 7 | 清单里 `chain-clamp` 名义写 135 却拿"安装面"当另一端点 → 报 122 | 我的清单写错（几何是对的） | 改成拿"标本面基准点"比 |
| 8 | `if-28` 报 30.0015 | 忘了悬臂 30mm 的水平跨距 | 补一个与触点同轴的"簧根沿"锚点 |

**仍然留着的已知摩擦点**
- `check_assembly` 的邻接发现**默认阈值 0.75mm**，抓不到刻意留的 **1.0mm** 弯臂↔载物台让位间隙
  （`undeclared = 0`）。把 `validate_assembly` 的阈值提到 1.2 才看得到 `arm↔stage min=1.0`。
- `validate_assembly` 的最小距离是**按顶点采样**的（≤1200 点），大网格上会**高估**间隙
  （本案 arm↔stage 被报成 3.19mm，真值 1.0mm）。要精确值得用 `measure_distance` 吸附。
- `check_assembly` 的 `declared` 判定按**零件对**，所以跨零件的高度链自检会把那一对整体"声明"掉——
  本清单的 C1/C2/C3 全部写成**弯臂零件内**自检就是为了绕开这个坑。
- 同轴度只能声明、不会机检（引擎没有 coaxial 算子），本清单用"两点 distance"代理并在 note 里写明。
