# 缝纫机旋梭工作单元（1.5× 演示，两轴布局）

一台桌面演示级的**旋梭工作单元**：手摇 → **上轴**（前端针杆曲柄、后端手摇盘）→ 曲柄-连杆-滑块
驱动针杆上下（行程 26 mm）；上轴后端 30T 同步带轮 → GT2 260 同步带 → 下轴（旋梭轴）带轮 → 旋梭
360°。旋梭轴只做旋转；两轴由同步带保持 1:1 相位。市面机同构：针杆曲柄在**上轴**（upper shaft /
main shaft），旋梭在**下轴**（lower shaft），两轴由带或立轴锥齿轮同步。梭壳被定位指压住不转，
梭芯在壳内；钩尖在机针下止点后扫过针眼。

> 需求：[PROMPT.md](PROMPT.md)。装配契约：[assembly/assembly.json](assembly/assembly.json)（36 接口，rev 29）。
> 面板：项目下拉选 **examples/sewing-rotary-hook**；「运行」→ **r101** 回放（针杆运动，**含关节对扫描**）。
> 两轴布局依据：[US20160289875A1](https://patents.google.com/patent/US20160289875A1/en)（upper shaft 3 + needle-bar crank 7）、
> [US6814015](https://patents.google.com/patent/US6814015/en)（lower shaft S2 驱动旋梭）、
> [US5125354](https://patents.google.com/patent/US5125354/en)（upper shaft 9 = main shaft）。
> 决策记录：`docs/DECISION-LOG.md` 2026-11-22（两轴+同步带）、2026-11-23（关节对逐位姿扫描）。

## 1. 结论与口径

| 主张 | 工具 / run | 结果 |
|---|---|---|
| 整机静态干涉 | 独立全对扫描（23 件 / 253 对，ε=1 mm³） | **0 干涉**，全部 watertight |
| 装配契约 | `check` **rev 29** | **36/36 通过**，0 硬违规，0 未声明邻接 |
| 针杆运动闭环 | `motion` **r101**（驱动上轴 0.5 rad/s，1 圈；**`scanJointPairs: true`**） | **0 干涉**（38 对候选全扫，含 5 对关节对）；行程 **26.001 mm**；关节漂移 **0**；闭环 `frame~bar` |
| 钩尖—针眼时序 | 姿态装配（钩尖 96°、z=22.38；针眼 22.5） | 时序几何成立；脚本仍按旧 r024 布局，需重跑（§6） |
| 上轴—下轴 1:1 | 同步带 30T×2 / GT2 260（带为外购见证；带轮 v126） | 等速 1:1；**physics 带耦合 run 待做**（§6） |
| 旧单轴布局（r024） | — | **作废**：`arbor↔rod` 峰值 75.87 mm³（连杆穿轮毂） |
| r092 的“0 干涉” | — | **作废**：`upper_shaft↔rod` 是转动副对，按设计被排除；按 `scanJointPairs` 重跑找到 **76.9 mm³**（连杆杆身横穿上轴 Ø10）——见 §2 的修法 |

> **这是“机构学成立”，不是“能缝纫”的结论。** 缝线路径、线张力、成缝机理没有建模；同步带
> 的 1:1 是几何见证（带轮同径），带传动的弹性/跳齿未仿真。

## 2. 机构与尺寸

```
手摇柄(-16,z155) → 上轴 Ø10 (z155, y-96..-8.5)
   ├─ 前端曲柄 r13，销 (2.26, 142.2)，销沿 y 伸到 -4
   │     → 连杆 L=25.5（y-6..-4，在上轴前端面之前）→ 针杆跨骑叉口 (0,116.5) → 针杆 Ø8 → 机针（行程 26）
   └─ 后端手摇盘 r20 + Ø8 摇柄销 + 手摇柄；带轮座 y-70..-60 → 上带轮 30T
GT2 260 同步带（y-70..-64）→ 下带轮 30T → 旋梭轴组 Ø10 → 旋梭 Ø45（只旋转）
针杆叉口 = 跨骑式：两条侧轨 x±6.2..7.6（躲开曲柄臂扫掠）、前/后颊夹连杆 y-6.2..-3.8、T 板接杆身
旋梭沉孔 Ø37.6 内坐梭壳 Ø36.6（不转，定位指 Ø2 销入耳孔）；梭芯 Ø30.4 在壳腔 Ø31.4 内
针板：针孔 Ø4.5、观察窗 30×20、定位耳；钩尖顶 z=22.5，针板 z=24
```

| 项 | 值 |
|---|---|
| 旋梭外径 / 钩尖轨迹 | Ø45 / R22.5（1.5× 家用 15 类） |
| 上轴 / 下轴 | z=155 / z=0，中心距 155；带轮 30T×2，GT2 260 mm 闭合环 |
| 曲柄半径 / 连杆 / 行程 | 13 mm / 25.5 mm / 26.0 mm（t=0 为下止点） |
| 连杆平面 / 叉口 | y-6..-4（上轴前端面 -8.5 之前）/ 侧轨顶 z121，顶行程 147 < 曲柄臂最小扫掠 147.3 |
| 针杆 / 机针 | Ø8 轴、夹头 z56.5..67.5 / Ø2.5 针身、Ø3.2 柄、眼 Ø1 @ z22.5 |
| 整机包络 | 135 × 141 × 175 mm |

**时序**：t=0 钩尖在 96°（顶偏右），针尖 z=18.5、针眼 z=22.5，钩尖 z=22.38 与针眼同高；
针杆从下止点向上 26 mm 再回落。驱动 1 圈 = 钩尖 1 圈（带 1:1），每个成缝周期钩尖恰好扫过针眼一次。

## 6. 未决项

1. **上轴—下轴带耦合 run**：motion 无带/齿轮副，需 physics 的 gear 关节（ratio=1）补证 1:1。
2. **时序证据脚本**：`evidence/hook_needle_timing.py` 仍按旧 r024 布局，需按 r101 的链重算。
3. **新件工艺筛查**与**视觉复核**（v143/v144/v149 等）。
4. **交付审计**：`cad_deliver audit` 仍因旧 run 的 superseded 记录与上述项不能排除。
5. **带轮的 GT2 齿形**是近似多边形，非标准齿廓；真实带需按标准重画。
6. **教训（已写进 DECISION-LOG 2026-11-23）**：转动副连接的对不在 motion 时间线里；同一机构里
   曲柄-连杆这类对必须用 `scanJointPairs: true` 或独立逐位姿扫描复核，否则“0 干涉”不覆盖它们。

## 7. 使用的模型与工具链

OpenSCAD（两轴版无齿轮）；DSH CAD 的 openscad 内核 + trimesh（`cad_python`）做独立全对扫描；
motion 的关节对扫描由 `excludedJointPairs`/`scanJointPairs` 提供。旧 r024 的齿轮对（v016/v077）
及其 ±5° 相位干涉问题随布局取消。
