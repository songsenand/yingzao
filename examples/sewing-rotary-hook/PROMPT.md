## 工艺与材料的约束

- 允许集：钣金、冲压、CNC（3 轴铣 + 车）、FDM；**集外工艺未使用**。
- 材料：黄铜（梭壳、梭芯）、304 不锈钢（机架、旋梭轴组、输入轴、针杆、连杆、定位指、销）、
  PLA（轴承座、针板、导座、齿轮×2、手摇柄）。
- 冲压在插件工艺目录里没有独立 id：冲压件（连杆、定位指）按 `sheet-metal-bend` 档筛切割
  特征，模具/回弹/落料为 handoff。这一映射按"实现选择"记录，不是新工艺批准。
- 外购件只允许标准件库内的 6000 轴承；M3 螺钉与 DIN471 卡簧为 BOM 项。

## 必须给出的证据

1. 每个打印/加工件过对应工艺档，排除项写清见证（规则、位置、实测 vs 要求）并回答。
2. 运动：钩尖 360° + 针杆 26 mm 行程，一个周期 ≥24 位姿、0 干涉、关节漂移 ≤0.2 mm；
   时序给出钩尖到针眼的相位关系。
3. 装配契约：同轴、配合、滑动副、时序见证；未声明邻接为 0。
4. 齿轮 1:1：另用 physics 规定比 run 证明传动比；齿面逐相位检查不得省略。
5. 未测项写"未测，因为…"。
