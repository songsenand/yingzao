# β-D-吡喃葡萄糖 球棍模型（可拆装 · FDM）

24 个原子球 + 24 根键棒，全部可以拆开重新拼装；靠一套**统一定位接口**做到"好拆、不晃、不自己松"。

- 外形 **97 × 116 × 55 mm**，PLA 用料 **≈49.9 g**（40 205 mm³，按 BOM 数量求和）
- 7 种零件 / 48 件：碳球 ×6、氧球 ×6、氢球 ×12、键棒 ×24（4 种长度）
- 无支撑；球按建模姿态打印（不要翻转），棍竖立打印。打印性筛查会给球报 33–121 mm² 的"朝下悬垂"——那是球体下半部本身的大角度曲面：球面每层只比上一层外扩约 0.8 mm，逐层可打（这也是实心球能不打支撑的原因）；棍的 37 mm² 来自卡脚导入锥，同样可直接打。

> 设计与接口的依据在 [`spec/design.md`](spec/design.md)，逐次工具与数字的过程记录在 [`BUILD.md`](BUILD.md)。

## 1. 打印

| 项 | 值 |
|---|---|
| 喷嘴 / 层高 | 0.4 mm / 0.2 mm |
| 材料 | PLA（PETG 卡脚更韧，但更"黏"，拆装手感变重） |
| 支撑 | 无（球面底部的渐进悬垂靠逐层桥接；首层是小圆面，建议 2 mm brim） |
| 壁 / 填充 | 3 圈 / 15%（球体主要靠外壁受力） |
| 颜色（CPK 习惯） | 碳=黑、氧=红、氢=白 |

零件数量：

| 零件 | 数量 | 备注 |
|---|---|---|
| 碳原子 C（4 孔，四面体） | 6 | 环上 5 个 + C6 |
| 氧原子 O（2 孔，109.47°） | 6 | 环 O5 + 5 个羟基氧 |
| 氢原子 H（单孔） | 12 | |
| 键棒 7.2（C–O 环内） | 2 | |
| 键棒 6.6（C–C） | 5 | 环上 4 根 + C5–C6 |
| 键棒 5.2（C–H / C–O 羟基） | 12 | |
| 键棒 4.8（O–H） | 5 | |

**两个打印姿态必须照做**：

1. **球按建模姿态打印（+Z 朝上），不要翻转。** 球上 4 个孔里有 3 个斜向下 19.5°，孔上壁近水平；
   模型已经在那三个孔的上侧做了**泪滴排屑**（Ø1.0 偏心孔），把塌陷引到孔外。方向是按 +Z 算的，
   翻转打印会让排屑跑到错误的一侧。
2. **棍竖立、一端卡脚朝下**，加 2 mm brim。首层是 Ø5.2 的环；卡脚是四瓣 0.4 mm 壁（1 圈线宽），
   这是全模型最薄的地方。

## 2. 装配

1. **先拼六元环**：C1–C2–C3–C4–C5–O5–C1。其中 C–C 用 6.6，两根 C–O（C5–O5、O5–C1）用 7.2。
2. **环的最后一个接头最后插。** 环是整套的公差瓶颈（见 §4），先把 5 根插好，最后那根会更容易到位。
3. 再接 C6（6.6）、5 个羟基氧（C–O 用 5.2、O–H 用 4.8）和 7 个 C–H（5.2）。
4. 插到位会有一声轻"咔哒"，台肩面落到孔口的定心平台上就到位了 —— 不需要工具。
5. 拆：捏住球与棍反向拉，卡珠会被挤过喉口（≈10 N）。

> 插的时候沿键轴方向推，不要"斜着撬"：斜着推会让卡脚单边受力，手感变硬。

## 3. 接口：一个 socket，一根 peg，全件通用

```
球上 socket                          棍端 peg（两端相同）
 定心平台 Ø6.3–6.8，深 0.90            台肩面 Ø5.0→Ø6.2 环带（定位面）
 直孔     Ø5.20，深 3.40              定心圆柱 Ø5.00 × 2.18
 环槽     Ø5.90，2.15–3.05            卡珠     Ø5.40，2.18–2.68
 泪滴排屑 Ø1.0（朝 +Z 偏心 2.85）      导入锥   Ø5.0→Ø3.2
```

**六个自由度各归谁管**（这是"定位准确"的全部依据）：

| 自由度 | 约束特征 | 数值 |
|---|---|---|
| 轴向 Z | 台肩面 ↔ 定心平台 | 名义 0；接触环带 0.5 mm 宽 |
| 绕 X / Y 倾角 | 同一对面接触 | 理论 0°（见 §4 的实际限制） |
| 横向 X / Y | Ø5.00 轴 ↔ Ø5.20 孔 | 直径间隙 0.20 → 横向 ±0.10 mm |
| 绕 Z 自转 | 不约束（故意） | 棍是回转体，免掉一个防转特征 |

单接口的"对不对齐"看 `renders/interface_section.png`：左 1:1、右约 3 倍，过轴 45° 剖切（避开 0.6 mm 开缝，否则剖面正好落在缝里、看不到卡脚壁）。图上标了台肩面↔定心平台 0.000、卡脚壁 0.40、peg/孔单边 0.10、卡珠/槽单边 0.25、尖端到底 0.20；由 `spec/make_figure_section.py` 从入库的 v031/v039 STL 直接剖出来，可复现。

**键角精度来自球，不来自棍**：球的四个孔的方向就是键角，棍只负责把两个球按定心平台间距撑开。
所以 48 个关节的制造误差不会累积到键角上。

**为什么不用别的**（完整对比见 `spec/design.md` §2.2）：圆柱压配靠摩擦、FDM 孔径 ±0.1 会让同一批
零件一半插不进一半一碰就掉；螺纹 24 根 × 2 端 × 3 圈太慢且 Ø6 牙型不完整；磁吸要外购件；经典
球头-球窝会让键角自由漂移，和"分子模型要刚性角"正好相反；卡口正锁最可靠但 Ø12 球内做 L 形槽
需要支撑/分半。**本方案把"定位"（面接触）与"保持"（弹性卡珠）分开**，各管一件事。

## 4. 已知限制（请先读这一节再判断"准不准"）

1. **卡脚是弹性的**：卡珠 Ø5.40 过 Ø5.20 喉口时单边挤压 0.10 mm。按悬臂梁估算：四瓣径向
   弹力 ≈5.8 N，经 45° 导入面与摩擦折算成**插入力 ≈11 N（量级 6–14 N）** —— 公式估算 +
   材料牌号假设，**没有实测**。第一版打印后建议用
   弹簧秤拔一次校准；偏松就把 `spec/parts/stick_*.scad` 里的 `bead_r` 加 0.05 重印棍（球不用重印）。
2. **未落座时会晃**：台肩面没压到平台时，Ø5.00/Ø5.20 的间隙允许 ≤5.7° 倾角（atan(0.20/2.0)）。
   装配后 24 根键的网络约束和重力会把台肩压回平台；CAD 仿真不建模这一项（刚性）。
3. **环是公差瓶颈**：CAD 里环精确闭合（残差 0.000 mm），但打印件每个 socket 有角度误差。
   取 σ_angle = 0.5°、σ_len = 0.05 mm 做 20 000 次蒙特卡洛：环的闭合残差
   **中位 0.34 mm / P95 0.68 mm / 最大 1.33 mm**，而 6 个关节的余隙合计约 0.6 mm
   → **90% 的装配靠余隙就能闭上，剩下 10% 要靠塑料的一点弹性**（锥口导入 + 卡脚可让）。
   这就是"环的最后一个接头最后插"的原因。
4. **打印性检查会报排除项**：按 `fdm-pla-0.4` 档案（壁厚下限 1.2 mm），卡脚 0.40 mm 壁与
   球口 0.56 mm 环带会被判 `excluded`。这两处都是弹性件/台阶而不是结构壁，是刻意的
   —— 详见 `BUILD.md` 的打印性表。**不要**把它当成"通过了"。

## 5. 目录与复现

```
spec/
  design.md          设计与接口的唯一真源（参数表、选型依据、自由度分解）
  build_molecule.py  椅式环 + 取代基几何 → molecule.json（自检环闭合/近碰）
  gen_scad.py        → spec/parts/*.scad（7 个零件）+ instances.json（48 个位姿）
  build_assembly.py  instances.json + versions.json → assembly/assembly.json（契约）
  tolerance_ring.py  环闭合公差蒙特卡洛 → tolerance_ring.json
  parts/             7 个零件的 SCAD 源（面板里也有同样几何的版本）
assembly/assembly.json   48 节点 + 每个 peg/球 三条判据
cad-data/                版本库、运行记录（面板读这里）
BUILD.md                 过程记录：每一步跑了什么、返回什么数字
```

重新生成（改参数后照这个顺序）：

```bash
cd examples/glucose-molecule
PY=/home/songsenand/.dsh/cad/runtime/venv/bin/python
$PY spec/build_molecule.py     # 分子几何（改了环/键长才需要）
$PY spec/gen_scad.py           # 零件 SCAD + 位姿表
$PY spec/tolerance_ring.py     # 公差预算
# 7 个 .scad 各自 generate_part 入库 → spec/versions.json
$PY spec/build_assembly.py     # 装配契约
```
