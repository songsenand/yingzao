# 决策记录（append-only）

## 2026-10-04：单物镜方案 + 外形仅作参考

**触发条件：** 第 1 条（用户拍板的决策）。

**要解决的问题：** 参考图片是一台带物镜转换器（ turret，3~4 个物镜切换）的传统单目显微镜；PROJECT.md 的光学方案是 M12 板机镜头（换镜头即换倍率），BOM 里也没有转换器件。图片与 PROJECT.md 在此冲突。

**决策内容：** 用户明确指示——不做物镜切换，**只做一只物镜**（M12×0.5 螺纹口装 f=12 板机镜头）；外形参考图片的整体比例与布局，但一切与 PROJECT.md 不符之处**以 PROJECT.md 为准**（如：照明用 LED 照明座而非反光镜、立柱/弯臂为打印件直线构型而非铸造曲线）。

**理由：** PROJECT.md 是本项目的意图与验收来源；转换器会增加齿盘定位机构且与 M12 镜头方案无关。用户指令优先级最高。

**依据：** 用户原话："不做物镜的切换，只需要一个物镜，其他图片和 PROJECT.md 不相符的以 PROJECT.md 为准"。

**影响：** M3 的镜筒下端只有单一 M12 镜头座接口，无转盘/定位槽机构；装配清单不含转换器接口；换倍率 = 拧下镜头换另一焦距 M12 镜头。
