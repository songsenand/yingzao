# 显微镜项目 · 插件试用方案

> **一句话**：用一台**能真打出来、零件真买得到**的单目复式显微镜，把 harness 的每一层能力真实地用一遍，**并用卡住的地方裁决"缺口的真伪"**（HARNESS §11.1）。
>
> **硬约束（用户定的，优先级高于一切）**：
> 1. **每一件都要能打印出来**——常见 FDM 机、常见耗材、尽量免支撑；
> 2. **外购件要好买**——国内电商当天能下单、单价便宜（全机外购预算 ≤ ¥250）；
> 3. **不用专件**：RMS 生物物镜那类（齐焦 45mm、0.8″×36 螺纹）不进 BOM——贵、且必须一次买对、换不了倍率。改用烂大街的安防/相机件。
>
> **本轮范围（2026-10-01 定）**：**M1–M4**——骨架与高度链 / 调焦机构 / 光学链与双端口像面 / 稳定性。
>
> **M5 移交蒸汽机项目**：显微镜身上没有流体场景（M5 的"灌注腔载玻片"本来就是我为了给 L2 找活干硬凑的，已删）。流体在蒸汽机上才是**问题本身**（进汽—做功—排汽）。M5 原文留在附录 B，等那个项目开工时搬过去改。
>
> **M4 留在显微镜**：它是**刚体**不是流体，而这台机器确实有两个没定的设计问题要靠它回答（配重腔要不要填、压片簧要不要做）——所以它不是"凑数的一次仿真"，见 §3 的 M4。
>
> **这份文档只给意图与验收目标，不给 SCAD、不给清单文件**——替 Agent 做完设计就测不出东西了。完工后再把成品清单与零件源码归档进本目录（那才轮到 HARNESS §6 的 `examples/` 通道）。**附录 A 是给方案制定者的核算，不要粘给 Agent。**

## 1. 项目定义

### 1.1 做什么

单目复式显微镜，**无专件**：打印底座/立柱/弯臂/载物台/调焦机构/镜筒/镜头座/目镜筒/照明座；外购全部是**烂大街的相机与安防件**。

| 子系统 | 方案 | 为什么这条能过关 |
|---|---|---|
| 物镜 | **M12（S-mount）板机镜头**，f=12mm 默认 | 安防/树莓派配件，十几块一个；**换镜头即换倍率** |
| 目视端口 | **Ø23.2mm 目镜**，或 DIY Ramsden（两片 Ø18 f=25 平凸） | 23.2 是国产生物显微镜目镜标准筒径 |
| 摄像端口 | **裸 M12 板机摄像头模块**（IMX219/OV5647 类） | **镜头就是物镜，相机端不需要镜头** → 只是"把传感器放在像面上" |
| 照明 | Ø5 白 LED 直照 + Z 向可调 + PWM 调光 | 无聚光镜；调距离即调照明 NA |

**设计上的关键推论**（M3 要考的就是这个）：M12 镜头是**有限共轭**使用——镜筒固定像距 **v = 156mm** 时，

- 倍率 `M = v/f − 1` → f=12 给 **12×**；f=25 给 5.2×（搜索档）；f=6 给 25×（细节档）
- 物距 `u = f(1 + 1/M)` → f=12 时 **13.0mm**（这就是工作距离，比真物镜宽裕得多）
- 所以**换镜头只换倍率与工作距离**，分辨率基本不变；**但调焦行程必须能覆盖 u 从 6.2mm 到 29.8mm → ≥25mm**

### 1.2 为什么是这个复杂度

| 项目要素 | 为什么必须有 | 压测什么 |
|---|---|---|
| ~15 个零件、一个装配 | 单件看不出装配表达的价值 | 零件→版本→记录 三级浏览、清单 |
| 5~7 条**数值可判**的接口 | 契约必须可执行 | `check_assembly` 的 L0 算子 |
| 1 条**故意不声明**的邻近配合 | 声明覆盖意图、发现兜住遗漏 | undeclared 通道 |
| 齿条-齿轮 + 精调 | 唯一真能跑起来的机构 | `simulate_motion` |
| 外购件（镜头/传感器/玻片） | 绕标准件设计 | `source: stock`（**今天不能当接口端点**） |
| 悬臂 + 细高身形 | 会倒、会晃；直接决定配重腔要不要填 | `simulate_physics`（M4） |
| ~~灌注腔载玻片~~ | ~~唯一自然的流体场景~~ | ~~`simulate_fluid`~~ —— **为找活干硬凑的，删**；流体属于蒸汽机 |

### 1.5 接口预算（这就是各里程碑的验收表）

**先把一件事说清楚**：`check_assembly` 的每条接口都要**两端都能取到几何真值**（两侧都是版本库里的零件 + datum）。外购件 `source: stock` 没有版本条目 → **不能当接口端点**。所以外购件在这里的正确用法是：把它们的影响**折进生成件的 datum 定义**（见"假设清单"），接口本身一律**生成件 ↔ 生成件**。

项目身份取 **cwd**，而语料存在 **`<DSH_HOME>/cad/` 下**——所以 B 用的是自己的 DSH home，**即使 cwd 相同也是另一份（空的）语料**，A/B 天然不互相污染，这正是这一轮想要的对照条件。

- **不需要备份**：本项目从空语料开始，主仓语料碰不到；
- **不需要 `显微-` 前缀**：零件名只在本项目内唯一，`底座` 不会认领主仓的 `底座`；
- **想强制干净**：删掉对应的 `cad/microscope-<hash>/` 即可（或换一个新目录开会话 = 新项目）。

建议节奏：**先用 B 跑 M1**（GLM 路由，顺手验证上一轮加的 pi-ai 图片预算），再在 A 上跑 M2~M4 完整体验。

## 3. 里程碑

> 每个里程碑的"你要说的话"**可以原样粘贴**。写法是刻意的：给意图、给约束、给验收目标，**不给做法**——做法是 Agent 的活，也是这次要观察的对象。

### M0 · 准备（5 分钟）

1. **以本目录为工作目录新开会话**（不要复用老会话：图片修剪、压缩、装配上下文都要从干净状态开始才可观测）。
2. **⚠️ 选「造物模式」，并且要确认它真的生效——这一步不能跳。** 默认是「标准模式」，而 **CAD 工具是按预设开放的**：标准模式的会话**一个 CAD 工具都没有**（工具表也不含 CAD 技能目录）。实测代价：Agent 拿不到工具，只能自己读插件源码、用 bash 调 OpenSCAD 硬画，最后报 `Error: skill "cad-toolbox" is unknown or no longer available`。
   - **⚠️ 这个选择只落在"当前那个空白会话"上，不会继承给之后新建的会话**（2026-10-01 查实，DESGIGN §13.14）：上一轮用户**真的选成功了**（日志里有一条 `agent-preset/selected → cad`），但 41 秒后新建的显微镜会话**出生仍是标准模式**。所以**顺序很重要：先把目标会话建好、让它成为当前会话，再选预设**；或者干脆把它设为默认预设。
   - **怎么确认真的生效**：面板顶部**没有**琥珀色提示；或直接问 Agent「你有哪些 CAD 工具」（应当列出 `generate_part` 等 11 个）。
   - **最稳的做法（推荐）**：**先**在 设置 → Agent 预设 里把「造物模式」**设为默认预设**，再新建会话——这样会话**出生**就是它，根本不经过那条会丢选择的暂存路径。
   - **丢了怎么办**：会话**还没开始**（还空白）→ 面板的琥珀色提示会说"现在重新选一次还来得及"，**重新选一次即可**；会话**已经开始** → 预设锁死，**再开一个新会话**（本项目语料还没东西，不会有损失）。
3. 右侧栏打开 `CAD 预览` tab（会话头部也有 `CAD` 按钮），**确认零件列表是空的**。
4. 记下开工时间与 `/api/cad/usage` 的当前 `calls`。

### M1 · 骨架与高度链（4 件 + 装配清单）

**目标**：底座 / 立柱 / 弯臂 / 载物台四件成形并装配到位，写出可执行清单覆盖接口 1~5；并且**抱箍座的高度必须是算出来的**——它要保证后面接上镜头座之后，标本面正好落在物距上。

**你要说的话**

```

弯臂（悬伸 60、厚 16，底面贴立柱顶面，另有一竖直面贴住立柱防转；前端做竖直导轨，

然后写装配清单，把接口 1、2、3、4、5 写成可执行条目（名义值、公差、severity），

**期望发生**：4 次 `generate_part`（每次 4 张渲染图）→ `check_assembly` → `overallStatus: pass`。

**面板上该看到**：零件下拉里出现 4 个零件（`底座`/`立柱`/`弯臂`/`载物台`，本项目内从 `p001` 起编号），每个都有版本；切到装配记录能看到接口报告卡片。

### M2 · 调焦机构（粗调 + 精调，5 件）

**目标**：滑座升降 **≥25mm**（换镜头要覆盖 u 从 6.2 到 29.8mm），全程不干涉；并且**精调能到 5µm 量级**。

**你要说的话**

```
加调焦机构：镜筒滑座（抱 Ø34 镜筒，背面一条 mod1 齿条）、齿轮轴（Ø8 轴 + mod1 z=20
直齿轮，一体打印）、两侧粗调旋钮 Ø30、以及一个精调环。轴承座固定在弯臂上，
两个 Ø8 孔把轴压住。滑座沿弯臂的竖直导轨升降。

两个硬要求：
1. 有效行程 ≥25mm（换 f=6 / f=12 / f=25 三种镜头时工作距离跨 6.2~29.8mm，
   粗调要能覆盖）；齿条与齿轮在行程两端都不得脱开。
2. 精调要能稳定停在 5µm 量级 —— 这是 f/2.0 镜头在该倍率下的焦深决定的
   （算一下：NA≈0.22 时总焦深约多少？），而打印件的回程间隙是 0.2mm 量级。
   请给出你的精调方案，并说明它怎么消除回程间隙。

用 simulate_motion 转两圈，报行程、干涉时间线、关节漂移；再跑一次 check_assembly
覆盖接口 6、7、8。
```

**期望发生**：`simulate_motion`（crank = 齿轮轴 kinematic 转动，滑座 prismatic 跟随）；`check_assembly` 覆盖 6/7/8。

**通过判据**：`stroke ≥ 25mm`；干涉时间线全程 `false`；关节锚点漂移 < 0.05mm；接口 6 轴孔间隙进公差。

**阴性对照**：齿条改短 5mm 或把行程上限设到超出齿条 → 必须出现干涉或脱开。

**本次特别要看（全项目最有价值的一次观察）**：
- 它算出来的焦深对不对（§附录 A 有正确量级：**~±6µm**）；**它有没有意识到 0.2mm 回程间隙比焦深大 30 倍**，从而必须做消隙（弹簧预压 / 单向逼近 / 楔形微调）。
- 精调方案合不合理：常见可行解是**用 M12×0.5 螺纹本身当精调**（0.5mm/转，配 Ø40 环 → 5µm 约 3.6°，可手动），或**齿轮减速**，或**楔块/杠杆**。若它开出一个"Ø10 旋钮直接顶"的方案，追问精度。
- `simulate_motion` 是唯一支持 **prismatic** 的仿真器；`simulate_physics` 只有 revolute（§6 缺口 ④）。

**顺手覆盖（各一次）**：`measure_distance` 量一次轴承孔与齿轮轴的配合（与清单的 `diameter-match` 交叉核对——两条独立路径给出同一个数才算验过）；`render_part` 在行程中点出一张剖切图，看齿条与齿轮是不是真在啮合。

### M3 · 光学链与双端口像面（5 件）

**目标**：镜筒 + 镜头座 + 目镜筒 + 相机托板就位；像距 156.0、物距 13.0 落进公差；目视与摄像**共用同一像面**。

**你要说的话**

```
接着做光学链：镜筒（Ø34 外 / Ø26 内，座面到像面 156.0）；镜头座（下端 M12×0.5
螺纹口装 f=12 镜头，上端 Ø26 与镜筒下端配合，Ø26 处要能微调 ±1mm 补偿镜头主面

也就是说：目视和摄像不是两套光路，是同一个像面上的两个插头。

把接口 10、11、12、13、14、15 写进清单，连同前面的一起跑 check_assembly。

**期望发生**：3~4 次 `generate_part` + `check_assembly`（接口 10~15）。

**通过判据**：接口 12 的 `measured` 落在 [155.7, 156.3]；接口 13 落在 [12.0, 14.0]；接口 10/11 间隙与 BOM 目标一致（±0.05）。

**本次特别要看**：
- 它有没有理解**"相机端不需要镜头"**（因为 M12 镜头就是物镜）——若它给相机端又画一个镜头，说明没接住。
- 它有没有为**镜头主面位置未知**留出装调余量（微调螺纹/锁母/垫片），还是把 156.0 当成可以一次打准的硬尺寸。

- `measure_closest` 求一次**镜筒下端 ↔ 载物台面**的最近点对（不用你给坐标，让解算器找）。
- `render_part` 出一张剖切图看镜筒内部与镜头座的螺纹口。

### M4 · 稳定性（+1 件压片簧，回答两个设计问题）

**目标**：不是"跑一次仿真看看"，而是用它回答两个**设计上还没定**的问题：

1. **底座配重腔要不要填**？立柱 200mm + 顶部镜筒/摄像头的悬臂，整机细高。
2. **压片簧（`slide-clip`）要不要做**？玻片槽单边只有 0.15 间隙，倾斜时会不会滑出。

**你要说的话**

```
现在只做稳定性验证，不要改几何。我要两个设计问题的答案，不是"仿真通过了"：

1. 倾倒：整机放 5° 斜面上（重力向量按 5° 倾斜给），看倒不倒。
   跑两态对比 —— 底座配重腔**空** vs **腔内加配重**（自己算该多重，
   或直接把底座密度调到等效质量）。报两种情况的结论，以及各自的**临界角度**。
2. 再补一次"手碰一下"：给立柱顶端一个初始角速度（模拟被人碰），
   看它是回正还是越倒越大。
3. 玻片保持：载物台倾斜 10°，玻片（75×25×1.2 的块）放进槽里，跑两态 ——
   **不加**压片簧 vs **加上**压片簧（悬臂梁尺寸你定）。报滑出 / 不滑出。

另外：滑座在齿条上会不会自己往下滑 —— 这一问如果 simulate_physics 表达不出来，
就直接告诉我"表达不出来"以及为什么，不要绕过去编一个结果。
```

**期望发生**：4~5 次 `simulate_physics`；`fellOver` 判定；稳态穿透 < 0.05mm。

（自己核一下它的算术：5° 斜面的重力向量应是 `[9810·sin5°, 0, −9810·cos5°] ≈ [855, 0, −9775]` mm/s²。另外这个工具**只支持 revolute 关节、没有 prismatic**——第 4 条就是冲这个来的。）

**通过判据**：两个设计问题都有**明确答案**（配重：填不填 + 临界角；压片簧：做不做），而不是"仿真跑通了"。

**本次特别要看**：
- 它有没有把"配重该多少"当成一个**要算的量**（重心位置 vs 底面支撑多边形），还是随手试个数。
- 细高身形（~400mm 高 / 150mm 底座 + 顶部一块摄像头板）**真的会倒吗** —— 这直接决定配重腔是多余还是必需。
- **第 4 条是本轮最有价值的一次取证**：`simulate_physics` 只有 revolute，"滑座会不会自己滑下去"这种**保持力**问题表达不出来（缺口 ④）。让它**如实说"表达不出来"**，比让它编一句"齿条自锁所以没问题"有价值得多。

## 6. 预期会撞上的墙（缺口的真伪由它裁决）

| # | 预期现象 | 意味着什么 | 该改什么 |
|---|---|---|---|
| ① | 外购件**不能当接口端点**（`source: stock` 无版本条目），只能把尺寸折进生成件的 datum 定义 | 尺寸链的**起点**没有几何真值，全靠手写假设；假设一变全链跟着变 | 需要"stock 件 = 实测记录 + 占位几何"机制（proposal §3 已点名） |

### 6.1 本轮不回答的问题（**不是砍范围，是显微镜问不出**）

M5 移交蒸汽机项目，所以下列能力这一轮拿不到真实反馈。**别把本次结论当成对它的判断**：

| 能力 | 本轮状态 | 补偿 |
|---|---|---|
| `simulate_fluid`（L2 流道） | **完全不覆盖** | M5 移交蒸汽机——那里流体不是"找个场景塞进去"，而是问题本身（进汽—做功—排汽） |
| `simulate_physics` 的**保持力**语义（prismatic / 摩擦） | **注定覆盖不到** | 不是"本轮不做"，是工具只有 revolute 关节（缺口 ④）。M4 第 4 条会把这件事当场问出来并记录 |
| `validate_assembly`（点名位姿的干涉检查） | **已补进 M3 的"顺手覆盖"** | 一次调用即可，别省 |
| `measure_part` / `measure_distance` / `measure_closest` | **已补进 M1/M2/M3** | 各一次；M3 那两条还是 datum 链的独立交叉核对 |
| `render_part`（指定相机 / 剖切） | **已补进 M1/M2/M3** | 各一次 |
| `create_part` | 不主动要求 | 只在 Agent 自己想给零件命名时才出现 |
| 弹簧预压 / 消隙（缺口 ③） | **仍会触达** | 就在 M2 的 5µm 要求里——本轮最有价值的一次工程判断，别跳过 |
| 图片修剪（保留 6 轮窗口） | 仍会触达 | M2/M3 轮数够多时；跑完看 `inspect-tool-catalog.mjs` 与 `/api/cad/usage` |

## 7. 时间盒与停止条件

- **单里程碑上限**：20 分钟或 10 轮工具调用，先到为准。超了就停手、记一行"摩擦点"、人工给方向再继续——**超时本身就是数据**。
- **整轮上限**：**M1–M4 一个下午（约 3 小时）**。M5 移交蒸汽机项目（附录 B）。
- **随时可停**：M1 结束就能回答"装配表达有没有用"；M2 结束能回答"运动仿真顺不顺"；M3 结束能回答"绕外购件设计的尺寸链立不立得住"；M4 结束能回答"配重腔与压片簧这两个设计决定"并拿到保持力缺口的现场证据。
- **不要中途改插件**：试用的目的是暴露问题。所有改动记进 §5，等跑完再动代码。

## 附录 A · 外购件可行性核算（**给方案制定者，不要粘给 Agent**）

### A.1 M12 板机镜头当物镜

薄透镜：`v = f(1+M)`、`u = f(1+1/M)`。固定像距 **v = 156mm**：

| 镜头 f | 倍率 M | 物距 u | 视场 (1/2.3″) | 物方 NA (f/2.0) | 分辨率 |
|---|---|---|---|---|---|
| 6 mm | 25× | 6.2 mm | 0.25 × 0.19 mm | 0.234 | ~1.4 µm |
| **12 mm** | **12×** | **13.0 mm** | **0.52 × 0.39 mm** | **0.225** | **~1.5 µm** |
| 16 mm | 8.75× | 17.8 mm | 0.72 × 0.54 mm | 0.219 | ~1.5 µm |
| 25 mm | 5.2× | 29.8 mm | 1.20 × 0.90 mm | 0.206 | ~1.6 µm |

- `NA_obj ≈ (D/2)/√(u² + (D/2)²)`，`D = f/N`；`d = 0.61λ/NA`（λ=550nm）
- **f/2.8 的常见款**：NA 掉到 ~0.16，分辨率 ~2.1µm → **采购要挑 f/2.0 或带手动光圈**
- **固定筒长时换镜头只换倍率**，分辨率几乎不变（u 与 D 同比例变）——这是这套方案最漂亮的地方
- **焦深**：`DOF ≈ λ/NA² + (2·像素)/(M·NA)` ≈ 11 + 1 ≈ **12µm 总焦深（±6µm）**
- **要接受的代价**：板机镜头是按"物在远处、像距 12.5mm"设计的，我们用到物距 13mm、像距 156mm 属严重超纲 → 球差/场曲先于衍射限制画质。对策：**反装**（前组朝传感器）+ **收小光圈**。**实际可用分辨率按 3~5µm 写，别按 1.5µm 立指标。**
- **视场小**：12× 只有 0.52×0.39mm，找目标很痛苦 → 备一个 f=25（5.2×，1.2×0.9mm）当搜索档。

### A.2 双端口共像面

M12 镜头就是物镜，**相机端不需要任何镜头**：镜筒顶做 Ø23.4 孔，其**光阑定位面距镜头座安装面 156.0mm**；目镜插进去看，相机托板插进去拍——传感器落在同一面。**同时看+拍**才需要 45° 翻转镜（升级项）。

### A.3 LED 直照

`NA_ill ≈ r/√(r²+d²)`：Ø5 LED 在 10mm 处 NA≈0.24、20mm 处 ≈0.12 —— 正好跨过物镜的 0.16~0.22，所以**"调距离 = 调照明 NA"物理上成立**。两个必须配的便宜件：**匀光片**（否则看到 LED 芯片的像）、**Ø8~12 视场光阑**（穷人的聚光镜）。PWM **≥2kHz**，否则照片有横纹。

## 附录 B · 移交给蒸汽机项目的里程碑（原文保留）

> **M4 已留在显微镜**（它的两个设计问题见 §3 的 M4）。这里只剩 **M5（流体）**：显微镜没有流体场景——原文里那个"灌注腔载玻片"是我为了给 L2 找活干硬凑的，搬过去时**直接废掉**，换成蒸汽机的实际流道（进汽—做功—排汽，或锅炉/水位）。

### M5 · 灌注腔载玻片（可选，L2）

**目标**：加一件打印的灌注腔载玻片（按标准载玻片外形 75×25 + 蛇形流道 + 进出液口），验证能充满、能排空、无死区。

**你要说的话**

```
加一件"灌注腔载玻片"：外形按标准载玻片 75×25，中央一条蛇形流道（截面 1×0.5，
总长 ~80），两端进/出液口接 Ø1.5 软管。用来长时间观察活体样本，
要求能完全充满（无气泡死角）、能排空。

用 simulate_fluid 跑一遍，报到达率、分段速度、死区。
```

**通过判据**：出口到达率 > 0.6；无明显低速死区（或指出死区位置与改进方向）。

**这一条为什么算"适中"**：不增加机构复杂度，只给 L2 一个自然的用武之地——而且它恰好是"放在显微镜下看的东西"。
