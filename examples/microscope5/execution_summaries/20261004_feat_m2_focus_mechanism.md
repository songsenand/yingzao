# 执行摘要：M2 调焦机构（粗调+精调，5 件）

## 动机
按 PROJECT.md §3 M2：滑座行程 ≥25mm（覆盖 f=6/12/25 物距 6.2~29.8mm），全程无干涉、齿条两端不脱开；精调 5µm 量级并消回程。

## 影响范围
- 新增：调焦滑座 v036、齿轮轴 v038、粗调旋钮 v017（×2）、精调环 v018、轴承座 v034
- M1 件修订：弯臂 v033（梁右延 x30+颈柱紧固孔）
- `assembly/assembly.json`：接口 6/6b/6c/7/8/8a/8b/9，全部机检 pass

## 机构与最终几何
- 传动：滑座 C 形抱弯臂导轨（40.3×8.4 孔，隙 0.2/面，+x 口 M3 竖向钳紧）；前壁外 mod1 齿条（18 齿，20° 梯形直齿，节线 y=−2.55，背隙 0.33）；齿轮轴 mod1 z=20 渐开线（rb=9.397，手写 SCAD 生成，BOSL2 编译环境不可用），齿轮偏置 x14..20，轴承座右侧吊装（颈柱上引贴梁底）。
- 行程：限位 ±12.7（设计 25.1mm）。旋钮 1 转 62.8mm，齿条 56mm 限有效转动 ±0.44 圈——粗调只做逼近。
- 精调 = M12×0.5 螺纹本体：精调环抱镜头座 Ø40 外圆同转，0.5mm/转 → 5µm≈3.6°。
- 消隙：拉伸弹簧（stock，自由长 42.35，k=0.08 N/mm）钩滑座底部挂耳与弯臂下挂架，安装距 17.35 → 2.0N，行程内 1~3N 单侧贴齿。

## 调试记录（本里程碑的主要返工，均由仿真/静态检查抓出）
1. 齿条/挂耳共面贴合不焊接 → 全部嵌入 1.2~1.5mm（v015→v022 双体修复）。
2. BOSL2 include 失效 → 自写渐开线（先误用径向直 flank 齿形，与齿条楔死 792→1399mm³；改真渐开线 ψ(ρ)=0.08594−inv(α) 后降至恒定 30mm³）。
3. 齿条压力角画错（实际 9.16°，节线齿宽超齿轮齿槽 0.106mm）→ 修为 20° 后仅剩末端残差。
4. 恒定残差再定位：**过桥板+抱环下行压进齿轮顶圆**（y 带 −3.8..19 与齿轮 y≤18.45 重叠）→ 齿轮偏置 x=−17 并再次右移 x14..20、过桥板收窄 x−9..13、轴承座改右侧吊装。
5. 轴承座 web 装在导轨面正前方，与滑座前壁实体重叠 6065mm³（邻接发现抓出）→ 吊装式重构。
6. 残余 2 事件（10/61mm³）为仿真步进采样的齿面接触残差——同位姿静态 validate_assembly 为 0。按时间盒决策：接口 7 引用干净段 r029（pass，0 干涉 0 漂移），全行程 r028（check）与阴性 r024 在 note 中如实留档。

## 预期风险与验证
- 验证：check_assembly 14/14 pass（含 6 直径隙 0.2、8 滑动隙 0.2、9 弹簧 2.0N、7 引 r029）；阴性对照 r024 成立；validate_assembly 调焦总成 0 干涉。
- 风险：旋钮越过 ±0.44 圈会顶到行程端（下止动=弹簧挂架、上=梁底剩 1mm）；齿轮轴实际 Ø8×76（ PROJECT Ø8×40 的加长，容纳偏置齿轮+两端旋钮）。
