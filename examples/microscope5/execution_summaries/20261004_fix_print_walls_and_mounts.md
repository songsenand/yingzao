# 执行摘要：亚线宽壁与固定链修正（面板截图复核）

## 动机
用户在 CAD 面板上复核 `调焦滑座` 时，壁厚工具报 **0.37mm** 并追问"强度够么、是不是设计错误"。
顺此线索全面复查后，发现**一类系统性建模错误**：多处切削/孔洞越界，留下亚线宽（< 0.4 喷嘴一条挤出线宽 ≈0.42–0.45mm）薄膜；并有一处"固定链断裂"（零件根本没被固定）。这些都不是薄壁朝向问题，而是几何错误，打印检测（薄壁/悬垂）与静力校验都不会主动报出来。

## 影响范围
- 零件：`调焦滑座`、`弯臂`、`轴承座`、`载物台`、`照明座`
- 装配清单：`assembly/assembly.json`（接口 7/8a/8b/9 的判据与端点）
- 仿真工件：`整机刚体（M4 仿真用）`
- 文档：M1~M4 执行摘要、交付表（见各自"后续修正"节）

## 具体操作步骤
1. **调焦滑座 v036 → v066**（`调焦滑座`）
   - 导轨孔 40.3 → 34.3（配套导轨 40 → 34），两侧壁 **0.35 → 3.35mm**；
   - 原"抱箍式 C 口钳紧"是**假的**：三个螺钉切削（Ø3.4×2、Ø6.5 沉头）位于 (16,−16)，而导轨孔为 x±20.15/y−20.3..−11.8——该点整个在孔腔内（即导轨体内），**没有切到任何材料**，滑座对导轨实际无夹紧、光轴方向有 0.4mm 游隙；
   - 改为**真定位**：背梁 2×M3 紧定（Y 向，压导轨背使之贴前壁）+ −X 壁 2×M3 紧定（X 向，压导轨侧使之贴 +X 壁）；紧定孔为盲孔（不击穿内壁留薄边）；
   - 背梁在 |x|<9 留中央让位开口，兼作弯臂背脊梁与弹簧的通道。
2. **弯臂 v033 → v071**（`弯臂`）
   - 竖直导轨 40 → 34 宽（换取滑座厚壁）；防转唇/梁/抱箍孔不变；
   - 弹簧挂架从导轨底端移到**背脊梁（|x|≤8）下端**（原位置挡住滑座轴向装配路径），挂耳加厚到 7.8mm 并**居中开 Ø4 钩孔**（原偏心孔壁仅 0.5）；
   - 修正梁底"轴承座紧固孔"：原孔在 (23.5/26.5, y=6)，而梁体只在 y −47..−12——**孔开在空气里**；改为 (26.5,−25)/(26.5,−18) 的过孔 + 梁底铜螺母坑。
3. **轴承座 v034 → v082**（`轴承座`）
   - **固定链断裂**：颈柱原在 y 0..12，弯臂梁在 y −47..−12，二者**完全不相交**（12mm 空隙），所谓过梁螺栓孔也在梁体之外——轴承座（承载齿轮轴与全部调焦反力）**没有任何固定**；改为颈柱深延到 y −30..2、上端咬入梁底 0.5，2×M3×30 自下方穿颈柱拧入梁底铜螺母（颈柱底 Ø6×8 沉头）；
   - 本体后移到 x 22..33.5（完全避开齿条 x≤20 与齿轮 x 14..20），轴孔 Ø8.2 直通，取消原"齿轮让坑"（原让坑掏穿前端面留 0.077 薄片）；
   - 本体加深到 y0..14，使轴孔 +y 侧壁厚 0.46 → **2.31**。
4. **载物台 v048 → v079**（`载物台`）
   - 滑轨 y 向 4 → 8mm 宽，锁紧槽 3.2 两侧各留 **2.4**（原 0.4）；
   - 吊架改**每侧 1×M3**（自下）+ 台面内 Ø4.2×4 铜螺母坑，孔位内移到 x±25（原 Ø4.3 坑离外轨外面仅 0.35、且沉头与外轨槽相交留 0.14）；
   - 内轨增设过梁槽（与外轨槽同位，z15.5..44 与挂台底面相接，无薄壁），使照明座窄梁可穿过成为单一实体。
5. **照明座 v047 → v080**（`照明座`）
   - 顶桥原为 x24..40 整块，**横穿载物台内轨与外轨**（干涉 230mm³）；改为 2.6mm 窄梁，从本体穿过内轨槽+外轨槽接到外侧垫板；
   - 滑翼由 4.0 收窄到 **3.7**（导槽 4.0 → 每侧 0.15 滑动隙，否则打印后滑不动）。
6. **装配清单同步**：接口 7 由 `motion-clearance(r029)` 改为 `distance`（节线重合判据，见下"工具局限"）；8a 实测 0.000（颈柱贴梁底）；8b 名义值 0.5 → **9.0**（轴承座后移后过桥板右缘到其左面的 x 向让位）；9 弹簧自由长 42.35 → **76.0**（安装距 51.0，k 0.08 → 2.0N）；`轴承座.左面` 基准随本体移到 x=22；补 `载物台.顶面` 基准（接口 17 端点缺失，曾导致校验工具报错）。

## 预期风险与验证
**逐件打印检测（每件修改后均复跑 `check_printability`）**
- 调焦滑座 v066：最薄壁 0.675（原 0.35；余下薄样本为模数1齿条齿顶 0.49，属细牙齿轮固有，见下）
- 弯臂 v071：最薄壁 **1.355**，薄样本 **0**
- 轴承座 v082：最薄壁 **2.306**，薄样本 **0**
- 载物台 v079：最薄壁 **1.204**，薄样本 **0**
- 照明座 v080：最薄壁 **2.6**，薄样本 **0**
- 照明座连通性：`check_connectivity` = single-body（1 实体）

**装配校验**（`validate_assembly`，6 件 15 对，阈值 1mm）：**干涉 0**；5 个"过紧"全部为声明配合：弯臂↔轴承座 0.000（颈柱贴梁底）、载物台↔照明座 0.150（滑翼导槽）、齿轮轴↔轴承座 0.100（轴颈压入）、弯臂↔调焦滑座 0.150（导轨侧隙）、调焦滑座↔齿轮轴 0.238（齿侧隙）。
**契约校验**（`check_assembly`，阈值 1mm）：**26/26 pass，硬违规 0、意图不符 0、跳过 0、未声明接触 0**。
**整机刚体**（`整机刚体（M4 仿真用）` v081 → v083 重建）：4 shells（原 5，轴承座并入主体壳），605.4 → 606.1cm³；5° 倾斜 2s **直立，穿透 0mm**；CoM (0.765, 4.27, 89.64)，前向临界角 31.9°——M4"配重腔不填"结论不变。

**工具局限（如实记录，不作为设计依据）**
1. `simulate_motion` 齿条模式（`pitchRadiusMm`）把驱动角与齿条位移各自积分，出现随时间**增长**的假干涉（5→937mm³），与同位姿静态校验（0.238mm 侧隙）矛盾；且行程包络改用显式位姿时又发现 2. `validate_assembly` 的 `pose` 旋转**绕世界原点而非基准轴**（实测把齿轮轴甩出 176mm 外，等效无效）。
   → 齿条-齿轮相位改为**解析证明 + 静止位姿实测**：模数1、z=20 → 20齿×π = 2π×10 **精确**，中心距 10.00 = 节圆半径，滚动比 z=−10·θ，故静止位姿实测侧隙 0.238mm 在**全行程成立**；啮合区间 148.5..195.7 ⊂ 齿条 146.9..197.1。

**已知取舍（非本轮引入，但需诚实记录）**
- 齿条/齿轮齿顶 0.49mm：模数1细牙固有（齿轮齿顶同理），属常规可打印细节，切片器会略作圆化；这是"0.675 最薄壁"的来源，不是结构壁。
- 照明座行程：受吊架挂台限制为 **−3..+11mm**（原记录 +20/−3 有误），对应 LED 距离 21..35mm → 照明 NA **0.07..0.14**，低于物镜 0.22，即满孔径照明欠填充（偏暗）。若需提升，应把 LED 座移到本体上表面（后续改版项）。
- 打印朝向：载物台需**台面朝下**打印（吊架/抱箍朝上生长；滑槽底 25.3mm 宽为桥接 ≤30 允许）；底座**倒扣**打印；轴承座竖放（颈柱朝上，Ø8.2 轴孔下半为小跨桥接）；照明座倒放。
