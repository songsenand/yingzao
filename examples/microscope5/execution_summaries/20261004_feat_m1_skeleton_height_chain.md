# 执行摘要：M1 骨架与高度链（底座/立柱/弯臂/载物台）

## 动机
按 PROJECT.md §3 M1 建立显微镜骨架四件与高度链，为后续调焦（M2）与光学链（M3）提供装配基准。
高度链是既定光学的前提：M12 f=12 镜头有限共轭使用，v=156.0 → M=12×，u=13.0。

## 影响范围
- 版本库零件：底座 v001、立柱 v013、弯臂 v014、载物台 v009（阴性对照件 立柱 v006 留档不作交付）
- `assembly/assembly.json`（接口 1、2、3、4、5 + 邻接发现后补声明的 5a）

## 高度链（世界坐标，z=0 为桌面；最终布局光轴在 x=0, y=37）
| 基准 | z (mm) |
|---|---|
| 底座顶面 / 立柱法兰底面 | 12.0 |
| 立柱顶面 / 弯臂底面 | 218.0 |
| 载物台顶面 / 槽底 | 60.0 / 58.5 |
| **标本面** = 槽底+1.2+0.17 | **59.87** |
| **镜头座安装面** = 标本面+13.0 | **72.87** |
| **像面** = 安装面+156.0 | **228.87** |
| 弯臂抱箍环中心（镜筒轴过此）| (0,37,196) |

核对：228.87−72.87=156.0 ✓；72.87−59.87=13.0 ✓。

## 布局修订（与初稿的差异，均由 validate_assembly 干涉检出驱动）
1. 竖直导轨从立柱正后方（y−40..−26）前移到立柱前切线之外（y−20..−12）——初版导轨整个埋在立柱柱身体积里（26972mm³ 干涉）。
2. 立柱柱身前面开防转平面（弦切 y=−22，宽 9.16）；弯臂防转唇改为 9mm 宽平板贴该平面——初版方唇包裹圆柱面造成 518mm³ 干涉。
3. 齿条/齿轮系移到导轨与镜筒之间：齿条在滑座前壁（节线 y=−2.55），光轴相应移到 y=37（z 向高度链不变）。
4. 载物台台面后缘延到 y=−18 与抱箍环实体重叠 3mm（修双体）。
5. PROJECT.md 预想的"弯臂前端面↔载物台后缘 1.0mm 让位"在本布局中两件 z 向相距 65mm，3D 最近距离不近，邻接发现抓到的是**立柱↔载物台抱箍 0.2mm 配合**——已补声明为接口 5a，发现通道验证有效。

## 具体操作步骤
1. `底座` v001：150×120×12；底面配重腔 96×64×5.5；法兰孔 Ø40.15×5；4×Ø4.3×6 铜螺母沉孔；四角 Ø16×2 垫位。
2. `立柱` v013：Ø22×200 + 法兰 Ø56×6 + 止口 Ø40×5 + 柱身前防转平面；顶面 2×Ø4.3×8 铜螺母孔。
3. `弯臂` v014：梁 44×35×16（z218–234）+ 导轨 40×8×94（z125–219，前面 y=−12 为滑动面）+ 防转唇（面 y=−22）+ 弹簧挂架（z117–126，兼下止动）。
4. `载物台` v009：110×90×8（y−18..72）+ 玻片槽 75.4×25.3×1.5（中心 y=37）+ 通光孔 Ø12 + 抱箍环 Ø34/Ø22.4（开缝+M3 钳紧）+ 照明座导耳 ×2。
5. 清单 6 条接口全部机检通过；阴性对照（止口 Ø39.5）触发 hard-violation 后改回。

## 预期风险与验证
- 风险点：立柱防转平面与导轨面是打印竖直面（无支撑问题）；载物台抱箍环孔 z 向贯穿、免支撑。
- 验证：check_assembly pass 6 / hard 0 / skipped 0 / undeclared 0；validate_assembly 干涉 0；阴性对照必须报错（已验证）。
