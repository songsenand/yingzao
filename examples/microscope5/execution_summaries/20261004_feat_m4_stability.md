## 两个设计问题的答案
### ① 配重腔填不填 → **不填（保留为选装）**
- 实测整机 CoM (0.63, 4.38, 88.08)mm，质量 ≈0.62kg（PLA 1.05e-6）。
- 支撑多边形 150×120：前向临界角 **32.3°**、后向 36.2°、侧向 >40°。5° 工况余量 6 倍。
- 填 240g 钢（腔 33.8cm³×0.9 填充）：CoM z 88→64mm，前向临界角 32.3°→**40.9°**。
- 结论：仅当台面常斜 >15° 或镜筒顶部常载摄像头模块时才值得填；BOM 保留腔体选装。
- 仿真注记：求解器缺省接触无摩擦，5° 工况机身**滑下**斜面（y+69/z−789，姿态保持直立=滑非倒）——倾倒判据由上述解析给出，仿真佐证了"不旋转"。

### ② 压片簧做不做 → **做**
- 无簧 10°：玻片位移仅 0.20mm（默认接触摩擦恰好 ≥ tan10°），处于边界。
- 有簧（0.5 过盈预压 ≈0.17N）：抗滑裕度提高约 5 倍，且覆盖振动/手持扰动。成本 4g/件。
- 压片簧 v056：台阶落地式（脚座 2×M3×8 自拧 + 高段跨台面 0.5 + 低段入槽压玻片顶）。

### ③（PROJECT 第 4 问）滑座会不会自己下滑 → **simulate_physics 表达不了齿轮保持**
- 解析保持分析原样输出：μ=0.3 → cap 9.98N vs 轴向驱动 1519N → **SLIDES under gravity**——竖直导轨无正压力，μ·m·g⊥ 恒为 0，这是**工具语义边界**（缺口④），不是设计缺陷。
- 真实保持 = 齿条-齿轮不可逆性 + 精调 M12×0.5 螺纹自锁 + 旋钮静摩擦；r029 运动半程 0 干涉佐证啮合面连续接触。

### ④ 手碰
- 0.1 rad/s：回正（stayed upright）；0.5 rad/s：仿真判倾倒（1.05s）。
- 解析：0.5 rad/s 动能 ≈0.77mJ ≪ 越障能 ≈103mJ → 实机（橡胶脚垫 μ≈0.8）应回正；仿真倾倒标签源于零摩擦接触的滑移耦合。设计裕度充足。

## 修正记录（v051 → v057）
v051 合并时机早于最后三次零件修订，内含旧精调环 v018（耳落孔腔）、旧旋钮 v017（紧定薄片）、旧压片簧 v050（叶嵌台面）。已用最终版本重建为 **v057**（593.98cm³，+7.2cm³ 净增量），并复跑：

- 5° 倾斜（240g 配重）：直立 ✓（r050）
- 新 CoM (0.61, 4.78, 88.14)——与 v051 的 (0.63, 4.38, 88.08) 几乎不变，前向临界角 32.3°→32.1°，**结论不变**
- 玻片保持复跑（r051，正确 v056 簧）：10° 下滑移仅 x+0.13mm（其余为 0.5 过盈的求解器沉陷），保持 ✓；并如实修正：首轮"有簧"跑（r041）用的旧 v050 簧嵌在台面里实际没压到玻片，该轮等价于无簧——结论"做簧"的依据是构造上的机械保持+裕度，不依赖那轮

## 二次修正（v057 → v060，用户面板截图复核发现）
粗调旋钮 v053 仍有**建模错误**：D 平面切削立方体贯穿整个旋钮，在盘上开出 10.6×11.4mm 窗、下缘只剩 1mm 薄片（面板截图红框）。该窗"可打印"，薄壁/悬垂检测不报——属渲染审查漏看，非打印检测失职。修复链：
1. v058：D 切削限制在孔周 Ø12 圆柱域内（intersection）→ 盘面开窗消除；
2. v059：紧定沟槽 +y 加宽让开毂肩曲面 → 0.05 刀口膜消除；
3. 终态 0.062 读数位于 D 平面与孔圆柱的相切相贯线（两空腔连通处无材料膜，watertight ✓、渲染确认 D 孔干净）——判为采样伪影，接受。
整机刚体随之重建为 **v060**，5° 工况复跑直立 ✓（r052）。CoM/临界角结论不变。
