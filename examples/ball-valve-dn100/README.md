# DN100 PN16 两片式法兰浮动球阀（ball-valve-dn100）

一个完整走通“建模 → 装配契约 → 运动学 → 流体 → 工艺路线”的示例：**不买成品件**，
只用 **砂型铸造 + 模锻 + CNC（车/铣）** 做出 DN100 PN16 法兰球阀，除非你确认，否则不新增
工艺（例如橡胶模压、电镀、焊接）。

| 项 | 取值 |
|---|---|
| 公称 | DN100 / PN16 / 全通径 |
| 结构 | 两片式、法兰连接（EN 1092-1 PN16）、浮动球 |
| 面到面 | 229 mm（EN 558-1 series 14，含突面） |
| 球 / 座孔 | Ø160 / Ø104（球通孔 Ø100） |
| 阀杆 | Ø28，方头 22×22，90° 行程 |
| 手柄 | 400 mm 力臂，90° 限位（-12°/+102° 止挡销） |
| 重量（几何×密度） | 约 38 kg（阀体 16.7 + 端盖 8.1 + 球 7.9 + 阀杆/压盖/手柄 4.0 + PTFE 1.3） |
| 介质工况 | 纯水，入口 2.0 m/s（≈56.5 m³/h） |

## 目录

```
source/valve.scad        设计源（参数 + 全部零件模块，PART 开关出件）
scripts/build.sh         导出 out/stl/*.stl（openscad）
scripts/inspect_stl.py   逐件报体积/包围盒/非流形边
scripts/line_of_sight.py 通径视线面积 vs 转角（几何，不是 CFD）
profiles/                砂铸 / CNC / 模锻 三个工艺档案（可被 check_printability 直接吃）
assembly/assembly.json   BOM + 29 条接口契约（几何校验通过）
docs/                    设计说明、工艺路线、仿真记录
```

## 复跑

```bash
./scripts/build.sh                       # 需要 openscad
# 导入：cad_part import out/stl/<件>.stl（8 个零件 + 3 个流道域）
# 装配：cad_assembly check  (assembly/assembly.json)
# 运动：simulate_motion（r019：90°，24 位姿，0 干涉）
# 流体：simulate_fluid（r017/r018 主结果，r004 直管标定，r006-r009 分辨率/负对照）
```

`cad-data/` 是本地语料（gitignored），克隆后没有版本和 run，需要按上面重新导入/复跑。

## 结果（先看结论）

- **装配**：29/29 接口通过，0 未声明邻接，0 硬冲突；干涉仅有 0.002 mm³ 级的多边形残差。
- **运动**：0→90° 全行程 24 个位姿 **0 干涉**（r019）；最大采样间隔 3.9°；关节漂移 0；限位销与手柄凸台
  在两端各留 1.5 mm，止挡接触发生在 -1.7°/+91.7°（约 1.7° 越程）。
- **流体**：全开到出口的水**到达率 86%**（dx4）/ 82%（dx3），45° 时 **75%**；质量守恒误差 0，
  无发散。**发动机不给压降/Cv**；90° 全关工况不能当密封试验（见 docs/SIMULATION.md 的局限一节）。
- **工艺筛查**：9/9 自制件已筛（5×not-excluded，3×difficult 棱线，1×excluded=球孔口锐边，需 0.5×45° 倒角）。
- **工艺**：阀体/端盖砂铸 WCB + CNC；球/阀杆/手柄模锻 + CNC；PTFE 座/填料/垫片车削或铣削；
  紧固件与铭牌外购；**非金属件允许按需外购**（用户 2026-11-17 追加，本版仍自制）。
  **没有新增工艺**。

## 已知缺口（都写在文档里，不是隐藏项）

- 拔模斜度、铸造圆角、锻造圆角没有建进 CAD（由模具/砂型保证）——`profiles/sand-cast-wcb.json`
  直接筛这份几何会报 `draft` 见证，那是尺子用错了对象，不是设计被否决。
- 阀杆顶部 M20×1.5 螺纹、手柄锁紧螺母没建几何（螺母外购）。
- 球座 0.2 mm 预紧间隙是**建模间隙**，PTFE 受压变形没有仿真。
- `simulate_fluid` 的 schema 要求 `pipeScad`，即使传 `versionId` 也会被入参校验拒绝；本示例用
  `import("<version>/model.stl")` 绕开，几何与登记的版本完全一致（见 docs/SIMULATION.md）。
