# 设计说明：DN100 PN16 两片式法兰浮动球阀

坐标：介质轴 = X，阀杆轴 = Z（z-up），球心在原点，单位 mm。

## 1. 尺寸从哪里来

| 尺寸 | 值 | 依据 |
|---|---|---|
| 面到面 L | 229 | EN 558-1 series 14（GB/T 12221 突面式 229 / 环连接 241），量到突面 |
| 管道法兰 | Ø220，PCD 180，8×Ø18 (M16)，厚 20，突面 Ø158×3 | EN 1092-1 PN16 DN100 |
| 球 | Ø160，通孔 Ø100（全通径） | 球径/通径 1.6，DN100 全通径常规值 Ø150–165 |
| 阀座 | 外径 Ø147.8，内孔 Ø104，45° 密封锥 | 密封带宽约 4 mm；0.1 mm 外径间隙让座浮动 |
| 壁厚 | 腔体 11 mm（Ø164 内 / Ø186 外） | ≥ ASME B16.34 Cl.150 NPS4 组 1.1 的 9.5 mm |
| 中法兰 | Ø236，PCD 208，8×M16 | 见下面“为什么中法兰比管道法兰大” |
| 阀杆 / 填料 | Ø28 / Ø40×24 填料，Ø44 防吹出台肩 | 常规 DN100 配比（Ø25–30 / Ø38–45） |
| 操作扭矩 | 约 130 N·m（PTFE 座，常温清水） | 厂家样本区间 100–180 N·m；400 mm 手柄 → 325 N 手力 |

## 2. 装配链（也是装配顺序）

1. 左阀座从右端 Ø164 开口送入，滑进左座孔 Ø148；
2. 球从同一开口送入，靠到左座上；
3. 右阀座装进端盖 Ø148 座孔；
4. 端盖 + PTFE 平垫（Ø170/Ø182×1.9）扣上，8×M16 拉紧；
5. 阀杆从**腔体内侧**向上穿：Ø44 台肩进到 Ø44.6 孔，坐在 z=130 的 Ø40 肩上（防吹出）；
6. 4 道 PTFE 填料 130→154，压盖压紧（4×M10）；
7. 手柄套 22 方头，M20 锁紧螺母压住（螺母外购，螺纹未建）。

## 3. 为什么中法兰 Ø236 比管道法兰 Ø220 还大

Ø160 的球必须整体从端盖侧的开口送进腔体，所以中法兰处的内孔必须是 Ø164，而不是座孔
Ø148。8×M16 只能落在 Ø164 之外：PCD 208（孔内缘 r=91）距腔壁 r=82 有 9 mm，垫片
（r 85–91）夹在中间。这是“球从一端装入”的两片式结构的直接后果；想缩小中法兰，就得改
三片式（球从中间装）或缩小球径——两者都会改变结构选型，不是可以顺手改的尺寸。

## 4. 密封与预紧

- 球座密封线在 r=56（Ø112），座锥面与球面留 **0.2 mm** 建模间隙；真实预紧靠 PTFE 受压
  变形（16 bar 下约 0.2–0.3 mm），**没有仿真**，只作为接口公差记录（I5/I6：57.1–57.5）。
- 阀杆密封是 4 道 PTFE 填料（无 O 圈、无橡胶）——这是“不新增模压工艺”的直接代价：
  填料需要压盖持续预紧，且摩擦力矩随压紧量上升。
- 中法兰是 PTFE 平垫（1.9 mm 在 1.6 槽内压缩 0.3 mm）。**0.3/1.9 ≈ 16% 压缩率偏低**
  （PTFE 常取 20–30%），实际应做到 2.2–2.4 mm 厚或改带金属芯垫；这一条记在垫片的
  视觉复核里。

## 5. 90° 限位

限位销在压盖 Ø120 限位板上，角度 **-12° / +102°**，Ø8；手柄底部凸台在 r 47–55、±6°。
几何上：凸台与销的最近距离 1.5 mm，止挡接触发生在 **-1.7° / +91.7°**，即 90° 行程
+1.7° 越程。这个越程是刻意的（避免球与座在死点被硬顶），但意味着**开度指示不能只看手柄
贴死**；要真正 0/90° 定位，应把销位改到 -10.3°/+100.3°（贴死）或在阀杆上加刻线。

## 6. 建模约定

- 布尔构造里相邻图元重叠 0.6 mm，避免共面布尔留下重复壳（阀体早期版本就因此被报 2 个 body）；
- 所有交付零件都是**单连通实体**（`shells=1`，流道域是 2 个壳：壁 + 球，属于仿真体）；
- 尖角保留：铸造/锻造圆角、拔模斜度未建（见 README 的已知缺口）；
- 阀门行程由“球+阀杆+手柄”合并体 `启闭组件`（v020）表达，运动仿真用它对抗阀体/端盖/座/压盖。

## 7. 强度没有主张

本示例没有做应力仿真，也没有把任何壁厚当作“算过”。11 mm 是按标准最小值加余量选的；
中法兰在 16 bar 下的螺栓预紧与垫片比压需要按 GB/T 12224 / ASME VIII 另算。
