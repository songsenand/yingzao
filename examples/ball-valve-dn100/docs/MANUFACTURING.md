# 工艺路线：砂型铸造 + 模锻 + CNC（不外购成品件）

用户确认的允许集合：**sand-casting / forging / cnc-3axis / cnc-turning**（`assembly.json` →
`manufacturing.allowed`，`approvedBy` 记录了会话确认）。紧固件与铭牌是唯一的外购件；
PTFE 只买**材料**（棒料/板材），零件自己做。

## 2. 三个工艺档案

`profiles/` 下三份 profile 的 `process` 字段分别是 schema 的族枚举 `casting` / `forging` /
`CNC-3axis`（目录 id 是 `sand-casting` / `forging` / `cnc-3axis`，两套词表不一致，profile 的
`notes` 里写明了映射）。所有数字都是 **rule-of-thumb 草稿，未标定**。

| 档案 | 关键阈值 | 状态 |
|---|---|---|
| `sand-casting-wcb` | 壁厚 ≥6、拔模 ≥2°、深径比 ≤2、公差 1.5 | 拔模/圆角是**图案/砂型**属性，CAD 里没有 |
| `cnc-3axis-cast-steel` | 壁厚 ≥3、刀具半径 ≥3（Ø6 刀）、深径比 ≤4、公差 0.1 | 已对阀体筛过，见下 |
| `die-forge-2cr13` | 壁厚 ≥4、拔模 ≥3°、公差 0.5 | 球/杆是“锻后全加工”，模锻面不留 |

| 零件 | 筛的档案 | 判定 | 见证 / 最薄读数 |
|---|---|---|---|
| 阀体 v007 | cnc-3axis | difficult | 0.149 mm @ Ø148→Ø100 台阶棱线（棱边效应） |
| 端盖 v008 | cnc-3axis | difficult | 0.469 mm @ 法兰与 Ø170 颈部转接棱线（1 个采样点，0.0004% 面积） |
| 球体 v003 | cnc-3axis | **excluded** | 0.026 mm @ Ø100 孔口棱边（49 点，1.2% 面积） |
| 阀杆 v006 | cnc-3axis | not-excluded | 最薄 10.0 mm；0 个圆孔 |
| 手柄 v010 | cnc-3axis | difficult | 1.10 mm @ 毂与臂结合处（6 点，0.17% 面积） |
| 压盖 v009 | cnc-3axis | not-excluded | 4.85 mm；5 个圆孔均可进 Ø6 刀 |
| 中法兰垫片 v012 | cnc-sheet-ptfe-1.9 | not-excluded | 1.9 mm = 板厚本身（用 3 mm 铣削壁规则是**错尺**） |
| 阀座 v019 | cnc-turning | not-excluded | Ø150 棒料、L/D 0.23、回转偏差 0 |
| 填料环 v011 | cnc-turning | not-excluded | Ø42 棒料、L/D 0.15、回转偏差 0 |

**怎么读这些 excluded/difficult**：见证全部落在**两个面收敛的棱线**上（台阶、法兰与颈部转接、
毂与臂结合、孔口），薄区面积占比 0–1.2%。工具自己说明了“薄壳 vs 薄边”的区分；这些是薄边，
不是薄壳。**唯一需要动几何的是球体**：Ø100 孔口要 0.5×45° 倒角——不只是为了过筛，孔口锐边
会刮伤 PTFE 座，倒角同时给装配导向。改球会连带改启闭组件合并体（v020）并重跑运动 r019。

**砂铸/模锻档案没有拿来筛这份 CAD**：这份几何是**加工后**的形状，拔模与锻造斜度在模具上。
拿它去筛砂铸档案，会在每条竖直壁上报 0° 拔模——尺子对错了对象。反过来也一样：不能拿
CNC 档案去筛砂型。铸造/锻造的模具侧要求见第 4 节。

## 4. 交给模具厂/锻模厂的清单（handoff）

- 拔模斜度：砂铸外壁 1.5–2°，砂芯 1–1.5°；锻件 3–5°；
- 圆角：铸件 R3–6（内棱）、R2–3（外棱）；锻件 R2–4；
- 加工余量：每个加工面 2–3 mm（阀体法兰面、座孔、颈部孔；球/杆锻件单边 1.5–2 mm）；
- 收缩率：WCB 线收缩 1.5–2%，需在模样上放；
- 浇冒口/冷铁、热处理（WCB 正火；2Cr13 调质）、无损检测（RT/UT 按订单）、
  2.4 MPa 水压试验与 0.6 MPa 气密（GB/T 13927）；
- 阀体与端盖必须**成对加工**中法兰面与座孔，否则同轴度（I2，±0.05）无法保证。

## 5. 没有新增工艺

橡胶 O 圈、电镀硬铬、焊接阀体、粉末冶金、注塑密封件——都不在集合里，也没有偷偷用。
球面不做镀铬，靠 2Cr13 调质 + 抛光；阀杆密封不做 O 圈，靠 PTFE 填料 + 压盖预紧。
如果后续要提**寿命/低扭矩**：阀杆 O 圈现在可以**直接外购**（非金属件外购权限，不需要新增模压
工艺）；**球面镀硬铬**仍属新增工艺（电镀），需要你确认后才加。
