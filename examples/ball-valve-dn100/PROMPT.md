# PROMPT — DN100 球阀示例（开工对齐记录）

## 用户原始要求

> 在 examples/ 中创建一个子文件夹，画一个球阀，并进行机械机构运动学仿真和流体仿真，
> 加工工艺是 CNC 和铸造和锻造为主，不能外购，如果两个工艺不能满足需求，需要灵活我确认后，
> 才能新增工艺，DN100

## 开工时问过、用户已答的四件事

| 问题 | 用户选择 |
|---|---|
| 结构型式 | **两片式 / 法兰连接 / 浮动球** |
| “不能外购”的边界 | **PTFE 座/填料 CNC 车削 + 紧固件/铭牌外购**（其余全自制，不新增工艺） |
| 材料路线 | **WCB 铸钢阀体 + 2Cr13 锻球/锻杆** |
| 流体工况 | 介质 **纯水**（未指定流速 → 取 2.0 m/s，见假设） |

## 由此确定的允许工艺集合

`sand-casting` / `forging` / `cnc-3axis` / `cnc-turning`

**新增工艺的判定线**：橡胶 O 圈（需模压）、球面镀硬铬（需电镀）、全焊接阀体（需焊接）、
注塑密封件——都不在集合内，且**都没有被使用**。若后续要提寿命或降扭矩，第一顺位是
“球面镀硬铬”或“阀杆 O 圈”，需要用户确认后才加。

## 代理自行取的默认（都进了 `assembly.json` 的 `brief.assumptions`）

1. 纯水入口 2.0 m/s（≈56.5 m³/h）——DN100 经济流速，用户只给了介质；
2. 面到面 229 mm、管道法兰 EN 1092-1 PN16 DN100；
3. 球 Ø160 全通径、座孔 Ø104、座与球 0.2 mm 预紧间隙；
4. 中法兰 Ø236（大于管道法兰 Ø220）——Ø160 球必须从 Ø164 开口装入；
5. 阀杆顶部 M20×1.5 螺纹与锁紧螺母未建几何（螺母外购）；
6. 拔模斜度/铸造圆角未建进 CAD（由模具保证）；
7. 手柄 400 mm，按 130 N·m 操作扭矩 ≈ 325 N 手力；
8. 流体仿真只作方向性证据，不给压降/Cv。

## “能用”的定义（`brief.verify`）

`["assembly", "motion", "flow"]` —— 装配接得上、90° 行程不撞、水能过去。
**没有主张强度**：壁厚只按标准最小值加余量选，没有算过。
