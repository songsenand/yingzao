## 4. M2 调焦机构 · 运动仿真

`simulate_motion`（run **r025**；crank = 齿轮轴 kinematic 转 ω=−2 rad/s，滑座 prismatic 跟随，**齿条按 `pitchRadiusMm` 与齿轮严格同比例**，不用正弦近似）：

```
Motion pass.  Interference: 0 event(s)
Max joint drift: 0mm          ← 关节锚点零漂移
carriage: travel 25.490mm on z
```

- **行程 25.49mm ≥ 25** ✓，落进接口 7b 的 [25,26] ✓
- **干涉**：齿条是用与齿轮**完全同齿形**的刀具沿滚切包络（N=160）切出来的，所以是**真共轭齿廓**，全程 **0 次干涉**，`simulate_motion` 状态是 **pass** —— 清单里 IF-07/IF-08 因此可以合法地写 `params.runId: r025`。
- 精调：`精调环` 内 **M40×1.5** 螺旋拧在镜头座外螺纹上，顶面抵镜筒下法兰；**1 圈 = 沿光轴 1.5mm → 5µm ≈ 1.2°**，可手动。牙型取 1.05/0.75 对 0.70/0.40，单边 0.35 余量，免支撑可打印。
- **回程间隙怎么办（PROJECT 最想看的一问）**：打印件回程 0.2mm 比焦深 ±6µm 大 30 倍，**所以粗调根本不参与定焦**。粗调只跑行程（单向逼近 + 预压，把间隙永远推在同一侧）；**5µm 由精调螺旋给**，它的轴向回程靠镜头座与镜筒法兰之间的一圈打印波形垫片预压消除。若要做到真正零回程，唯一正确的解法是**剖分齿条 / 剪刀齿轮**，本设计没有做（见 §5 缺口 ③）。

## 5. M4 稳定性 · 两个设计问题的答案

### 问题 1：底座配重腔要不要填？——**不用填**（但余量比 C 臂改造前薄了约 1°）

> ⚠️ 本节数字是 **v054** 重算的。整机刚体前后并过三次：v031（**10 件旧版本**：立柱/弯臂/载物台/滑座/齿轮轴/旋钮/精调环/镜头座/照明座/压片簧）、v051（立柱/弯臂/照明座换了，但弯臂还是带着「托板脱开」bug 的 v049）、**v054**（弯臂 v053 修好后才对）。

`merge_parts` 按当前版本并成整机刚体（**v054**，弯臂 v053 修好托板脱开后重并）：体积 891690mm³，**重心 [−0.13, 32.54, 199.09]**。PLA 实心等效质量 1.11kg。
C 臂挖掉了前侧材料、立柱加粗在后，所以**重心比旧方案后移 3.4mm**（28.83 → 32.21）。

`simulate_physics`（重力按 5° 斜面给 `[855, 0, −9775]`）：

```
machine-empty-v54: stayed upright     ← 5° 斜面上不倒
稳态穿透 3.21mm（v031 时 6.41mm；工具自己注明这是求解器伪值，不是配合实测）
```

临界角 = `atan(d / h)`，d = 重心地面投影到支撑边界的距离，h = 重心高 199.1：

| 倾倒方向 | 支撑边界 | 空腔 | 填 135g 钢砂 | 增益 |
|---|---|---|---|---|
| 向后（最先倒） | 胶垫位 Y=67 | **9.8°** | 11.6° | +1.7° |
| 向后 | 底座外缘 Y=80 | 13.4° | 15.2° | +1.8° |
| 向前 | 前凹弧 Y=−35 | 18.7° | 20.2° | +1.5° |
| 侧向 | 腰 X=±55 | 15.5° | 17.1° | +1.6° |

（加配重后重心 [0, 30.63, 177.88]，总质量 1.24kg）

**结论**：5° 稳稳站立 ✓；临界角 9.8–18.7°，比旧方案薄约 1.2°。
→ **配重腔不必填**（台面 ≤5° 时余量 2 倍）。若真要补，**别只在原腔加料**——腔中心 Y=15 在重心 Y=32 前方 17mm，把 200g 配重挪到 Y≈0 可把临界角抬到 **14.0°**（+4°），比原地加料有效一倍以上。

### 问题 2：压片簧做不做？——**做，但不是为了 10°**

`simulate_physics` 把载物台连同玻片（75×25×1.2）一起倾斜（run 见 §6）：

```
倾斜 10° 无压片簧：settled penetration 0mm，玻片 kept in place（未滑出）
倾斜 25° 无压片簧：settled penetration 0mm，玻片 kept in place（未滑出）
```

理由：玻片是玻璃、槽底是 PLA，μ ≈ 0.3–0.4；`tan10° = 0.176 < μ` → 静摩擦本来就不会让它滑出；`tan25° = 0.466` 也只是刚到边界。

**结论**：**10° 倾斜下，不加压片簧也不会滑出**。做压片簧的理由不是稳定性，而是：
1. 槽单边有 0.15mm 间隙 → 玻片能横向窜 0.3mm，扫视场时会移位；压片簧把它压在后槽壁上，**定位可重复**；
2. 显微镜一定会被碰，模型里表达不了「碰一下」这种瞬态；
3. 成本是一个打印件的料。

→ **做**（v030，预压 1.2 N），但把它的定位记在「消除槽内自由窜动」而不是「防滑出」上。

### 问题 3（手碰一下）：**本轮未跑**，如实说明。
### 问题 4：滑座在齿条上会不会自己往下滑？——**表达不出来，而且缺口的名字要改**

PROJECT §6 缺口 ④ 写的是「`simulate_physics` 只有 revolute，没有 prismatic」。**现场复核：这条已经不成立了** —— 本版工具**同时支持 revolute 和 prismatic**（本次 M2 就用了 prismatic）。

但问题依然表达不出来，原因换了：**prismatic 关节是运动约束，不是保持力模型，工具没有任何摩擦 / 自锁参数**。所以：

- 装上 prismatic 关节 → 滑座只能沿 Z 走，重力下它**必然**滑到底，工具无法回答「它会不会停住」；
- 不加关节 → 它就是自由刚体，同样必然掉下来。

**物理上正确的答案**：mod1 直齿条-齿轮**不是自锁机构**（正反都能被驱动），所以松开手后，约 1.5N 的镜筒+滑座自重会把它压到回程间隙的极限位置（≈0.2mm），不会真的「匀速下滑」，但也**停不回你刚才的位置**。这正是必须靠精调螺旋（1.2°/5µm）+ 单向逼近的原因。

→ 缺口 ④ 的准确表述应从「没有 prismatic」改为「**prismatic 有，但没有摩擦/保持力语义**；『装得对不对』能仿真，『保持得住吗』仿真不了」。

### 5.1 一处把整条齿轮线拖垮的根因（用户截图发现，已修）

用户在 CAD 面板里放大 `齿轮轴` 后指出：**中间有一道看得穿的缝，而且压根不像齿轮**。`measure_part` 立刻证实：`watertight: false`（全机 16 件里唯一一件）。

根因不是布尔运算，而是 **OpenSCAD 的三角函数单位**：`sin/cos/tan` 吃**角度**、`asin/acos/atan` 吐**角度**，而渐开线公式 `inv(α)=tanα−α` 要求**弧度**。原代码直接混用，于是

```
ap = acos(rb/rp)          // 返回 20（度），本应是 0.34907 弧度
inv(ap) = tan(20) - 20    // = −19.636，本应是 +0.014905
```

在**节圆上**两项恰好抵消（所以 `ph(rp)` 看起来是对的，自检时骗过了我），一旦离开节圆就整片垮掉：`ph(rb) = −19.57`、`ph(ra) = +9.40`，齿廓多边形成了横跨大半个圆的怪物。后果是连锁的：

1. 网格不闭合 → 面板把开放边界画成**那道缝**；
2. 齿形不是齿 → **不像齿轮**；
3. 用它当滚刀切出来的**齿条也是错的** → 于是出现了一开始那 24mm³ 的“齿条干涉”，逼我改成 160 段滚切包络、加宽滚刀、加深齿顶…… **全都是在错误齿形上打补丁**；
4. 连 `measure_closest` 报的 0.05mm“余量”也是假象。

修法就是把角度/弧度显式换算（`d2r` / `r2d` / `invr`）。修好后自检：`ph(rb)=4.781°`、`ph(rp)=3.927°`、`ph(ra)=1.855°`，全部正确；`齿轮轴` 与 `调焦滑座` 双双 **watertight: true**；`simulate_motion` 从“30 次干涉、状态 check”变成 **“0 次干涉、状态 pass”**。

**教训（值得写进 skill）**：`measure_part` 的 `watertight` 字段应该在使用任何零件之前先过一遍 —— 这次全机 16 件只查了 1 件就抓到了根因；渲染图看着“像不像”是次要的，**非闭合网格会让后面所有几何检查都在假前提上运行**。

### 5.2 建模位姿 ≠ 啮合转角（位姿记账，不是机构缺陷）

`validate_assembly` 在**未经装配转角**的名义位姿上报 `carriage↔shaft 11.62mm³`。这不是齿形问题，而是记账问题：

25.5mm 行程是**不对称**的（要同时覆盖 f=6/12/25 的物距 6.2 / 13.0 / 29.8mm，相对名义 u=13.0 就是 −6.8 / 0 / +16.8），所以**名义光学位落在行程内部而不是端点**。而滚齿包络的相位常数是按“行程初始位”标定的，于是建模的名义位姿（滑座在 u=13.0、齿轮在其建模相位）之间差了 0.7 rad —— 齿轮**要再转 −40.1°** 才与齿条啮合。

试过把这个转角写进清单的 `transform`：`carriage↔shaft` 立刻从 11.62 掉到 **0.04mm³**，但同一旋转也会把轴端 **D 形削平** 和 `齿轮节圆点` datum 一起转走（旋钮的 D 孔对不上、datum 落到 6.91mm 外），所以又退了回来。正确的做法是**把 0.7 rad 烘进滚齿相位常数**，代价是仿真必须从建模位姿起步（`phaseRad=0`），行程就只剩单向 25.5mm —— 覆盖不了三档物距。

**结论**：这是「不对称行程」与「名义位姿即装配位姿」之间的固有张力，**属于装配记账，不是机构缺陷** —— 机构本身已由 r025 跨全行程证明（0 干涉）。

### 5.3 压片簧的“尖”（用户第二张截图，已修）

用户把 `压片簧` 的端头框出来问。查下去是两件事叠在一起：

1. **0.3mm 台阶**：悬臂 `hull` 的端截面是 z∈[187.2,188.4]，而压脚是 z∈[186.9,188.1] —— 顶面差 0.3mm，在渲染里就是尖端旁边那个缺口；
2. **更要紧的是接触方式**：压脚只是悬臂**斜面端头**伸出的 1.2mm 薄片，等于用 **刀刃**去压玻片 —— 玻璃上会被划出印子，而且那 3mm 是**无支撑悬臂**，受力点不在梁上。

修法（v036）：让悬臂端截面与压脚**同面**（都取 z∈[186.9,188.1]）→ 齐平无台阶；压脚改成 **6×8mm 水平压面**（面接触而不是线接触，且接触面与玻片平行）；前端再收一个**薄鼻当鞋头**（1.2→0.6mm 过渡），装调时能滑上玻片。

`watertight: true`，genus 2（两个 M3 孔）；`validate_assembly` 里 `stage↔clip` 从“干涉 1.94mm³”变成 **0.000mm 贴合** ✓。

### 5.4 螺纹的“全深突然起头”（用户第三张截图，已修）

用户把 `镜头座` 外螺纹上的一个小三角框出来。那是**螺旋牙的起点**：v028 的牙从 z=190.65 处以**全深**直接冒出来。代价两处：

1. **打印**：0.6mm 牙高在一个截面上瞬间出现，是个突变尖角，喷头在那儿必然堆料；
2. **装调**：真螺纹都要有导入段。牙对不上就硬拧 = **乱扣**，而这里的配合是 Ø40 细牙、只能手动对——这正是最该有导入的地方。

修法（v037 / v038 同步）：给 `helix_rib` 加 `lead` 参数，两端各用 **1 个螺距（1.5mm）** 把牙高、牙宽都从 0 线性长到全深 —— 也就是 standard 的 thread run-out。内外螺纹同相位、同螺距、同 lead，所以仍然配对。顺带把牙面分段从 36/圈提到 **60/圈**（10°→6°），牙面明显变光（见渲染）。

`watertight: true`（v037 / v038 都通过）。`validate_assembly` 的 `tube↔mount` 保持 0.000mm 贴合。

**同一个毛病在别处也顺手查了**：`镜筒` 与 `目镜筒` / `相机托板` 的 Ø23.4 承孔、`轴承座` 的剖分瓦口都已经是倒角/圆角导入，不需要改。

### 5.5 「相切而非相交」是一整类 bug —— 靠 genus 审计一次扫出来（用户第四张截图）

用户把 `精调环` 内螺纹上那片**密密麻麻的小方块**框出来。它不是渲染噪点，是**真的网格碎面**。根因和 §5.1 的齿轮轮毂**完全同类**：

> 布尔运算的两个面**半径一模一样**，于是它们只是**相切**而不是**相交**。

| 零件 | 刀具内表面 | 被切/被并的面 | 结果 |
|---|---|---|---|
| 精调环 v038 | `helix_rib(ri=19.72, …)` | 螺纹底孔 `r=19.72` | genus **367**、满屏碎面 |
| 镜头座 v037 | `helix_rib(ri=19.30, …)` | 螺纹芯 `Ø38.6 → r=19.30` | genus **318** |
| 齿轮轴 v008 | `circle(r=rd)` 正好在齿根圆 | 齿根圆 | `watertight:false`（§5.1）|

修法一律相同：**让刀具插进去 0.3**（`ri` 收到 19.42 / 19.00），把相切变成真相交。可见形状**一点没变**（牙顶、牙宽、螺纹外径都原样），但：

| | v037 / v038 | v039 / v040 |
|---|---|---|
| genus | 318 / 367 | **1 / 1** ← 带一个通孔就该是 1 |
| 三角面 | 9226 / 12400 | 6170 / 8984（−33% / −28%）|
| `fine-ring↔mount` | 干涉 0.36–0.84mm³ | **0.191mm 间隙**（干涉消失）|

**顺着这条线做全件 genus 审计，又抓出三件**：

| 零件 | 症状 | 真因 | 修法 |
|---|---|---|---|
| **载物台 v004** | **`watertight:false`** | 前右角斜切的顶点 X=55 正好等于台子右表面；玻片取放斜口 X∈[±37.7] 与玻片槽两侧完全同面 | v044：斜切推到 X=55.5；斜口收到 ±37.6 |
| **弯臂 v012** | genus **−2** | 轴承座的 4 个 M3 铜螺母孔打在 z∈[302,314]，**整段埋在实体里** —— 不只是非流形，**铜螺母根本装不进去**，轴承座也没法拧 | v042：孔改到 z∈[308,320]，开口正好在瓦座面 z=320 上，螺钉从 z=344 下来一路是通的 |
| **粗调旋钮 v010** | genus **−1** | D 形削平块 `cube([30,26,…])` 只覆盖局部 x∈[0,30]，等于**在旋钮体上切掉一大块**而不是只削轴孔 | v043：削平块收到轴孔宽度内（|x|<6），只把 Ø8.2 孔削出 D 平面，旋钮外形不动 |

**「埋孔」那条是最有价值的**：它不是网格洁癖，是**装配真的做不出来** —— 而且 `check_assembly` 全绿、渲染图也看不出来（孔在实体内部，渲染根本看不见）。

**给 skill 的一条硬规矩**：
> **每个零件在投入使用前，`measure_part` 必须同时看两个字段** ——
> `watertight` 必须是 `true`；`genus` 必须是**非负且符合该件通孔数**（一个通孔 = 1，两个 = 2）。
> 共面相切会同时污染这两个指标；`genus` 为负、或远大于通孔数，就是同一个病。

### 5.6 托板根部：强度够，打印不行（用户第五张截图）

用户把 `弯臂` 托板根部框出来问「能加工出来吗？强度够吗？」。核算结果——**强度没问题，打印不行**：

**强度（核算，不是目测）**：
- 托板根截面 **60(X) × 8(Z) mm**，抗弯模量 S = 60×8²/6 = **640 mm³**
- 静载：载物台 89g（0.87N），重心在托板中部，力臂 60mm → M = 52 N·mm → **σ = 0.082 MPa**
- 手碰 20N 在玻片前缘（力臂 91mm）→ **σ = 2.84 MPa**
- PLA 弯曲强度 ~50 MPa → **静载是它的 1/600，手碰是 1/18** → **强度绰绰有余** ✓

**打印（这才是缺陷）**：
- 托板的**下表面**（z=172）从臂前面一路向前悬空伸出去 **61mm，下面什么都没有** —— 这是一个 **61mm 的桥接**，PROJECT 的限制是 **≤30mm** ✗
- 而且根部是一个 **90° 内尖角**，无任何过渡

**修法（v052）**：
1. 托板**顶面保持 z=180 不动**（载物台照样坐在上面），**底面从根部 172 斜升到前端 177**（8 厚 → 3 厚，**3.1° 斜面**）→ 斜升本身就是自支撑，**不再需要桥接** ✓
2. 加一道**加强肋**从臂前面（z≈186）斜落到托板底面（Y=19），**下斜角 27°** —— 免支撑 ✓
3. 肋同时把 90° 内尖角填成缓过渡，并让托板的有效悬臂从 61mm 缩到 ~25mm（**刚度反升**）

`watertight: true`、genus 1 ✓；`validate_assembly` 的 `stage↔clip` 保持 0.000mm 贴合。
新出现一处小残差：`arm↔stage 1.54mm³`（托板斜底与载物台底面之间 0.3mm 级的局部贴合，非受力位置）。

### 5.7 我自己交出了一件「断开」的零件（用户第六张截图）——以及一个工具缺口

用户把 `弯臂 v052` 的托板框出来：**托板整块和臂身分离了**，只靠一小片连着。质问是「交付之前自己都不看下么」——**成立，这是我的失职**。

**过程**：v052 我把托板从「实心 8mm 板」改成「斜底 hull」以消除 61mm 桥接。改完只看了 `measure_part`（`watertight: true`、`genus: 1` 都正常）就把版本号报了出去，**没有重新渲染确认托板还连在臂上**。

**根因**：斜底托板的根部截面只剩 `Y∈[45,46] × z∈[177,180]` 一小块，而臂身在 z∈[177,180] 的前缘已经收到 `Y≈47.9`——**两者在 Y 方向错开 2mm，完全不接触**。托板整块成了悬空的独立体。

**这暴露了一个工具缺口（PROJECT 缺口 ⑨，建议记录）**：
> `measure_part` 只报 `watertight` / `genus` / 体积 / 重心，**不报 shell（连通体）个数**。
> 一个「零件内部有一块断开」的错误，在这三个指标上**全部正常** —— 断开的那块自己也是闭合的。
> 只有 `merge_parts` 的返回里带 shell 数（我那次是 7 shells），但那要在合并时才会被看到。
> **建议**：`measure_part` 增加 `shells` 字段；或者 `check_assembly` 把「同一零件内互不接触的 shell」列为告警。

**修法（v053）**：托板保留斜底 + 前端薄鼻，**在根部加一块 `Y∈[44,60] × z∈[172,180]` 的连接块伸进臂身内部**，保证托板与臂身真重叠。连接块在臂身内部的那段本来就被臂体占据，所以可见外形不变，但托板与臂**真正连成一体**。

**复核**：`watertight: true`、genus 2（托板斜底 + 加强肋形成的两个环）；整机渲染里托板已与臂连续。

### 5.8 加强肋：用户一句「这块斜的薄板是啥？」让我把它删了（第七张截图）

用户问 v053 上那块斜的薄板是什么。它是 v052 我加的**加强肋**（gusset）——当时的说法是「补根部 90° 内尖角、兼作打印支撑」。这一问让我重新核了它，**三项全部不成立**：

| 当时的理由 | 核查结果 |
|---|---|
| 补根部内尖角 | 根部应力 **0.082 MPa**（静载）/ 2.84 MPa（手碰 20N），是 PLA 强度的 0.16%~5.7% —— **没有东西需要加强**；而肋自己才 1~2mm 厚，真受力它先断 |
| 兼作打印支撑 | 托板底面已经改成 **3.1° 斜升**，本来就自支撑 —— **也不需要** |
| —— | 它在 `Y∈[19,29] ∩ z∈[180,188]` 处**直接插进载物台 1.54mm³** —— `validate_assembly` 报的那条 `arm↔stage` 就是它 |

**修法（v055）：删。** 删掉后 `arm↔stage` 从 1.54mm³ 干涉降到 **0.000mm 贴合**，少一块刀刃状薄片、少一处打印毛刺，强度不受影响（它本来就没贡献）。

**教训**：**为修一个缺陷而加的东西，本身必须被重新审查一次** —— 它可能解决不了当初的问题（这条肋没解决打印，因为斜底已经解决了），还可能制造新缺陷（插进载物台）。加之前先问「这个东西到底承担什么载荷」，答不上来就别加。

**我给自己立的规矩（并写进 skill 建议）**：
> **任何一次改轮廓/改连接的 `generate_part`，交付前必须 `render_part` 亲眼看一遍**——
> `watertight` 和 `genus` 都通过 ≠ 零件还是你想要的那个形状。这次就是反例。

| 工具 | run | 结果 |
|---|---|---|
| check_assembly | 最终一次 | 28 接口 / pass 28 / hard 0 / intent 0 / skipped 0 / undeclared 4 |
| simulate_motion | r025 | **pass**：行程 25.490mm · 关节漂移 0mm · **干涉 0 次** |
| validate_assembly | r051（最终） | 干涉 **1** 处：仅剩 `carriage↔shaft 11.62mm³`（§5.2 位姿记账）；12 处贴合/紧配。`arm↔stage` 从 1.54mm³ 降到 0.000mm 贴合（删加强肋后） |
| simulate_physics | v054 重算 | 5° 斜面：**stayed upright**，稳态穿透 **3.21mm**（旧整机 6.41mm；工具注明这是求解器伪值，不是配合实测） |
| measure_part / measure_distance / measure_closest | — | 见 §3 交叉核对 |

**validate_assembly 抓到 3 个真缺陷**（这正是「点名位姿检查」与「契约检查」不是一回事的现场证据）：
1. 镜筒内孔与 Ø26 止口同为 Ø26 → **零间隙**，2.31mm³ 干涉 → 改孔为 Ø26.15（v025）；
2. 精调环螺旋起点比镜头座低 0.1mm，且两边牙型余量只有 0.07mm → 7.36mm³ 干涉 → 同相 + 牙型放大（v029）；
3. 相机托板法兰 Ø34 与目镜筒 Ø34 筒身同径 → **1839.9mm³** 干涉 → 插入段加长到 40、法兰移到筒顶之上（v027）。

**没做干净的地方（如实列出）**：
- `carriage↔shaft` 在**未经装配转角的名义位姿**上报 **11.62mm³** —— 见 §5.2，是位姿记账不是机构缺陷。
- **【两次被我写错、又被推翻的记录】** 本节早先写过「0.90mm³ 是滚齿离散化残差」与「fine-ring↔mount 0.36–0.84mm³ 是螺旋分段残差」——**两条都是错的**。前者真因是 §5.1 的角度/弧度 bug，后者真因是 §5.5 的共面相切布尔。修好后 `simulate_motion` 对齿条-齿轮是 **0 次干涉**，`validate_assembly` 里 `fine-ring↔mount` 从「干涉」降为 **0.191mm 间隙**。
- 教训：**「残差/噪声」是最容易被用来掩盖真 bug 的说辞**。这两次我都用「分段残差」把它解释掉了，是审查者（用户截图）逼出了真因。
- `simulate_physics` 整机稳态穿透 **3.21mm**，仍高于 PROJECT 的「<0.05mm」标准 —— 工具自己已注明这是**求解器伪值，不是配合实测**（整机由 8 个互不完全接触的 shell 组成，地面接触稀疏）。零件之间的配合请以 §3 的接口和 `validate_assembly` 为准。
- `整机刚体` **v054** 合并报 **7 shells**（旧 v031 是 46）——shell 变少是因为这次合并的零件都已修成闭合实体。仍有 7 个互不接触的壳（外购件缺席、间隙配合），对刚体研究合法。

## 7. 打印约束（主动交代）

- 全部件按 **PLA 一种材料、220×220×250 打印床**可打；最大单件 **弯臂 60×120×191**、**镜筒 48×48×156**，均不超床，**无需拆件**。
